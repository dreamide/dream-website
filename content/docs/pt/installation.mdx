O Dream está disponível como aplicativo de desktop para macOS, Windows e Linux.

<Card title="Baixar Dream" icon="download" href="/pt/download">
  Abra a página de download para selecionar o pacote para sua plataforma e arquitetura.
</Card>

## Pacotes disponíveis

| Plataforma | Pacotes |
| --- | --- |
| macOS | DMG para Apple Silicon (ARM64) ou Intel (x64) |
| Windows | Instalador para x64 |
| Linux | DEB, RPM ou AppImage para x64 |

## Antes de abrir o Dream

Instale e autentique pelo menos um [CLI do agente compatível](/docs/pt/providers). O Dream detecta o CLI e os modelos disponíveis nele; as credenciais de API e as assinaturas permanecem gerenciadas pelo próprio provedor.

## Atualizações

O Dream verifica atualizações para aplicativos. Quando uma atualização estiver disponível, use a ação de atualização no app ou baixe o pacote mais recente a partir da [página de download](/pt/download).

<Tip>
  Se o Dream não detectar um CLI instalado, confirme que o comando funciona no seu terminal normal, em seguida, atualize o provedor nas configurações do Dream.
</Tip>

## Próximos passos

Após a instalação, [conecte um provedor](/docs/pt/providers) e ative pelo menos um modelo. Em seguida, [abra seu primeiro projeto](/docs/pt/first-project). Você pode escolher o idioma da interface, o aspecto e a shell do terminal nas [Configurações → Geral](/docs/pt/settings#geral).

Se o aplicativo abrir, mas você não consegue iniciar uma conversa, verifique [solução de problemas para modelo e fornecedor](/docs/pt/troubleshooting#um-modelo-está-faltando-ou-eu-não-consigo-iniciar-uma-conversa).
