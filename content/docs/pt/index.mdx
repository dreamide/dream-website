## O que o Dream inclui

- Um espaço de trabalho multi-projeto com guias de projeto persistentes
- [Espaços de trabalho remotos por SSH](/docs/pt/remote-hosts) com agentes, arquivos, Git e terminais remotos
- Várias conversas ao lado um do outro e ramificações de conversa
- Prompts reutilizáveis em projetos e habilidades de agentes conscientes de provedor
- Pontos de verificação por resposta para revisão e restauração dos arquivos que o agente alterou
- Suporte ao CLI do Codex, CLI do Claude Code, CLI do OpenCode, CLI do Agent do Cursor e CLI do Grok Build
- Um explorador de arquivos, busca e edição de arquivos, terminais integrados e previsões de navegador
- Status do Git, ramo, diferença, commit, push, solicitação de pull e fluxos de trabalho com árvore de trabalho, incluindo a integração de uma árvore de trabalho concluída em seu ramo base
- Feedback de diferença por linha e seleção de elementos do navegador que enviam mensagens direcionadas para uma conversa
- Um painel de solicitação de pull no GitHub para revisão de código, publicação de comentários, edição de detalhes e mesclagem
- Servidores MCP configuráveis e ferramentas integradas de agente para interação com navegador

<Note>
  O Dream executa agentes de programação por meio de seus CLIs instalados. Você precisa ter pelo menos um CLI suportado antes de poder iniciar uma conversa.
</Note>

## Entender o workspace

Um **projeto** é uma pasta no seu computador ou em um host SSH com seus próprios chats e ferramentas. Um **chat** é uma conversa com seu próprio modelo e configurações. Vários chats de um projeto compartilham seus arquivos; um **árvore de trabalho** oferece uma cópia de trabalho Git separada para uma tarefa.

Use [Permissões dos agentes](/docs/pt/agent-modes) para escolher como um agente funciona, e [Contexto e uso](/docs/pt/context-and-usage) para entender as informações abaixo do composer. O [referencial de configurações](/docs/pt/settings) lista as preferências aplicáveis em todo o aplicativo. Se algo estiver faltando ou não funcionar, comece com [Solução de problemas](/docs/pt/troubleshooting).
