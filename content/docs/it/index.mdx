Connetti un'CLI di agente supportato, apri una cartella e lavora con una o più conversazioni senza cambiare strumenti.

## Cosa include Dream

- Un workspace multi-progetto con schede di progetto persistenti
- [Host remoti](/docs/it/remote-hosts) tramite SSH o HTTPS, con agenti, file, Git e terminali remoti
- [Accesso remoto](/docs/it/remote-access) ai progetti di questo computer da un telefono o un computer associato
- Molti chat parallele e ramificazione delle chat
- [Code di messaggi](/docs/it/chats#mettere-in-coda-i-messaggi) per inviare istruzioni mentre un agente lavora
- [Chat senza progetto](/docs/it/standalone-chats) per le domande che non richiedono una cartella
- [Delega](/docs/it/delegation) di attività da un provider di agenti a un altro
- Prompt riutilizzabili tra progetti e competenze agentistiche consapevoli del provider
- Punti di controllo per risposta per la revisione e il ripristino dei file modificati da un agente
- Supporto per Codex CLI, Claude Code CLI, OpenCode CLI, Cursor Agent CLI, Grok Build CLI e Antigravity CLI
- Un esploratore di file, una ricerca e modifica di file, terminali integrati e anteprime di browser
- Flussi di lavoro Git per stato, branch, diff, commit, fetch, pull, push, pull request e worktree, incluso il merge di un worktree completato nel suo branch di base
- Feedback sul differenziale a livello di riga e selezione degli elementi del browser che inviano messaggi mirati a un chat
- Un panel unificato di Git con Modifiche, un grafico a colori della Storia e la revisione di Pull request
- [Ricerca nelle chat e notifiche](/docs/it/chats) tra progetti locali e host remoti connessi
- [Cerca nei file](/docs/it/files#cerca-nei-file) con espressioni regolari e filtri di file
- [Shortcuts personalizzabili del tastierino](/docs/it/settings#istruzioni-rapide-del-tastierino)
- Serveri MCP configurabili e strumenti integrati per l'interazione con il browser

<Note>
  Dream esegue agenti di programmazione attraverso i loro CLIs installati. È necessario almeno un CLI supportato prima di poter iniziare una conversazione.
</Note>

## Capisci lo spazio di lavoro

Un **progetto** è una cartella sul tuo computer o su un host remoto con chat e strumenti propri. Una **chat** è una conversazione con un proprio modello e proprie impostazioni. Più chat nello stesso progetto ne condividono i file; un **albero di lavoro** offre a un'attività un checkout Git separato.

Usa [Autorizzazioni degli agenti](/docs/it/agent-modes) per scegliere come funziona un agente, e [Contesto e utilizzo](/docs/it/context-and-usage) per comprendere le informazioni sotto il composer. La [guida alle impostazioni](/docs/it/settings) elenca le preferenze applicative. Se qualcosa manca o non funziona, inizia con [Risoluzione dei problemi](/docs/it/troubleshooting).
