Dream è disponibile come applicazione desktop per macOS, Windows e Linux.

<Card title="Scarica Dream" icon="download" href="/it/download">
  Apri la pagina del download per selezionare il pacchetto per la tua piattaforma e architettura.
</Card>

## Pacchetti disponibili

| Piattaforma | Pacchetti |
| --- | --- |
| macOS | DMG per Apple silicon (ARM64) o Intel (x64) |
| Windows | Installer per x64 |
| Linux | DEB, RPM o AppImage per x64 |

## Prima di aprire Dream

Installa e autentica almeno un [CLI dell'agente supportato](/docs/it/providers). Dream rileva il CLI e i modelli a lui disponibili; le credenziali API e le sottoscrizioni rimangono gestite da quel provider.

## Aggiornamenti

Dream controlla l'aggiornamento dell'applicazione. Quando è disponibile un aggiornamento, utilizza l'azione Aggiorna nell'applicazione o scarica il nuovo pacchetto dalla [pagina di download](/it/download).

<Tip>
  Se Dream non rileva un CLI installato, conferma che il comando funziona nel tuo terminale normale, poi aggiorna il provider dalle impostazioni di Dream.
</Tip>

## Passi successivi

Dopo l'installazione, [connetti un provider](/docs/it/providers) e abilita almeno un modello. Poi [apri il tuo primo progetto](/docs/it/first-project). Puoi scegliere il linguaggio dell'interfaccia, l'aspetto e lo shell del terminale nelle [Impostazioni → Generale](/docs/it/settings#generale).

Se l'app si apre ma non riesci a iniziare una conversazione, verifica [il troubleshooting del modello e del provider](/docs/it/troubleshooting#un-modello-manca-o-non-posso-avviare-una-chat).
