Dreamは、あなたのコンピュータに既にインストールされているコーディングエージェントのコマンドラインツールと協働します。

## サポートされているプロバイダー

| Provider | 必要な CLI |
| --- | --- |
| OpenAI | Codex CLI |
| Anthropic | Claude Code CLI |
| OpenCode | OpenCode CLI |
| Cursor | Cursor Agent CLI |
| Grok Build | Grok Build CLI |

そのプロバイダーから CLI をインストールし、Dream の外でその CLI の通常のサインインまたは認証フローを完了する。

## モデルを有効にする

1. Dream で **設定** を開く。
2. **プロバイダー**を選択します。
3. CLIをインストールまたは認証した後、プロバイダーを更新する。
4. プロバイダーの有効化スイッチをオンにし、その検出されたモデルの1つ以上を有効にします。
5. Open **一般 → モデル** 並びに新しいチャットおよびコミットとプルリクエストの作成に使用するデフォルトを設定します。

最初のプロジェクトを開く前に、少なくとも1つのモデルを有効にしなければなりません。チャットが開始された後、デフォルトのモデルとは別に異なる有効モデルを使用できます。

## 複数のプロバイダーを使用する

使用したい各プロバイダーのモデルを有効にします。チャットコンポーザーには有効なモデルがリストされていますので、別の会話では別のプロバイダーを選択したり、既に進行中のチャットでモデルを変更したりできます。

たとえば、実装チャットは1つのプロバイダーに保持し、レビューチャットは別のプロバイダーを使用できます。各回のグローバル既定値を変更する必要はありません。[モデルと既定の設定](/docs/ja/models)を参照して、新しいチャットの既定値、推論の努力、速度、および別途Gitドローリングモデルを設定できます。

## プロバイダーの違いを理解する

インストールされた CLI は認証を処理し、エージェントの作業を実行する。モデルリスト、サポートされる労力および速度オプション、添付ファイルの処理、使用情報、および権限行動は、プロバイダーごとに異なる場合がある。

Dream はチャットごとに **確認する**、**編集を承認**、**フルアクセス** の3つの権限を提供します。これらの権限を選択する前に、[Agent permissions](/docs/ja/agent-modes) をご確認ください。Claude はリスケーブルセッションをサポートしており、[Continue in terminal](/docs/ja/terminals#dream-ide-で-claude-チャットをターミナルで継続する) を提供しています。

[スキル](/docs/ja/skills)は Claude Code、Codex、OpenCode、Cursor で利用できます。[MCP サーバー](/docs/ja/mcp-servers)と Dream の組み込みブラウザーツールは Claude Code、Codex、OpenCode、Grok Build で利用できます。Cursor は Dream が管理するこれらのツール接続に対応していません。

## CLIの更新を確認する

プロバイダーカードは、利用可能な場合にインストールされた CLI バージョンを表示します。Dream は新しいバージョンの存在を検出し、見つかった場合に **更新可能: …** のバッジを表示します。このバッジは更新の可用性を示すものであり、更新を実行するものではありません。その CLI の通常のインストール方法を使用して更新を行い、その後 Dream でプロバイダーカードを再読み込みます。

プロバイダーの「有効」スイッチを使用して、CLIをアンインストールせずにそのモデルを利用可能な選択肢から非表示にできます。有効プロバイダーまたはモデルを変更した後は、再度デフォルト設定を確認してください。

## 検出のトラブルシューティング

もしプロバイダーが **CLIが検出されませんでした** と述べた場合：

1. システムのターミナルを開き、CLIコマンドが正常に開始されるかを確認してください。
2. CLIが要求するサインインまたは初回実行設定を完了させる。
3. **設定 → プロバイダー**に戻って、それを再読み込みします。
4. OpenCodeでは、モデルが表示されない場合、認証フローを実行するか、`opencode.json` を設定してください。

Dreamが開いているときにCLIがインストールされた場合、それでもリフレッシュがそれを検出しない場合はDreamを再起動してください。このコマンドはDreamの環境で利用可能でなければなりません。シェルのエイリアスだけではCLIはインストールされていないとみなされます。

CLIが検出された場合でも、望むモデルが存在しない場合は、プロバイダーのアカウントまたは設定を確認し、リストを再取得してください。モデルがリストされているもののチャットで利用できない場合は、それぞれのトグルで有効化し、プロバイダー自体が有効になっていることを確認してください。追加のチェックについては[トラブルシューティング](/docs/ja/troubleshooting)を参照してください。
