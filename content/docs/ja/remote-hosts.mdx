title: "リモートホスト"
description: "SSH または HTTPS で別のマシンのプロジェクトを開き、そこでエージェント、ファイル、Git、端末を使います。"

ローカルとリモートのプロジェクトを並べて開けます。ファイル、Git、エージェント、端末は各ホスト上で動作します。プロジェクトタブとチャット下部でホストを確認できます。

接続方式は2種類あります。

| 経路 | 利用条件 | 必要なもの |
| --- | --- | --- |
| SSH | `ssh` で接続できるマシン | SSH 接続先。Dream がホストをインストールして起動します。 |
| HTTPS | Dream または `dream-host` で[リモートアクセス](/docs/ja/remote-access)が有効 | ホストアドレスとペアリングコード |

両方の経路を登録できます。[経路](/docs/ja/remote-hosts#経路)を参照してください。

## SSH ホストを追加する

1. システムのターミナルで `ssh devbox` が動作することを確認します。`devbox` は SSH 設定のエイリアスまたは `user@host` に置き換えてください。Dream はシステムの SSH クライアント、設定、鍵を使用します。
2. **設定 → 接続** を開き、**リモートホスト** で **ホストを追加**、**SSH ホスト** の順に選びます。
3. **SSH の接続先** を入力します。SSH 設定のエイリアスが候補に出ます。名前を省略すると接続先が名前になります。
4. **保存** を押すとすぐに接続します。
5. ホスト鍵、パスワード、パスフレーズ、二要素認証の要求には Dream 内で回答します。要求を拒否またはキャンセルすると、その接続試行は停止します。

接続時に対応するホストを `~/.dream/host/versions/` に自動インストールして起動します。直接ダウンロードできなければローカルから SSH で転送します。エージェント CLI はリモート側でインストール・認証してください。

SSH ホストは Linux x64・ARM64（glibc 2.31 以降）と Apple silicon の macOS に対応します。接続元は Windows、macOS、Linux を使えます。

## HTTPS でホストとペアリングする

SSH が使えない場合などはコードを使います。例えば Tailscale や Cloudflare Tunnel 経由で職場の PC に接続できます。

1. 相手の PC で[リモートアクセス](/docs/ja/remote-access)を有効にし、**デバイスをペアリング** または `dream-host pair` でコードを発行します。
2. この PC の **設定 → 接続** で **ホストを追加**、**ペアリングコード** の順に選びます。
3. **ホストのアドレス** と **ペアリングコード** を入力します。名前は任意です。
4. **ホストをペアリング** をクリックします。

コードは10分間有効で1回限りです。この PC がホストの HTTPS 証明書を信頼する必要があります。アカウントは不要で、ホストで解除するまで有効です。

## 経路

**リモートホスト** はホストごとに1行です。**編集** で経路を開き、**SSH 経路を追加** や **HTTPS 経路を追加** で追加します。この画面でホスト名も変更できます。

上から順に接続を試します。**上へ移動** と **下へ移動** で並べ替え、**経路を削除** で削除します。最低1件は必要です。優先経路が使えなければ次に切り替わります。

ホスト上のサイトを[ブラウザー](/docs/ja/browser)でプレビューしたり **開くアプリ** で外部エディターを使うには SSH 経路が必要です。HTTPS のみでもプロジェクト、チャット、ファイル、Git、端末を使えます。

## リモートプロジェクトを開く

1. プロジェクトタブ横の **+**、次に **フォルダを開く** をクリックします。
2. **フォルダーを開く** の **開く場所** でホストを選びます。必要に応じて自動接続します。
3. **フォルダのパス** を入力します。ホスト上の候補から **Tab** で選択中のパスを補完します。
4. **開く**をクリックします。リモートフォルダーが、専用のチャットとツールを持つプロジェクトタブとして開きます。

ホストが未登録なら下部の **SSH ホストを追加…** を使います。

閉じたリモートプロジェクトは、ホストとパス付きで**最近閉じた項目**に表示されます。再び開くと、そのホストに接続します。リモートパスはリモートマシン上の場所です。Dream の外でファイルを開くときは、そのマシンに接続したエディターを使用してください。

## ホストの再接続と削除

**設定 → 接続** に接続状態が出ます。切断中もタブは残り、再接続まで送信は無効です。自動再試行が終了したらエラーを確認し、チャットの **再接続** または **接続**（**設定 → 接続** 内）を使います。

切断中もホストでターンは進み、再接続時に追跡を再開します。

**切断** ではタブが残ります。**削除** は確認後にホストとプロジェクトをワークスペースから除き、端末を停止します。ホスト上のファイルとチャットは残ります。

## 接続の問題

端末で同じ SSH 接続先を試し、認証やホスト鍵の問題を解決します。起動できなければ **設定 → 接続** のエラーと対応環境を確認します。

HTTPS 接続拒否のエラーはバージョン不一致か認可不足かを示します。両方のバージョンを揃えるか、新しいコードで再ペアリングします。

開発版は Dream リポジトリで `pnpm host:install-dev devbox` を実行して再接続します。リモート側には Node.js 22 以降、pnpm または Corepack、make、Python 3、C++ ツールチェーン（g++ 10 以降）が必要です。置き換え前に既存の開発用デーモンを停止します。
