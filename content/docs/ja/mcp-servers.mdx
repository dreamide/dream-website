title: "MCPサーバー"
description: "サポートされているコーディングエージェントに外部ツールを追加またはインポートする。"
---

Model Context Protocol (MCP)サーバーは、エージェントに追加のツールを提供します。これらを **設定 → MCP サーバー** で構成できます。Dreamは、**Claude Code**、**Codex**、**OpenCode** および **Grok Build** に対してこれらの接続をサポートしています。CursorはDream管理のMCP接続をサポートしていません。

## サーバーを追加する

1. Open **設定 → MCP サーバー** 並びに **サーバーを追加** をクリックします。
2. 英字、数字、ハイフン、アンダースコアを使い、英字または数字で始まる一意の**名前**を選んでください。
3. **トランスポート** を選択し、サーバーから提供された接続情報を入力します。
4. **有効**の設定を維持してサーバーを公開するようにし、**保存**をクリックします。

| 輸送 | フィールド |
| --- | --- |
| コマンド (stdio) | **コマンド**に実行ファイルを、**引数**に1行につき1つの引数を入力し、必要に応じて**環境変数**を設定します |
| HTTP | HTTP または HTTPS の **URL** と、任意の**ヘッダー** |
| SSE | HTTP または HTTPS の **URL** と、任意の**ヘッダー** |

環境変数とヘッダーは1行ごとに `KEY=VALUE` の形式で入力してください。実行ファイルはその引数と分けて保持してください。たとえば、ローカルサーバーは `node` をコマンドとし、エントリファイルへの絶対パスを引数として使う場合があります。

サーバー定義はDreamのローカルデータベースに保存され、入力したすべての認証情報も含まれます。その値は暗号化されずに保存されます。

## 既存の設定をインポート

1. 配置を含めるプロジェクトを選択してください。
2. Open **設定 → MCP サーバー → インポート…**。
3. 検出されたサーバー、そのソースファイル、および警告を確認する。
4. 追加するサーバーを選択して **インポート** をクリックします。

DreamはClaudeのユーザーおよびプロジェクト設定、Codexのユーザー設定、CursorのユーザーおよびプロジェクトMCP設定をスキャンします。すでに設定されている名前は**登録済み**とマークされ、再インポートされません。

Dream にコピーの定義をインポートする。元のファイルに後続の変更が自動的に同期されない。Cursor の設定をインポートすると、そのサーバーは Dream のサポートされているプロバイダーに利用可能になるが、Dream での Cursor チャットに MCP サポートは追加されない。

**編集**を使用して定義を変更し、**保存**を使用して適用します。**有効**をオフにすると、その設定を保持しながら次のエージェントリクエストに公開しないようにできます。削除するには**削除**をクリックし、**削除を確認**を実行します。定義を削除しても、その実行ファイルはアンインストールされません。

サーバーを変更した後、サポートされているチャットで新しいリクエストを送信します。プロバイダーが古い接続を使用している場合は、新しいチャットを開始します。ツールが利用できない場合、実行ファイル、URL、認証情報、およびチャットエラーを確認します。

Dream の[組み込みブラウザーツール](/docs/ja/browser#エージェントにブラウザを使用してもらう)は、対応するプロバイダーで自動的に接続されます。ここでサーバーを追加する必要はありません。
