title: "モデルと既定の設定"
description: "モデルを有効にし、チャットやGitドロッピングのデフォルトを選び、会話のモデルを変更する。"
---

Dream は、利用可能なモデルと、特定のタスクに選択されるモデルを分離している。**設定 → プロバイダー** は利用可能なモデルの有無を制御する。**設定 → 一般** の **モデル** グループはデフォルトを制御する。各チャットのメッセージボックスの下にある選択者はその会話に適用される。

## モデルを有効にする

1. [サポートされているプロバイダーのCLI](/docs/ja/providers)をインストールし、認証する。
2. Open **設定 → プロバイダー** およびプロバイダーを有効にします。
3. Providerを更新して、そのCLIと利用可能なモデルを検出します。
4. Dreamの選択器に表示されるモデルを有効にします。

複数のプロバイダーからのモデルを有効にできます。選択項目にモデルが存在しない場合は、まずここでの有効化を確認してください。更新は利用可能性を検出するもので、デフォルトモデルを選択するものとは別です。

## 新しいチャットのデフォルトを設定する

1. Open **設定 → 一般 → モデル**。
2. **既定のチャットモデル**では、有効なモデルを選択します。
3. **推論強度** と **速度** を選択するモデルがその制御を提供する場合に選択する。
4. プロジェクトに戻って、選択を用いて新しいチャットを開始する。

デフォルト設定はプロジェクト間で新たに作成されるチャットに適用されます。既存の会話はそれぞれのモデル設定を維持します。**新しいチャット**際に既に開いている空のドラフトが再び表示される場合、そのコンポーザーを確認し、必要に応じてモデルを変更してください。

## コミットとPRの作成にモデルを設定する

同じ **モデル** グループで、**テキスト生成モデル** およびその努力度と速度（サポートされている場合）を選択します。Dream は、これらの選択をコミットメッセージやプルリクエストのテキストの作成時に使用します。

たとえば、実装チャットには1つのモデルを使用し、Gitの要約には別のモデルを使用できます。Gitドローリングモデルを変更しても、チャットモデルは変わりません。生成されたテキストを公開する前に確認および編集するには、[Git workflows](/docs/ja/git-workflows)を参照してください。

## チャットのモデルを変更する

1. 会話を開き、その現在の応答が終了するのを待ちます。
2. メッセージボックスの下にモデル名をクリックしてください。
3. 有効なモデルを選択してください。必要に応じて、他のプロバイダーからのモデルも選択できます。
4. 次のメッセージを送信する前に、努力と速度の制御を確認してください。

Dream では会話は常に表示されます。モデルを変更するとその努力および速度の選択がリセットされ、特定の値が必要な場合は再度選択しなおす必要があります。モデルの変更は、その後の作業に新しいプロバイダーセッションを開始しますが、既に生成されたメッセージは変更されません。

## 推論強度と速度

| コントロール | 目的 |
| --- | --- |
| 推論強度 | そのモデルが提供する推論労働量レベルを選択する |
| 速度 | サポートされる速度階層を選択します。たとえば、StandardまたはFastなど。 |

これらのコントロールは、選択されたモデルがそれらをサポートしている場合にのみ表示されます。利用可能な努力レベルはモデルごとに異なります。速度階層は異なる利用制限を持つ可能性があります；階層の選択においては、オプションの説明およびプロバイダーの利用情報に注目してください。

デフォルトの努力と速度は新しいチャットに適用されます。チャット内でどちらかを変更することは、その会話に影響を与えます。速度を変更することは、次の作業に対してそのプロバイダーのセッションをリセットします。

## デフォルトが利用できない場合

選択された既定モデルを無効にしたり、変更されたモデルリストを再読み込みさせることで、Dream が別の有効モデルを選択する可能性があります。有効モデルを変更した後、両方の既定選択項目を再確認してください。モデルがすべて無効の場合、新しいチャットを開始する前に1つを有効にします。

コントロールの欠落または検出失敗の場合は、[トラブルシューティング](/docs/ja/troubleshooting)を参照してください。
