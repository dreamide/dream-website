Dreamの上部にあるギアアイコンで**設定**を開く。サイドバーには**一般**、**プロバイダー**、**プロンプト**、**スキル**、**MCP サーバー**、および**アーカイブ済みチャット**がある。一般設定は選択するごとに適用される。プロンプト、スキル、サーバー定義のフォームにはそれぞれ独自の作成または保存アクションがある。

## 一般

| 設定 | 何を制御するか |
| --- | --- |
| 言語 | インターフェース言語 |
| ターミナル | 新しいターミナルセッションで使用されるシェル |
| テーマ | システム、ライト、またはダークな表示方法 |
| ベースカラー | インターフェースのグレートーン |
| アクセントカラー | 主要アクションとアクティブな状態 |

ターミナルシェルを変更すると、新しいセッションに影響を与えます。選択を適用するには新しいターミナルを開いてください；[ターミナル](/docs/ja/terminals)を参照してください。

### チャットメッセージ

| 設定 | デフォルト | 何を制御するか |
| --- | --- | --- |
| 推論要約を表示 | On | モデルが提供する要約の表示 |
| ツール呼び出しをグループ化 | オフ | ツール活動のコンパクトなグループ化 |
| ツール呼び出しを展開 | オフ | ツール呼び出しの詳細が展開されるかどうか |
| チェックポイントを変更する | On | 各返答ごとにプロジェクトファイルをスナップショットとして保存して、変更を確認・復元できるようにする |

ディスプレイ設定はプロジェクト間の会話に影響を与えるが、モデルの推論労力や追加のツール権限を変更しない。**変更チェックポイント** をオフにすると新しいスナップショットが停止する；[変更の確認と復元](/docs/ja/checkpoints)を参照。

### モデル

**モデル** グループは一般のトップにあります。

| 設定 | スコープ |
| --- | --- |
| 既定のチャットモデル | プロジェクト間で新たに作成されたチャット |
| 既定の権限 | 質問、編集を承認、または新しいチャットに対してフルアクセス |
| 推論強度 | デフォルトのモデルがサポートしている場合の新しいチャットに対する推論の努力 |
| 速度 | 新しいチャット用の速度階層で、デフォルトモデルがサポートする場合 |
| テキスト生成モデル | 生成されたコミットメッセージとプルリクエストのテキスト、独自の努力とスピードで |

既に存在するチャットはそれぞれの選択を保持します。モデルを Providers で有効にした上で、既定のモデルとして選択してください。完全な設定手順については [Models and defaults](/docs/ja/models) を参照してください。

## プロバイダー

各プロバイダーのカードは、CLIの検出状態、インストール済みバージョン、リフレッシュアクション、および有効化スイッチを表示します。プロバイダーおよび個別モデルを有効にすることで、セレクタに利用可能にします。**更新可能**というバッジは、検出された場合に新しいCLIバージョンの存在を示します。CLIをDreamの外で更新し、その後カードをリフレッシュしてください。

Dream とは別でプロバイダーの CLI をインストールし、認証を行ってください。その後、そのカードをリフレッシュしてください。Dream の設定は CLI の認証フローを置き換えることはありません。[プロバイダーの接続](/docs/ja/providers)を参照してください。

## プロンプト、スキル、およびMCPサーバー

| セクション | 何ができるか |
| --- | --- |
| [プロンプト](/docs/ja/saved-prompts) | 任意のプロジェクトのチャット用に再利用可能なプロンプトを作成、プレビュー、コピー、順序を変更、編集 |
| [スキル](/docs/ja/skills) | プロバイダーとプロジェクト別にスキルを検索し、SKILL.mdファイルをプレビューし、新しいスキルを作成する |
| [MCPサーバー](/docs/ja/mcp-servers) | ツールサーバーを追加またはインポートし、その接続設定を管理する |

## アーカイブ済みチャット

| コントロール | 何をしますか |
| --- | --- |
| チェックボックスの行 | 複数のプロジェクト間でアーカイブされた会話を選択 |
| ヘッダーのチェックボックス | すべてのアーカイブされた会話を選択 |
| 復元 | 選択したチャットをアクティブな履歴に戻す |
| 削除 | Dreamで選択したチャットとメッセージを永続的に削除する |
| 指定日数後にチャットをアーカイブ | 不活性化の切替日を日数で設定する；デフォルトは30日 |
| 今すぐアーカイブ | カットオフに該当するチャットをアーカイブする |

カットオフは自動ジョブをスケジュールしません。大量処理や永続削除を使用する前に、[チャットのアーカイブと復元](/docs/ja/archived-chats)を参照してください。

## Settings以外のコントロール

一部の設定は個々のチャットまたはプロジェクトに属します。チャットのモデル、労力、スピード、および権限はそのチャットのコンポーザーで設定できます。左のツールバーでマルチチャットを切り替えます。チャットのカラムやツールパネルのサイズはワークスペース内で直接調整できます。
