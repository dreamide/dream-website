スキルは `SKILL.md` ファイルに指示をパッケージ化します。Dream は選択されたエージェントおよびプロジェクトに対して、そのプロバイダーのスキル場所を使用してスキルを発見します。スキルピッカーは **Claude Code**、**Codex**、**OpenCode** および **Cursor Agent** をサポートしています。

## チャットでスキルを使用する

1. チャットを開き、使用したいモデルを選択します。
2. メッセージボックスに **$** を続けてスキルの名前の一部を入力します。
3. スキルをピッカーから選択し、タスクの指示を追加してください。
4. メッセージを送信します。

たとえば、`release-checklist` スキルを選び、リリース前に現在の変更を確認するよう依頼します。Dream は選択したスキルをインラインのメンションとして表示し、送信済みメッセージにはスキルバッジを表示します。チャットのプロバイダーやプロジェクトを切り替えると、利用可能なスキルも変わることがあります。

スキルの呼び出しは選択されたプロバイダーによって処理されます。スキルを記述することにより指示が提供されます；これはチャットの[権限設定](/docs/ja/agent-modes)を変更することではありません。

## スキルを検索およびプレビュー

1. Open **設定 → スキル**。
2. プロバイダータブを選択し、検証するプロジェクトを指定します。
3. スキルを選択して、その説明、ソース、パス、および `SKILL.md` のプレビューを確認できます。
4. **フォルダーを開く**を使用して、あなたの好みのエディタでそのファイルを編集できます。

スキルは、**プロジェクト**、**個人**、**プラグイン**、**管理対象**、および**組み込み**などのスコープに分類されます。そのソースが利用可能である場合。スキルをインストールまたは編集した後、まだ表示されていない場合は**更新**を実行してください。

## スキルを有効にするか無効にする

Claude Code と Codex はスキルごとのスイッチを提供しています。これらはプロバイダー自身の設定を更新するため、Dreamの外側でもスキルの利用可能性に影響を与えます。Claude Code はオーバーライドを `~/.claude/settings.json` に保存し、Codex はそのアプリサーバーを通じて `~/.codex/config.toml` に保存します。

OpenCode と Cursor は Dream でスキルごとのスイッチを提供していません。スキルのロードを停止するには、プロバイダーのスキル場所内のそのフォルダを管理してください。

## スキルを作成する

1. **設定 → スキル**で、スキルが1つに属するべきプロジェクトを選択します。
2. **新しいスキル**をクリックしてください。
3. **名前**を入力し、**説明**としてそのスキルを使用するタイミングを説明し、**手順 (SKILL.md)** を設定してください。
4. 1つまたは複数の **保存先** 選択肢を選択してください。
5. オプションで **呼び出されたときだけ実行** を選択し、**作成** をクリックします。

名前は小文字の文字、数字、ハイフンを使用し、最大64文字までです。Dreamはその名前でフォルダを作成し、選択された各場所に`SKILL.md`ファイルを1つずつ作成します。

| 場所 | 意図された用途 |
| --- | --- |
| プロジェクト · `.agents/skills` | Codex、OpenCode、および Cursor 用の共有プロジェクトスキル |
| プロジェクト · `.claude/skills` | Claude Code のプロジェクトスキル |
| 個人用 · `~/.agents/skills` | Codex、OpenCode、および Cursor 用の共有個人スキル |
| 個人用 · `~/.claude/skills` | Claude Code の個人スキル |

プロジェクトの場所には開いているプロジェクトが必要です。**呼び出されたときだけ実行**します。スキルの`disable-model-invocation`設定を書き込みます；その設定がどのように強制されるかはプロバイダーによって異なります。

**スキルとして保存**から始めることもできます。[設定 → プロンプト](/docs/ja/saved-prompts)

## スキルが不足している場合

選択されたプロバイダーとプロジェクトを確認し、リストをリフレッシュし、Settings に表示されている発見エラーを確認してください。スキルがプロバイダーが読み取れる場所にあり、無効になっていないことを確認してください。あるプロバイダーで利用可能なスキルは、別のプロバイダーで必ずしも利用可能ではありません。
