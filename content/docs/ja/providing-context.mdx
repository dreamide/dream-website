アグェントに結果、関連する文脈、および作業開始前に適用すべき制約を提供する。ファイル参照はコードを特定するのに役立ち、添付ファイルはスクリーンショットなどの追加資料を提供できる。

## プロジェクトファイルまたはフォルダを参照する

1. チャットのメッセージボックスに **@** を入れてファイルまたはフォルダのパスの一部を入力します。
2. 結果のリストから選択してください。**アップ**キーと**ダウン**キーを使って結果を移動し、**Enter**または**Tab**キーで選択してください。
3. 挿入された参照の周りにあなたの指示を追加してください。
4. メッセージを送信します。

たとえば、設定コンポーネントを参照して、次のように尋ねる：

> このフォームが設定をロードおよび保存する方法を説明し、なぜリフレッシュによって選択された値が失われるのかを検索する。

タスクがどこに属しているかわかっている場合、ファイルを選択し、アグェントが複数の関連ファイルを確認する必要がある場合、フォルダを選択します。結果リストは親パスを表示して、同じ名前のファイルを区別します。**Escape** を押してリストを閉じます。

参照は現在のプロジェクト内の場所を識別します。ファイルコンテンツを固定したり、ディレクトリのコピーを会話に添付したりするものではありません。

## ファイルを添付する

1. メッセージボックスの横にある**ファイルを添付**コントロールをクリックしてください。
2. 添付アクションを選択し、コンピュータからファイルを選択します。
3. 添付ファイルが composer に表示されていることを確認してください。
4. アグエントがそれをどのように使うべきかを説明してください。その後、メッセージを提出してください。

スクリーンショットに関しては、期待される動作および問題点を説明してください。選択されたプロバイダーとモデルは、使用できる添付タイプを決定します。

## 繰り返し実行可能な指示のためにスキルを使用する

コンポーザーに **$** をタイプして、選択されたプロバイダーおよびプロジェクトの[エージェントスキル](/docs/ja/skills)を検索します。選択後、タスクを説明します。スキルは、あなたのメッセージ内のファイル参照および添付ファイルとともに、手順やプロジェクト規約を提供できます。

繰り返し送信する必要があるplain textについては、[再利用可能なプロンプト](/docs/ja/saved-prompts)を使用してください。

## 画像を表示およびコピーする

会話中の画像をクリックして、その大きなプレビューを開きます。画像の上にマウスを合わせることで、右上に**画像をコピー**が表示され、それをクリックしてクリップボードに画像をコピーします。

レポートや他のチャットでDream自体をキャプチャするには、[ウィンドウスクリーンショットショートカット](/docs/ja/workspace#dreamウィンドウをキャプチャする)を使用してください。

## 送信前にコンテキストを削除する

添付ファイルの削除コントロールを使用して、コンポーザーからそれを削除します。インラインプロジェクト参照の場合、メッセージ内のその参照の記述を削除します。その参照はその際に削除されます。残りのテキストを確認して、リクエストがまだ意味を成しているかを確認します。

**@** がパスを検出しなかった場合、現在のプロジェクトを確認し、[Files](/docs/ja/files) でファイルを検索してください。パスが移動またはリネームされた場合、現在のパスを使用します。

## 別のチャットに足够的な文脈を提供してください

別々のチャットは自動的にそのメッセージを共有しません。実装チャットの側にレビューを開始する際、変更点を特定し、どのファイルが関係するかを確認し、レビュアーが確認すべき内容を明確にします。

[ブランチ](/docs/ja/branching-chats)を使用して以前のメッセージを別の会話に持ち込むか、[スタッシュ](/docs/ja/stash)を使用してプロジェクト参照付きのプロンプトを後で保存する。
