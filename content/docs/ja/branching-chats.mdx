---
title: "会話の分岐"
description: "同じワークスペース内の以前のメッセージから継続するか、または隔離された Git ワークツリーから継続する。"
---

会話の別のアプローチを検討したい場合に、会話の内容をブランチに分割できます。Dreamは選択されたメッセージを元に新しい会話にメッセージをコピーし、元の会話は保持します。その時点以降のメッセージは新しい会話に含まれません。

## 同じワークスペースで続ける

1. ソースコンバージョンを開き、その応答が終了するまで待つ。
2. ブランチを派生させるメッセージを検索します。
3. その **このメッセージから続ける…** アクションを使用します。
4. **このワークスペース** の下で **新しいチャットで続ける** を選択します。
5. 新しい会話で、試したい代替案についてフォローアップメッセージを送る。

新しいチャットはソースチャットのモデルおよび権限設定で開始されます。マルチチャットの場合は、ソースチャットの横に開きます。シングルチャットレイアウトの場合は、そのチャットが表示される会話になります。

たとえば、アグエントがバグを説明した後で、新しいチャットで小さな修正を比較するように要求する場合、両方の会話は現在のプロジェクトファイルを使用できる。

<Note>
  ブランチは会話履歴をコピーします。選択されたメッセージが送信されたときのファイルシステムの状態に戻すことはありません。このワークスペース内の両方のチャットは依然として同じファイルを共有しています。
</Note>

## 新しいワークツリーで継続する

独立チェックアウトの場合、**このメッセージから続ける… → 新しいワークツリー** を使用します。このオプションは Git リポジトリの存在を必要とします。Dream はワークツリープロジェクトを作成し、履歴をコピーした新しいチャットを作成します。

このショートカットは現在のブランチをベースとしており、チャットタイトルからブランチ名を生成します。カスタムベースリファレンスを選択するよう促すことはありません。ベースリファレンスおよびブランチ名を自分で選択したい場合は、[ブランチスイッチャーからワークツリーを作成](/docs/ja/worktrees#ワークツリーを作成する)してください。

<Warning>
  新しいワークツリーはコミットされたGitの履歴から開始されます。未コミットの変更を含みませんし、選択されたメッセージにおける正確なファイル状態を再構築することもありません。新しいチェックアウトに必要な変更を保存してコミットしてください。その後、ワークツリーにブランチを切ってください。
</Warning>

## 適切な種類のブランチを選択する

| あなたは… | Use |
| --- | --- |
| Dream IDE で現在のコードについて別の質問をしますか？ | このワークスペース |
| 推論を比較しながら、以前の議論を維持する | このワークスペース |
| 別のエージェントが独立したチェックアウトを編集する | 新しいワークツリー |
| タスクを開始するにはメッセージをコピーする必要はありません | 新しいチャット |

応答処理中の間はブランチの作成が利用できません。ワークツリーオプションが利用できない場合は、プロジェクトがGitリポジトリ内にあることを確認してください。結果として生成されたプロジェクトを開くか削除する方法については、[ワークツリー](/docs/ja/worktrees)を参照してください。
