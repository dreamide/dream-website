DreamはmacOS、Windows、Linux向けのデスクトップアプリとして利用可能です。

<Card title="Dreamをダウンロード" icon="download" href="/ja/download">
  ダウンロードページを開いて、あなたのプラットフォームとアーキテクチャに合わせたパッケージを選択します。
</Card>

## 利用可能なパッケージ

| プラットフォーム | パッケージ |
| --- | --- |
| macOS | Apple silicon (ARM64) または Intel (x64) 用の DMG |
| Windows | x64用インストーラー |
| Linux | x64 用の DEB、RPM、または AppImage |

## Dreamを開く前に

[サポートされているエージェントCLI](/docs/ja/providers)の少なくとも1つをインストールし、認証してください。DreamはCLIおよびそのCLIが提供するモデルを検出します。API認証情報およびサブスクリプションはそのプロバイダーによって管理されます。

## 更新内容

Dreamはアプリケーションの更新を確認します。更新が利用可能な場合、アプリ内の「更新」アクションを使用するか、[ダウンロードページ](/ja/download)から最新のパッケージをダウンロードします。

<Tip>
  DreamがインストールされたCLIを検知しない場合、通常のターミナルでコマンドが正常に動作することを確認し、Dreamの設定からプロバイダーを再読み込みます。
</Tip>

## 次へ

インストール後、[プロバイダーを接続](/docs/ja/providers)し、少なくとも1つのモデルを有効にします。その後、[最初のプロジェクトを開く](/docs/ja/first-project)ことができます。[設定 → 一般](/docs/ja/settings#一般)でインターフェース言語、外観、ターミナルシェルを選択できます。

アプリが開くものの会話の開始ができない場合は、[モデルとプロバイダーのトラブルシューティング](/docs/ja/troubleshooting#モデルが存在しないかチャットを開始できません)を確認してください。
