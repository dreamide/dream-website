右のツールバーの **ファイル** をクリックして、アクティブなプロジェクトのフォルダをブラウズできます。ツリーからファイルを開くことで、チャットと一緒にそのファイルを確認できます。ファイルタブを使えば、複数の開かれたファイルを切り替えることができます。

## ファイルを検索する

1. **ファイル**をオープンする。
2. ツリーの上部の「ファイルを検索」にファイル名またはパスの一部を入力してください。
3. 結果を選択して開く。
4. 検索をクリアして、ツリーをブラウズに戻します。

Dreamのファイルアクションで**ファイルを更新**を実行して、Dreamの外で行われた変更がツリーに反映されていない場合に使用します。ファイルを検索することでそのパスを特定できます；そのファイル内のテキストを検索するにはエディタの検索機能を使用します。

## ファイル内の検索と置換

1. ファイルを開き、エディタのツールバーにある **現在のファイルを検索** をクリックします。
2. **検索**にテキストを入力してください。
3. **次の一致**または**前の一致**を使用して結果を移動できます。
4. 必要に応じて、**大文字と小文字を区別**、**単語全体に一致**、または**正規表現を使用**を有効にします。

検索パネルは置換コントロールも提供しています。**すべて置換**を使用する前にマッチを確認し、ファイルを保存して変更をディスクに書き込みます。置換は現在のファイルに影響を与えます。

## 編集し、保存する

コードエディタで書き換え可能なテキストファイルを編集します。保存されていない変更はそのタブにマークされ、パネルは保存されていないドキュメントのファイル数を表示できます。

編集ツールバーの**保存**をクリックするか、編集がフォーカスされているとき、macOSでは**Command+S**、Windows/Linuxでは**Ctrl+S**を押してください。アグェントまたはターミナルコマンドが新しい内容を使用する前に、各編集されたファイルを保存してください。これらのツールはディスク上のファイルを読み取ります。

ファイルタブを切り替えることで、ドラフトを保持しながら他のファイルを確認できます。**変更を捨てる**を使用して、ローカルのドラフトを放棄できます。これはGitを通じて変更を元に戻すことに別れます。

未保存の変更を持つタブを閉じると、**保存 / 保存しない / キャンセル**のポップアップが表示されます。**保存**はドラフトを書き込み、タブを閉じます。**保存しない**はドラフトを捨ててタブを閉じます。**キャンセル**はタブを保持します。保存に失敗するか、外部の編集と衝突した場合、ファイルは開いており、問題を解決できるようにします。

## 編集器の外でファイルが変更された場合に処理する

エージェント、ターミナルコマンド、または外部エディタがドロップをもつ状態で同じファイルを変更する場合、Dreamは保存時にディスク内容を確認し、新しいバージョンを静かに上書きするのではなく、衝突を報告します。

1. 保管したいドラフトテキストを保持してください。
2. 衝突メッセージを読み取る。
3. **ディスクから再読み込み**を使用して現在のファイルを読み込みます。
4. まだ必要な変更を再適用した後、再度保存してください。

<Warning>
  ディスクから再読み込みは、あなたのローカルドロイトを置き換える。コピーが必要な未保存の作業を実行する前に、それをコピーする。
</Warning>

## ビューを調整する

**折り返しを有効にする**を長さの大きい行に使用してください。ファイルツリーおよびエディタパネルのサイズを調整してコンテンツにより多くのスペースを確保してください。利用可能な**開くアプリ**アクションを使用して外部エディタで継続してください。

保存後、[変更](/docs/ja/git-workflows)を開いて Git の差分を確認してください。ファイルについてエージェントに質問するには、チャットの入力欄で [@ を使ってそのファイルを参照](/docs/ja/providing-context)してください。
