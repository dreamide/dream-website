Dreamは、あなたのプロジェクト、AIコーディングエージェント、ファイル、ターミナル、ブラウザプレビュー、そしてGitワークフローを1つのデスクトップワーキングスペースに統合します。サポートされているエージェントCLIを接続し、フォルダを開き、1つ以上のチャットを扱うことができます。ツールを切り替えることなく作業できます。

## Dream には何が含まれていますか

- 複数プロジェクトを扱えるワークスペースで、永続的なプロジェクトタブを提供する
- 複数の並列チャットとチャットブランチ
- プロジェクト間で再利用可能なプロンプトおよびプロバイダー意識のあるエージェントスキル
- アグエントが変更したファイルを確認および復元するために使用するリプライごとのチェックポイント
- Codex CLI、Claude Code CLI、OpenCode CLI、Cursor Agent CLI および Grok Build CLI のサポート
- ファイルエクスプローラー、ファイル検索および編集、統合されたターミナル、ブラウザプレビュー
- Gitのステータス、ブランチ、差分、コミット、プッシュ、プルリクエスト、およびワークツリーのワークフロー、および完了したワークツリーをベースブランチにマージする方法
- ラインレベルの差分フィードバックとブラウザ要素選択によるチャットへのターゲットメッセージ送信
- コードのレビュー、コメントの投稿、詳細の編集、マージを行うためのGitHubのプルリクエストパネル
- ブラウザインタラクション用のカスタマイズ可能な MCPサーバーと組み込みのエージェントツール

<Note>
  Dreamは、インストールされたCLIを通じてコーディングエージェントを実行します。チャットを開始する前に、少なくとも1つのサポートされているCLIが必要です。
</Note>

## ワークスペースを理解する

**プロジェクト**は、独自のチャットとツールを持つローカルフォルダです。**チャット**は、独自のモデルと設定を持つ会話です。同じプロジェクト内の複数のチャットはそのファイルを共有します；**ワークツリー**はタスクに別々のGitチェックアウトを提供します。

[エージェントの権限](/docs/ja/agent-modes)を使用してエージェントがどのように動作するかを選択し、[コンテキストと使用量](/docs/ja/context-and-usage)を使用してコンポーザーの下にある情報を理解します。[設定リファレンス](/docs/ja/settings)はアプリ全体の設定をリストしています。何かが欠けているか、実行できない場合はまず[トラブルシューティング](/docs/ja/troubleshooting)から始めます。
