Dreamは、あなたのプロジェクト、AIコーディングエージェント、ファイル、ターミナル、ブラウザプレビュー、そしてGitワークフローを1つのデスクトップワーキングスペースに統合します。サポートされているエージェントCLIを接続し、フォルダを開き、1つ以上のチャットを扱うことができます。ツールを切り替えることなく作業できます。

## Dream には何が含まれていますか

- 複数プロジェクトを扱えるワークスペースで、永続的なプロジェクトタブを提供する
- SSH または HTTPS の [リモートホスト](/docs/ja/remote-hosts)でエージェント、ファイル、Git、端末を利用
- ペアリング済みのスマートフォンや PC からプロジェクトへ[リモートアクセス](/docs/ja/remote-access)
- 複数の並列チャットとチャットブランチ
- エージェントの作業中に指示を送る[メッセージキュー](/docs/ja/chats#メッセージをキューに入れる)
- フォルダー不要の質問には[プロジェクトのないチャット](/docs/ja/standalone-chats)
- 別のプロバイダーへの[タスク委任](/docs/ja/delegation)
- プロジェクト間で再利用可能なプロンプトおよびプロバイダー意識のあるエージェントスキル
- アグエントが変更したファイルを確認および復元するために使用するリプライごとのチェックポイント
- Codex CLI、Claude Code CLI、OpenCode CLI、Cursor Agent CLI、Grok Build CLI、Antigravity CLI に対応
- ファイルエクスプローラー、ファイル検索および編集、統合されたターミナル、ブラウザプレビュー
- Git 状態、ブランチ、差分、コミット、フェッチ、プル、プッシュ、PR、ワークツリーの作成とベースへのマージ
- ラインレベルの差分フィードバックとブラウザ要素選択によるチャットへのターゲットメッセージ送信
- Changes、色付きの履歴グラフ、およびプルリクエストレビューを備えた統合型Gitパネル
- ローカルプロジェクトと接続中のホストを対象とした[チャット検索と通知](/docs/ja/chats)
- ファイル内検索 ([Find in files](/docs/ja/files#ファイル内を検索)) で正規表現とファイルフィルタを使用
- [カスタマイズ可能なキーバインド](/docs/ja/settings#キーボードショートカット)
- ブラウザインタラクション用のカスタマイズ可能な MCPサーバーと組み込みのエージェントツール

<Note>
  Dreamは、インストールされたCLIを通じてコーディングエージェントを実行します。チャットを開始する前に、少なくとも1つのサポートされているCLIが必要です。
</Note>

## ワークスペースを理解する

**プロジェクト** はチャットとツールを持つローカルまたはリモートのフォルダーです。**チャット** は独自のモデルと設定を持ちます。プロジェクトのファイルは共有され、**ワークツリー** は独立した Git 作業コピーを提供します。

[エージェントの権限](/docs/ja/agent-modes)を使用してエージェントがどのように動作するかを選択し、[コンテキストと使用量](/docs/ja/context-and-usage)を使用してコンポーザーの下にある情報を理解します。[設定リファレンス](/docs/ja/settings)はアプリ全体の設定をリストしています。何かが欠けているか、実行できない場合はまず[トラブルシューティング](/docs/ja/troubleshooting)から始めます。
