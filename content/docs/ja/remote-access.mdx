---
title: "リモートアクセス"
description: "スマートフォン、ブラウザ、または別の Dream デスクトップから、このコンピューターのプロジェクトを使用します。"
---

リモートアクセスを使うと、他のデバイスからこのコンピューター上のプロジェクトで作業できます。スマートフォンや別のコンピューターではブラウザで Dream を開き、別の Dream デスクトップではこのコンピューターを[リモートホスト](/docs/ja/remote-hosts#https-経由でホストをペアリングする)として追加できます。どのデバイスも事前にペアリングが必要で、アクセスはいつでも取り消せます。

エージェント、ターミナル、Git コマンドは引き続きこのコンピューター上で実行されます。ペアリング済みデバイスがこのコンピューターに接続できるのは、ここで Dream のホストが実行されている間だけです。Dream を閉じた後もホストを実行し続けるには、ホストを[サービス](/docs/ja/host-service)としてインストールしてください。

## 開始する前に

デバイスがこのコンピューターに接続する方法を選択します：

| 接続方法 | 必要なもの |
| --- | --- |
| Tailscale | このコンピューターと各デバイスに Tailscale がインストールされ、サインイン済みであること。tailnet で MagicDNS と HTTPS 証明書が有効になっていること |
| Cloudflare Tunnel | Cloudflare アカウント内の永続的な Cloudflare Tunnel とホスト名 (例: `dream.example.com`) |

Cloudflare Tunnel の場合は、専用のリモート管理トンネルを作成し、そのコネクタートークンだけをコピーします。そのホスト名を、Dream に表示される**ローカルポート**の `http://127.0.0.1` にルーティングし、`/api/*` ではキャッシュをバイパスします。Quick Tunnel はサポートされていません。また、ホスト名で対話型の Cloudflare Access ログインを必須にすることはできません。

## リモートアクセスをオンにする

1. **設定 → 接続**を開き、**リモートアクセス**を探します。
2. **設定**を選択します。
3. **このコンピュータへの接続方法**で、**Tailscale** または **Cloudflare Tunnel** を選択します。
4. Cloudflare Tunnel の場合は、**公開アドレス**を入力し、**トンネルトークン**を貼り付けます。コネクターに**未インストール**と表示される場合は、**cloudflared をインストール**を選択します。
5. **オンにする**を選択します。

Dream は接続を確認してから**準備完了**と表示します。**準備未完了**と表示された場合は、その下のメッセージを読んで設定を修正し、**再確認**を使用します。一部のメッセージには**設定ページを開く**が含まれます。

接続方法を切り替えたり、トンネルトークンを置き換えたりするには、**変更**を使用します。保存済みのトークンを使い続けるには、トークンを空欄のままにします。**ペアリング済みデバイスを許可**スイッチを使うと、設定やペアリング済みデバイスを失わずにリモートアクセスをオフ・オンできます。

### 詳細オプション

| オプション | 何をしますか |
| --- | --- |
| HTTPS ポート | Tailscale が Dream を提供するポート。Tailscale がすでにそのポートで別のものを提供している場合は変更します |
| ローカルポート | このコンピューターでリモート接続を受け付けるポート。自動で選択するには空欄のままにします |
| cloudflared を自分で実行する | 別途インストールして実行する Cloudflare コネクターを使用します。Dream はそれを起動、停止、削除しません |

## デバイスをペアリングする

1. リモートアクセスが**準備完了**の状態で、**デバイスをペアリング**を選択します。
2. デバイスの**アクセス**レベルを選択します。
3. **ペアリングを作成**を選択します。
4. デバイスで QR コードをスキャンするか、リンクを開きます。**リンクをコピー**を使ってリンクを送ることもできます。
5. **完了**を選択します。

| アクセス | デバイスでできること |
| --- | --- |
| 表示のみ | プロジェクト、チャット、ターミナルを閲覧 |
| 表示と作業 | さらに、あなたとしてエージェント、ターミナル、Git を実行 |
| すべて | さらに、デバイスのペアリングと削除 |

リンクは 1 回だけ使用でき、10 分後に期限切れになります。リンクを使わずにペアリングするには、デバイスでホストのアドレスを開き、QR コードの横に表示されたペアリングコードを入力して、デバイスに名前を付けます。その後デバイスは、このコンピューターで**承認**を選択するまで待機します。承認は**ペアリング待ち**から行います。心当たりのないデバイスには**拒否**を選択してください。

別の Dream デスクトップをペアリングするには、そのデスクトップの**ホストを追加 → ペアリングリンク**ダイアログにリンクを貼り付けます。[HTTPS 経由でホストをペアリングする](/docs/ja/remote-hosts#https-経由でホストをペアリングする)を参照してください。

## ペアリング済みデバイスで Dream を使う

ペアリング済みデバイスでは、ブラウザで Dream が開きます。スマートフォンでは、Dream はコンパクトなレイアウトを使用します。デバイスは、アクセスレベルの範囲内で、このコンピューター上のプロジェクト、チャット、ファイル、ターミナルを操作できます。

このコンピューターに接続できない場合は、その旨のバナーが表示され、デバイスには保存済みの内容が表示されます。ホストが再び利用可能になると、Dream は再接続します。スリープ中のコンピューターには接続できません。

デバイス自体からそのデバイスのアクセス権を削除するには、**サインアウト**を選択します。このボタンは**このデバイス**にあります。サインアウトすると、そのブラウザに保存された内容も削除されます。

## ペアリング済みデバイスを管理する

**ペアリング済みデバイス**には、各デバイスと最終使用日時が一覧表示されます。デバイスのアクセス権を削除するには**取り消す**を選択します。そのデバイスで開いているページはすぐに停止しますが、このコンピューター上の作業は続行されます。30 日間使用されなかったデバイスは、再度ペアリングする必要があります。

## リモートアクセスの問題

| メッセージまたは症状 | 何をすべきか |
| --- | --- |
| Tailscale がインストールされていないか、実行されていない | Tailscale をインストールしてサインインし、このコンピューターを接続してから、**再確認**を選択します |
| このコンピューターは承認を待っています | Tailscale 管理コンソールで承認します |
| MagicDNS と HTTPS 証明書を有効にしてください | Tailscale 管理コンソールで、tailnet の両方を有効にします |
| Tailscale はこのユーザーによる Serve 設定の変更を許可していません | Linux では `sudo tailscale set --operator=$USER` を一度実行してから、再確認します |
| 別のプログラムがすでにそのポートを使用しています | 別の**HTTPS ポート**または**ローカルポート**を選択します (**詳細設定**内) |
| Tailscale 経由でこのコンピューターに到達できませんでした | Tailscale がまだ証明書を取得中の可能性があります。1 分後に再確認してください |
| Cloudflare 経由でこのコンピューターに到達できませんでした | Cloudflare で、ホスト名のサービス URL を `http://127.0.0.1` と Dream に表示される**ローカルポート**に設定します |
| Cloudflare コネクターの接続を待っています | トンネルトークンと、このコンピューターからの送信接続が許可されていることを確認します |
| ペアリングリンクの期限が切れているか、使用済みです | もう一度**デバイスをペアリング**を選択し、新しいリンクを使用します |
| デバイスが動作しなくなった | 取り消されたか、30 日間使用されなかったかを確認し、再度ペアリングします |
