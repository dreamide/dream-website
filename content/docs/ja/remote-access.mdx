---
title: "リモートアクセス"
description: "Tailscale または Cloudflare Tunnel 経由で端末をペアリングし、スマートフォンや別の PC からプロジェクトを使います。"
---

ペアリング済み端末はブラウザーまたはデスクトップアプリで接続できます。エージェント、ファイル、端末、Git はこの PC 上で動作します。

初期状態では無効です。ネットワーク経路を用意し、端末ごとにペアリングします。Dream アカウントや中継サービスは不要です。

## 接続方法を選ぶ

| 選択肢 | 仕組み | 必要なもの |
| --- | --- | --- |
| Tailscale | tailnet 内で HTTPS 配信 | 全端末に Tailscale を導入し、tailnet で MagicDNS と HTTPS 証明書を有効化 |
| Cloudflare Tunnel | 所有ドメインの公開ホスト名で配信 | Cloudflare アカウントの永続トンネルと自分で実行する `cloudflared` コネクター |

独自のリバースプロキシも利用できます。[ホストの実行](/docs/ja/dream-host#コマンドラインからのリモートアクセス)を参照してください。

## リモートアクセスを有効にする

1. **設定 → 接続** で **リモートアクセス** を探します。
2. **設定** をクリックします。
3. **このコンピュータへの接続方法** で **Tailscale** または **Cloudflare Tunnel** を選びます。
4. Tailscale は **HTTPS ポート** を確認します。Cloudflare Tunnel は **公開アドレス** に `https://dream.example.com` などを入力します。
5. 固定ポートが不要なら **ローカルポート** を空欄にし、**オンにする** を押します。

到達できると **ペアリング済みデバイスを許可** の横に **準備完了** と表示されます。**準備未完了** なら問題を修正して **再確認** を押します。設定変更は **変更**、ペアリングを保持して停止するには **ペアリング済みデバイスを許可** をオフにします。

### Cloudflare トンネルを設定する

`cloudflared` はご自身で実行します。Dream に必要なのは公開アドレスとローカル転送先ポートだけです。トークンは不要です。

1. Cloudflare ダッシュボードでトンネルを作り、表示されたインストールコマンドをこの PC で実行します。
2. 所有ドメインのホスト名にルートを追加し、サービスを `HTTP`、宛先を `127.0.0.1:5410` または Dream の **ローカルポート** にします。
3. ホスト名で API と WebSocket への直接接続を許可します。Cloudflare Access のログインやブラウザーチャレンジを挟まず、`/api/*` のキャッシュとバッファリングを無効にします。

Quick Tunnels はアドレスが変わりチャットをストリームできないため非対応です。

## 端末をペアリングする

1. 準備ができたら **デバイスをペアリング** をクリックします。
2. **アクセス** で権限を選びます。
3. **ペアリングを作成** を押します。**ペアリングコード** と **ホストのアドレス** が表示されます。
4. 相手端末のブラウザーでホストアドレスを開き、コードと **デバイス名** を入力して **ペアリング** を押します。

別のデスクトップアプリからは同じアドレスとコードで[この PC をホストに追加](/docs/ja/remote-hosts#https-でホストとペアリングする)します。

コードは10分間有効で1回限りです。選んだ権限が付与されるため対象端末だけに渡します。

| アクセス権 | できること |
| --- | --- |
| 閲覧のみ | プロジェクト、チャット、端末を閲覧 |
| 閲覧と作業 | さらに本人の権限でエージェント、端末、Git を実行 |
| フルアクセス | さらに端末のペアリングと解除 |

## ペアリング済み端末で使う

ブラウザーにこの PC のプロジェクト、チャット、ファイル、端末、Git が表示されます。**ブラウザ**、**設定 → 接続**、別のホストのフォルダーを開く操作、外部エディター用の **開くアプリ** はデスクトップ専用です。

切断時は再接続中または保存済みデータを表示中であることが通知されます。ホストは作業を続けます。端末側で解除するには **設定** で **サインアウト** を選びます。

## ペアリング済み端末を管理する

**ペアリング済みデバイス** に権限と最終使用時刻が出ます。**取り消す** で1台、**すべて取り消す** ですべて解除します。解除した端末のページは直ちに使えなくなりますが、ホストの作業は続きます。

## この PC を接続可能に保つ

接続には PC が起きていてホストが動作している必要があります。アプリが起動したホストは終了時に停止します。バックグラウンドやヘッドレスでの運用は[ホストの実行](/docs/ja/dream-host)を参照してください。

バージョンの相違が表示されたら古い方を更新し、ホストを再起動します。
