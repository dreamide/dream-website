各 Dream プロジェクトには独自のワークスペースがあります。プロジェクトのタブを使えば、リポジトリを移動しながらも、各プロジェクトの開いているチャットとツールを維持できます。

プロジェクトは [SSH ホスト](/docs/ja/remote-hosts)上にも配置できます。コマンドを実行する前にホストのラベルを確認してください。リモートプロジェクトのツールはそのマシン上で動作します。

## プロジェクトを追加し、切り替えます

1. プロジェクトタブの側に **+** をクリックするか、開始画面で **フォルダを開く** を使用する。
2. 作業するフォルダを選択してください。
3. そのタブを選択して、そのプロジェクトをアクティブプロジェクトに設定します。

アクティブなプロジェクトは、どのチャット、ファイル、ターミナル、ブラウザタブ、およびストッシュアイテムを表示するかを決定します。タスクを送信したりコマンドを実行する前に、選択されたタブを確認してください。関連するプロジェクトを隣接させたい場合、プロジェクトタブをドラッグして順序を変更できます。

## 外部からプロジェクトを再命名または開く

プロジェクトの **…** メニューを開き、**編集** を選択して表示名またはアイコンを変更します。アイコンをクリックして最大5MBの画像をアップロードし、**保存** をクリックします。カスタムアイコンをリセットすることで、プロジェクトに対して自動検出に戻ります。Dreamでプロジェクトを名前を変更しても、ディスク上のフォルダ名は変わりません。

メニューの**開くアプリ**の選択肢を使用して、プロジェクトを利用可能な外部エディタで開く。

## 前のチャットに戻る

プロジェクトタブの側に**戻る**と**進む**を使用して、開いたプロジェクトやチャットを再訪問できます。WindowsおよびLinuxでは**Alt+Left**と**Alt+Right**、macOSでは**Command+[**と**Command+]**を使用します。マウスのバックとフォワードボタンも機能します。

この履歴はプロジェクトおよびチャットの選択に従って記録されます。ツールパネルを切り替えることはエントリを追加しません。埋め込みブラウザには独自のナビゲーション履歴があります。ターミナルまたはコードエディタ内のキーボードショートカットは、そのツールの設定に従います。

## プロジェクトを閉じて再開する

1. プロジェクトの **…** メニューを開き、**閉じる** を選択します。
2. 返信したい場合は、プロジェクトの **+** ボタンをクリックして「はじめに」画面を開きます。
3. **最近閉じた項目**でプロジェクトを検索し、必要に応じて検索フィールドを使用する。
4. プロジェクトを選択して再開します。

プロジェクトを閉じると、その開いているタブが削除されるが、フォルダは削除されない。Dreamは可能な限り、チャットや開いているツールなどの保存されたプロジェクトコンテキストを復元する。閉じたプロジェクトを、ターミナルプロセスを継続するための手段として使用しないでください。

## ワークスペースコントロールを検索する

左のツールバーには **チャット履歴**、**新しいチャット**、**マルチチャットを有効化**があります。アイコンをホバーするとラベルが表示されます。チャット入力欄には選択されたモデル、サポートされている場合の努力と速度、および権限が表示されます。

右のツールバーはプロジェクトツールを開きます：

| ツール | 何ができるか |
| --- | --- |
| [Git](/docs/ja/git-workflows) | 変更を確認し、コミットし、履歴を閲覧し、ブランチのプルリクエストを管理する |
| [ファイル](/docs/ja/files) | ファイルを閲覧し、パスを検索し、ファイルの内容を編集する |
| [ブラウザ](/docs/ja/browser) | プレビューURLとウェブページを確認 |
| [ターミナル](/docs/ja/terminals) | プロジェクトコマンドを別々のセッションで実行する |
| [スタッシュ](/docs/ja/stash) | プロンプトを保存して後で実行する |

リポジトリプロジェクトにはGitコントロールが表示されます。チャットの下で、ブランチコントロールを使用してブランチを切り替えたり、[ワークツリーを作成](/docs/ja/worktrees)したりできます。隣接する**Git の操作**メニューは、ブランチの状態に応じてコミット、公開、プルリクエスト、およびワークツリーアクションを提供します。

## チャットとパネルを整理する

ツールをクリックしてパネルを開く。チャットにスペースが必要な場合、パネルの閉じるまたは折りたたみコントロールを使用する。パネルのディバイダーをドラッグしてレイアウトのサイズを調整する。ツールパネルを閉じることは、そのツールの個別のターミナルセッションやブラウザタブを閉じることとは異なります。

[multi-chat](/docs/ja/multiple-chats) を有効にし、会話の列をリサイズ可能なカラムに配置できます。各チャットは独自の会話履歴を持ちますが、プロジェクト内のすべてのチャットは同じファイルを使用します。独立したチェックアウトにはワークツリーを使用します。

## Dreamウィンドウをキャプチャする

Windows/Linuxでは**Ctrl+Shift+S**、macOSでは**Command+Shift+S**を押してDreamウィンドウをキャプチャできます。Dreamはスクリーンショットをクリップボードにコピーし、PNGとして保存するダイアログを開きます。保存ダイアログをキャンセルするとクリップボードのコピーが保持されます。通知は、画像がコピーされたか、保存されたか、またはキャプチャできなかったかを報告します。

ウェブページのスクリーンショットには、[ブラウザのスクリーンショット機能](/docs/ja/browser)を使用してください。

アプリ全体の外観、言語、モデルの設定については、[Settings](/docs/ja/settings)を開いてください。過去の会話を見つけるには、[Chat history](/docs/ja/chats)または[Archived chats](/docs/ja/archived-chats)を使用してください。
