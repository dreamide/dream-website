Dream is available as a desktop application for macOS, Windows, and Linux.

<Card title="Download Dream" icon="download" href="/download">
  Open the download page to select the package for your platform and architecture.
</Card>

## Available packages

| Platform | Packages |
| --- | --- |
| macOS | DMG for Apple silicon (ARM64) or Intel (x64) |
| Windows | Installer for x64 |
| Linux | DEB, RPM, or AppImage for x64 |

## Before opening Dream

Install and authenticate at least one [supported agent CLI](/docs/providers). Dream detects the CLI
and the models it makes available; API credentials and subscriptions remain managed by that
provider.

## Updates

Dream checks for application updates. When an update is available, use the update action in the app
or download the newest package from the [download page](/download).

<Tip>
  If Dream does not detect an installed CLI, confirm that the command works in your normal terminal,
  then refresh the provider from Dream's settings.
</Tip>

## Next steps

After installation, [connect a provider](/docs/providers) and enable at least one model. Then
[open your first project](/docs/first-project). You can choose the interface language, appearance,
and terminal shell in [Settings → General](/docs/settings#general).

If the app opens but you cannot start a conversation, check
[model and provider troubleshooting](/docs/troubleshooting#a-model-is-missing-or-i-cannot-start-a-chat).
