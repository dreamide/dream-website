Dream은 사용할 수 있는 모델들을 특정 작업에 사용할 모델과 구분합니다. **설정 → 제공자**는 사용 가능성을 제어합니다. **설정 → 일반**에서 **모델** 그룹은 기본값을 제어합니다. 각 채팅 메시지 상자 아래의 선택자는 해당 대화를 제어합니다.

## 모델 활성화

1. [지원되는 제공자 CLI](/docs/ko/providers)를 설치하고 인증하세요.
2. 열림 **설정 → 제공자** 및 제공자를 활성화합니다.
3. 제공자를 새로 고침하여 CLI 및 사용 가능한 모델을 탐지합니다.
4. Dream의 선택기에서 나타나는 모델을 활성화하세요.

여러 제공업체의 모델을 활성화할 수 있습니다. 선택기에서 모델이 누락된 경우 먼저 여기에서 활성화되었는지 확인하세요. 새로 고침은 가용성 여부를 감지하지만 기본 모델을 선택하는 것과는 별개입니다.

## 새로운 채팅의 기본 설정을 설정합니다

1. 열림 **설정 → 일반 → 모델**.
2. **기본 채팅 모델**에서 활성화된 모델을 선택합니다.
3. **추론 강도**와 **속도**를 선택할 수 있는 경우 해당 모델에 그 제어 옵션이 있는지 확인합니다.
4. 프로젝트로 돌아가 새 채팅을 시작하여 선택을 사용합니다.

기본 설정은 프로젝트 내에서 새로 생성되는 채팅에 적용됩니다. 기존 대화는 자체 모델 설정을 유지합니다. 만약 **새 채팅**이 이미 열린 빈 초안을 다시 가져오면, 그 초안의 편집기에서 모델을 변경해야 합니다.

## 커밋과 PR 작성에 모델을 설정하세요

같은 **모델** 그룹에서 **텍스트 생성 모델**을 선택하고, 지원되는 경우 노력과 속도를 설정합니다. Dream은 커밋 메시지와 풀리퀘스트 텍스트를 작성할 때 이러한 설정을 사용합니다.

예를 들어, 구현 대화에는 하나의 모델을 사용하고 Git 요약에는 다른 모델을 사용할 수 있습니다. Git 드래프트 모델을 변경해도 채팅 모델이 변경되지 않습니다. 생성된 텍스트를 출판하기 전에 검토하고 편집하려면 [Git 작업 흐름](/docs/ko/git-workflows)을 참조하세요.

## 채팅의 모델을 변경합니다

1. 대화를 열고 현재 응답이 끝날 때까지 기다려주세요.
2. 메시지 박스 아래 모델 이름을 클릭하세요.
3. 활성화된 모델을 선택하십시오. 다른 제공업체의 모델이 필요할 경우 해당 모델을 선택하십시오.
4. 다음 메시지를 보낼 전에 노력과 속도 제어를 확인하세요.

대화는 Dream에서 계속 보입니다. 모델을 변경하면 그 모델의 노력과 속도 선택이 초기화되므로 원하는 특정 값을 선택해야 할 경우 다시 선택해야 합니다. 모델 변경은 이후 작업을 위한 새로운 제공자 세션을 시작하지만 이미 생성된 메시지에는 영향을 주지 않습니다.

## 추론 강도와 속도

| 제어 | 목적 |
| --- | --- |
| 추론 강도 | 그 모델이 제공하는 추론 노력 수준을 선택합니다 |
| 속도 | 지원되는 속도 레이어 중 하나, 예를 들어 표준 또는 빠른 레이어를 선택합니다. |

이 컨트롤들은 선택한 모델이 이를 지원하는 경우에만 나타납니다. 사용 가능한 노력 수준은 모델에 따라 다릅니다. 속도 테일러는 다른 사용 조건을 가질 수 있으므로, 테일러 선택 시 옵션 설명과 제공업체의 사용 정보를 참조하시기 바랍니다.

기본 노력과 속도는 새 채팅에 적용됩니다. 채팅에서 어느 하나를 변경하면 해당 대화에 영향을 미칩니다. 속도를 변경하면 이후 작업을 위한 제공자 세션을 초기화합니다.

## 기본값이 사용할 수 없을 경우

선택한 기본 모델을 비활성화하거나 변경된 모델 목록을 새로고침할 경우 Dream이 다른 활성 모델을 선택할 수 있습니다. 활성 모델을 변경한 후에는 두 개의 기본 선택자 모두를 다시 확인하세요. 활성 모델이 없으면 새 채팅을 시작하기 전에 하나를 활성화하세요.

제어 요소가 누락되었거나 감지 실패가 발생했을 경우, [문제 해결](/docs/ko/troubleshooting)을 참조하세요.
