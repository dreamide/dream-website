## Dream이 포함하는 내용은 무엇인가?

- 기존 프로젝트 탭을 유지하는 다 프로젝트 워크스페이스
- 원격 에이전트, 파일, Git, 터미널을 지원하는 [SSH 원격 작업 공간](/docs/ko/remote-hosts)
- 다중 측면 병렬 채팅 및 채팅 분기
- 프로젝트 간에 재사용 가능한 프롬프트 및 제공자 인식 애그 업무 기술
- 대화별 체크포인트를 통해 에이전트가 변경한 파일을 검토하고 복원합니다
- Codex CLI, Claude Code CLI, OpenCode CLI, Cursor Agent CLI, 및 Grok Build CLI 지원
- 파일 탐색기, 파일 검색 및 편집, 통합 터미널, 브라우저 미리보기
- Git 상태, 브랜치, 차이, 커밋, 푸시, 풀리퀘스트, 워크트리 워크플로우, 완료된 워크트리가 기반 브랜치로 병합되는 경우 포함
- 라인 레벨 다이프 피드백과 브라우저 요소 선택이 채팅에 타겟을 맞춘 메시지를 전송합니다
- 코드 검토, 댓글 작성, 세부 정보 편집 및 머지에 사용되는 GitHub 풀리퀘스트 패널
- 설정 가능한 MCP 서버 및 브라우저 상호작용을 위한 내장된 에이전트 도구

<Note>
  Dream은 설치된 CLIs를 통해 코딩 에이전트를 실행합니다. 채팅을 시작하기 전에 최소한 하나의 지원되는 CLI를 설치해야 합니다.
</Note>

## 작업 공간을 이해하세요

**프로젝트**는 컴퓨터 또는 SSH 호스트에 있는 폴더로, 자체 채팅과 도구를 갖습니다. **채팅**은 자체 모델과 설정을 갖는 대화입니다. 같은 프로젝트의 여러 채팅은 파일을 공유하며, **작업 트리**는 작업에 별도의 Git 작업 사본을 제공합니다.

[에이전트 권한](/docs/ko/agent-modes)에서 에이전트의 동작 방식을 선택하고, [컨텍스트와 사용량](/docs/ko/context-and-usage)에서 입력창 아래에 표시되는 정보를 확인하세요. [설정 안내](/docs/ko/settings)에는 앱 전체에 적용되는 환경설정이 나와 있습니다. 기능이 보이지 않거나 실행되지 않는다면 [문제 해결](/docs/ko/troubleshooting)부터 살펴보세요.
