로컬 및 원격 프로젝트를 함께 열 수 있습니다. 파일, Git, 에이전트, 터미널은 프로젝트 호스트에서 동작합니다. 프로젝트 탭과 채팅 하단에 호스트가 표시됩니다.

두 가지 방법으로 연결합니다.

| 경로 | 사용 조건 | 요구 사항 |
| --- | --- | --- |
| SSH | `ssh`로 접속 가능한 컴퓨터 | SSH 대상. Dream이 호스트를 설치하고 시작합니다. |
| HTTPS | Dream 또는 `dream-host`에서 [원격 액세스](/docs/ko/remote-access) 활성화 | 호스트 주소 및 페어링 코드 |

두 종류의 경로를 함께 등록할 수 있습니다. [경로](/docs/ko/remote-hosts#경로)를 참고하세요.

## SSH 호스트 추가

1. 시스템 터미널에서 `ssh devbox`가 작동하는지 확인하세요. `devbox`는 SSH 설정 별칭 또는 `user@host`로 바꿉니다. Dream은 시스템의 SSH 클라이언트, 설정, 키를 사용합니다.
2. **설정 → 연결**를 열고 **원격 호스트**에서 **호스트 추가**, **SSH 호스트** 순으로 선택하세요.
3. **SSH 대상**를 입력하세요. SSH 설정의 별칭이 제안됩니다. 이름을 생략하면 대상이 이름이 됩니다.
4. **저장**를 클릭하면 바로 연결됩니다.
5. Dream에서 호스트 키, 비밀번호, 암호문 또는 2단계 인증 요청에 응답하세요. 요청을 거부하거나 취소하면 해당 연결 시도가 중지됩니다.

연결 시 버전에 맞는 호스트를 `~/.dream/host/versions/`에 설치하고 시작합니다. 직접 다운로드할 수 없으면 로컬에서 받아 SSH로 전송합니다. 원격 컴퓨터에 에이전트 CLI를 설치하고 로그인하세요.

SSH 호스트는 Linux x64 및 ARM64(glibc 2.31 이상), Apple silicon macOS를 지원합니다. 접속 앱은 Windows, macOS, Linux에서 사용할 수 있습니다.

## HTTPS로 호스트 페어링

SSH가 어렵다면 코드를 사용하세요. 예를 들어 Tailscale 또는 Cloudflare Tunnel로 사무실 컴퓨터에 연결할 수 있습니다.

1. 다른 컴퓨터에서 [원격 액세스](/docs/ko/remote-access)를 켜고 **기기 페어링** 또는 `dream-host pair`로 코드를 발급하세요.
2. 이 컴퓨터의 **설정 → 연결**에서 **호스트 추가**, **페어링 코드**를 선택하세요.
3. **호스트 주소** 및 **페어링 코드**를 입력하세요. 이름은 선택 사항입니다.
4. **호스트 페어링**를 클릭하세요.

코드는 10분간 한 번만 유효합니다. 이 컴퓨터가 호스트의 HTTPS 인증서를 신뢰해야 합니다. 계정은 필요 없으며 호스트에서 해제할 때까지 페어링이 유지됩니다.

## 경로

**원격 호스트**에는 호스트마다 한 항목이 표시됩니다. **편집**로 경로를 열고 **SSH 경로 추가** 또는 **HTTPS 경로 추가**로 추가하세요. 같은 창에서 이름도 바꿀 수 있습니다.

위에서 아래로 연결을 시도합니다. **위로 이동** 및 **아래로 이동**로 정렬하고 **경로 삭제**로 삭제하세요. 하나 이상 남겨야 합니다. 우선 경로가 실패하면 다음으로 전환합니다.

호스트 사이트를 [브라우저](/docs/ko/browser)에서 미리 보거나 **다음에서 열기**로 외부 편집기를 쓰려면 SSH 경로가 필요합니다. HTTPS만으로도 프로젝트, 채팅, 파일, Git, 터미널을 쓸 수 있습니다.

## 원격 프로젝트 열기

1. 프로젝트 탭 옆의 **+**, 이어서 **폴더 열기**를 클릭하세요.
2. **폴더 열기** 창의 **열 위치**에서 호스트를 선택하세요. 필요하면 자동으로 연결됩니다.
3. **폴더 경로**를 입력하세요. 호스트의 일치하는 폴더가 표시되며 **Tab**으로 선택된 경로를 완성합니다.
4. **열기**를 클릭하세요. 원격 폴더가 자체 채팅과 도구를 갖는 프로젝트 탭으로 열립니다.

등록한 호스트가 없으면 하단의 **SSH 호스트 추가…**를 사용하세요.

닫은 원격 프로젝트는 호스트 및 경로와 함께 **최근 닫힘**에 나타납니다. 다시 열면 해당 호스트에 연결됩니다. 원격 경로는 원격 컴퓨터에 속하므로 Dream 외부에서 파일을 열 때는 그 컴퓨터에 연결된 편집기를 사용하세요.

## 호스트 재연결 또는 제거

**설정 → 연결**에 연결 상태가 표시됩니다. 연결이 끊기면 자동 재시도하며 탭은 유지되지만 재연결 전에는 보낼 수 없습니다. 재시도가 멈추면 오류를 확인하고 채팅의 **다시 연결** 또는 **연결**(**설정 → 연결** 안)를 선택하세요.

연결이 끊겨도 호스트에서 턴이 계속되며 재연결하면 다시 진행 상황을 봅니다.

**연결 해제**는 탭을 유지합니다. **제거**는 확인 후 작업 공간에서 호스트와 프로젝트를 제거하고 터미널을 중지합니다. 호스트의 파일과 채팅은 유지됩니다.

## 연결 문제

시스템 터미널에서 같은 SSH 대상을 테스트하고 인증이나 호스트 키 문제를 해결하세요. 시작 실패 시 **설정 → 연결**의 오류와 지원 플랫폼을 확인하세요.

HTTPS 거부 오류는 버전 불일치 또는 권한 부족을 표시합니다. 버전을 맞추거나 새 코드로 다시 페어링하세요.

개발 빌드는 Dream 저장소에서 `pnpm host:install-dev devbox`를 실행하고 다시 연결하세요. 원격 빌드에는 Node.js 22 이상, pnpm 또는 Corepack, make, Python 3, C++ 도구(g++ 10 이상)가 필요합니다. 설치 프로그램은 교체 전 기존 개발 데몬을 중지합니다.
