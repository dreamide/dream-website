Dream은 로컬 프로젝트와 함께 SSH를 통해 원격 컴퓨터의 프로젝트를 열 수 있습니다. 파일, Git 명령, 에이전트 프로세스, 터미널은 프로젝트 호스트에서 실행됩니다. 프로젝트의 호스트 레이블에서 작업 위치를 확인할 수 있습니다.

SSH 작업 공간은 Dream v0.25.0부터 사용할 수 있습니다. 이 릴리스에는 Linux x64, Linux ARM64, macOS Apple silicon(ARM64)용 관리형 호스트 런타임이 포함됩니다. 이는 원격 호스트의 지원 플랫폼이며, Dream 데스크톱 앱은 Windows, macOS, Linux에서 실행할 수 있습니다.

## 호스트 추가 및 연결

1. 시스템 터미널에서 `ssh devbox`가 작동하는지 확인하세요. `devbox`는 SSH 설정 별칭 또는 `user@host`로 바꿉니다. Dream은 시스템의 SSH 클라이언트, 설정, 키를 사용합니다.
2. **설정 → SSH 호스트**를 열고 **SSH 호스트 추가**를 선택하세요. **SSH 대상**과 선택 사항인 **이름**을 입력합니다.
3. 런타임을 자동으로 설치하려면 **호스트 명령**을 비워 두세요. **저장**을 클릭한 다음 **연결**을 클릭합니다.
4. Dream에서 호스트 키, 비밀번호, 암호문 또는 2단계 인증 요청에 응답하세요. 요청을 거부하거나 취소하면 해당 연결 시도가 중지됩니다.

관리형 런타임은 버전별로 `~/.dream/host/versions/`에 설치됩니다. 호스트에서 런타임을 다운로드할 수 없으면 Dream이 로컬로 다운로드한 뒤 SSH로 업로드할 수 있습니다. 에이전트 CLI도 원격 컴퓨터에 설치하고 로그인하세요. CLI는 해당 컴퓨터의 환경에서 실행됩니다.

런타임을 수동으로 설치한 경우 **호스트 명령**을 원격 컴퓨터에서 `dream-host`를 실행하는 명령으로 설정하세요.

## 원격 프로젝트 열기

아직 호스트를 추가하지 않았다면 **SSH 호스트에서 열기**를 선택할 때 **설정 → SSH 호스트**로 바로 이동합니다. 호스트를 추가한 다음 시작 화면으로 돌아와 폴더를 여세요.

1. 시작 화면에서 **SSH 호스트에서 열기**를 선택하세요. 프로젝트 **+** 버튼으로 이 화면에 돌아올 수 있습니다.
2. **호스트**를 선택하고 필요한 경우 연결하세요. **홈 폴더**, **상위 폴더**, **숨김 폴더 표시**로 폴더를 탐색하거나 **폴더 경로**를 직접 입력합니다.
3. **열기**를 클릭하세요. 원격 폴더가 자체 채팅과 도구를 갖는 프로젝트 탭으로 열립니다.

닫은 원격 프로젝트는 호스트 및 경로와 함께 **최근 닫힘**에 나타납니다. 다시 열면 해당 호스트에 연결됩니다. 원격 경로는 원격 컴퓨터에 속하므로 Dream 외부에서 파일을 열 때는 그 컴퓨터에 연결된 편집기를 사용하세요.

## 호스트 재연결 또는 제거

Dream은 중단된 연결을 다시 시도합니다. 호스트를 사용할 수 없어도 프로젝트 탭은 유지되며, 재연결될 때까지 메시지 전송이 비활성화됩니다. 재연결이 멈추면 표시된 오류를 확인하고 **다시 연결** 또는 **연결**(**설정 → SSH 호스트** 내)을 사용하세요.

**편집**으로 호스트 이름, 대상, 명령을 변경하세요. 대상이나 명령을 변경하면 활성 연결을 다시 설정합니다. **연결 해제**는 프로젝트 탭을 유지합니다. **제거**는 원격 파일이나 호스트 카탈로그를 삭제하지 않고 이 Dream 작업 공간에서 호스트와 해당 프로젝트를 제거합니다.

## 연결 문제

먼저 시스템 터미널에서 동일한 SSH 대상을 확인하세요. 인증 또는 호스트 키 문제를 해결한 뒤 재연결합니다. 호스트 런타임이 시작되지 않으면 **설정 → SSH 호스트**의 오류를 읽고 설정된 **호스트 명령** 또는 플랫폼용 런타임의 제공 여부를 확인하세요.

개발 빌드에는 다운로드할 수 있는 게시된 런타임이 없습니다. Dream 앱 저장소에서 `pnpm host:install-dev devbox`를 실행한 뒤 **호스트 명령**을 비운 상태로 다시 연결하세요. 원격 빌드에는 Node.js 22 이상, pnpm 또는 Corepack, make, Python 3, C++ 도구 모음(g++ 10 이상)이 필요합니다. 설치 프로그램은 런타임을 교체하기 전에 기존 개발 호스트 데몬을 중지합니다.
