Dream은 이미 컴퓨터에 설치된 코딩 에이전트 명령행 도구들과 함께 작동합니다.

## 지원되는 제공업체

| 제공자 | 필수 CLI |
| --- | --- |
| OpenAI | Codex CLI |
| Anthropic | Claude Code CLI |
| OpenCode | OpenCode CLI |
| Cursor | Cursor Agent CLI |
| Grok 빌드 | Grok 빌드 CLI |

제공자에서 CLI를 설치한 후, Dream 외부에서 해당 CLI의 일반적인 로그인 또는 인증 흐름을 완료합니다.

## 모델 활성화

1. Dream에서 **설정**을 열기.
2. **제공자**를 선택합니다.
3. CLI를 설치하거나 인증한 후 제공자를 새로 고침합니다.
4. 제공자에 대한 활성화 스위치를 켜고, 탐지된 모델 중 하나 이상을 활성화합니다.
5. 열림 **일반 → 모델** 및 새 채팅과 커밋 및 풀리퀘스트 작성에 대한 기본값을 선택합니다.

첫 프로젝트를 열기 전에 최소한 하나의 모델을 활성화해야 합니다. 채팅이 시작된 후에는 기본 모델 외에 다른 활성 모델을 사용할 수 있습니다.

## 다른 제공자를 사용하세요

사용하고자 하는 각 제공업체의 모델을 활성화합니다. 채팅 구성 요소는 활성화된 모델들을 목록으로 표시하므로, 다른 대화에서 다른 제공업체를 선택하거나 현재 채팅에서 모델을 변경할 수 있습니다.

예를 들어, 구현 채팅은 하나의 제공업체를 유지하고 다른 제공업체를 사용하여 리뷰 채팅을 생성할 수 있습니다. 매번 전역 기본 설정을 변경할 필요는 없습니다. [모델과 기본 설정](/docs/ko/models)을 따르며 새 채팅 기본 설정, 추론 노력, 속도, 그리고 별도의 Git 드래프트 모델을 구성할 수 있습니다.

## 제공자 차이를 이해하세요

설치된 CLI는 인증을 처리하고 에이전트 작업을 실행한다. 모델 목록, 지원되는 노력과 속도 옵션, 첨부 파일 처리, 사용 정보, 권한 행동은 제공업체마다 다를 수 있다.

Dream은 각 채팅에 대해 **물어보기**, **편집 승인**, 그리고 **전체 액세스** 권한을 제공합니다. 권한을 선택하기 전에 [에이전트 권한](/docs/ko/agent-modes)을 읽어보세요. 클라우드는 재개시 가능한 세션을 통해 [터미널에서 계속](/docs/ko/terminals#터미널에서-클라우드-채팅을-계속하기) 채팅을 진행합니다.

[스킬](/docs/ko/skills)은 Claude Code, Codex, OpenCode, Cursor에서 사용할 수 있습니다. [MCP 서버](/docs/ko/mcp-servers)와 Dream의 내장 브라우저 도구는 Claude Code, Codex, OpenCode, Grok Build에서 사용할 수 있습니다. Cursor는 Dream이 관리하는 이러한 도구 연결을 지원하지 않습니다.

## CLI 업데이트를 확인하세요

제공자 카드는 설치된 CLI 버전이 있는 경우 해당 버전을 표시합니다. Dream은 새 버전이 있는지 확인하며, 새 버전이 발견되면 **업데이트 가능: …** 배지을 표시합니다. 배지는 사용 가능성을 보여주며, 업데이트를 설치하지 않습니다. 해당 CLI의 일반적인 설치 방법을 사용하여 업데이트한 후, Dream에서 제공자 카드를 다시 새로고침합니다.

제공자에 대한 enable 스위치를 사용하여 모델을 사용 가능한 선택지에서 숨길 수 있으며 CLI를 제거하지 않고도 가능합니다. 활성화된 제공자 또는 모델을 변경한 후에는 기본 설정을 다시 확인하세요.

## 문제 해결 탐지

만약 제공업체가 **CLI를 탐지하지 못했습니다**라고 말하면:

1. 시스템 터미널을 열고 CLI 명령어가 성공적으로 시작되는지 확인하세요.
2. CLI에서 요구하는 로그인 또는 첫 실행 설정을 완료합니다.
3. **설정 → 제공자**로 돌아가 새로 고침하세요.
4. OpenCode에서 인증 흐름을 실행하거나 모델이 나타나지 않는 경우 `opencode.json`을 구성하세요.

드림이 열려 있던 중 CLI가 설치된 경우, 여전히 새로고침이 이를 감지하지 못할 경우 드림을 재시작해야 합니다. 명령어는 드림의 환경에서 사용 가능해야 하며, 쉘 앨리어스만으로는 설치된 CLI가 아닙니다.

CLI가 감지되었지만 원하는 모델이 누락된 경우, 제공업체의 계정/설정을 확인하고 목록을 새로 고침하세요. 모델이 목록에 있지만 채팅에서 사용할 수 없는 경우, 토글을 사용하여 모델을 활성화하고 제공업체 자체가 활성화되었는지 확인하세요. 추가적인 점검을 위해 [문제 해결](/docs/ko/troubleshooting)을 참조하세요.
