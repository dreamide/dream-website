각 채팅에는 메시지 박스 아래에 **권한** 제어가 있습니다. 새 채팅은 **설정 → 일반 → 모델 → 기본 권한**을 상속하며, 기본적으로 **전체 액세스**로 시작됩니다. 기본 권한을 변경해도 기존 채팅에 영향을 주지 않습니다.

## 권한 선택

1. 메시지 입력란 아래의 방패 아이콘을 누르세요. 툴팁에는 **권한**이 표시됩니다.
2. **물어보기**, **편집 승인**, 또는 **전체 액세스**를 선택하세요.
3. 작업 내용을 확인하고 전송하세요.

| 권한 | 기대되는 행동 |
| --- | --- |
| 물어보기 | 제공자 구성에서 허가가 필요한 작업에 대해 승인을 요청합니다. |
| 편집 승인 | 파일 편집을 자동으로 허용하면서 다른 작업에 대해 승인 처리를 유지합니다. |
| 전체 액세스 | агент에 승인 요청 없이 더 넓은 권한을 부여합니다 |

권한의 정확한 동작은 선택한 제공업체에 따라 달라집니다. **물어보기**을 선택해도 모든 읽기 작업이나 도구 호출에서 승인을 요청하는 것은 아니며, **편집 승인**을 선택해도 모든 명령이 승인되는 것은 아닙니다.

<Note>
  Dream에는 더 이상 Build와 Plan을 위한 별도의 컨트롤이 없습니다. 먼저 계획을 세우려면 변경하기 전에 조사하고 접근 방법을 제안하도록 에이전트에게 요청하세요. 이 지시만으로 파일 시스템 접근이 읽기 전용으로 제한되지는 않습니다. 작업에 적합한 권한도 함께 선택하세요.
</Note>

## 질문에 응답하고 승인을 처리합니다

애그런트는 당신에게 요구사항을 명확히 하거나 선택지를 선택하거나 조치를 승인하도록 요청할 수 있습니다. 대화에서 요청을 읽고 제공된 컨트롤을 사용하여 응답하세요. 프로젝트 탭은 애그런트가 당신의 답변을 기다리고 있다는 것을 나타낼 수 있습니다. 해당 프로젝트를 열고 대화로 돌아가 요청을 다시 읽으세요.

작업을 변경해야 한다면 해당 채팅에서 에이전트에게 수정된 지시를 전달하세요. 필요할 때 중지 컨트롤로 응답을 중단하세요. 중지해도 이미 완료된 편집이나 명령은 되돌려지지 않습니다. 이후 [변경 사항](/docs/ko/git-workflows)을 확인하거나 응답의 [체크포인트](/docs/ko/checkpoints)를 사용해 변경된 파일을 복원하세요.

서로 다른 파일을 필요로 하는 병렬 작업에는 [워크트리](/docs/ko/worktrees)를 사용하십시오. 권한 설정은 같은 폴더에 있는 두 개의 채팅이 독립된 체크아웃을 가지지 않습니다.
