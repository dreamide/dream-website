---
title: "원격 액세스"
description: "Tailscale 또는 Cloudflare Tunnel로 기기를 페어링해 휴대폰이나 다른 컴퓨터에서 프로젝트를 사용하세요."
---

페어링된 기기는 브라우저나 데스크톱 앱에서 연결합니다. 에이전트, 파일, 터미널, Git은 이 컴퓨터에서 작동합니다.

기본적으로 꺼져 있습니다. 네트워크 경로를 준비하고 기기마다 페어링하세요. Dream 계정이나 중계 서비스는 필요하지 않습니다.

## 연결 방법 선택

| 옵션 | 작동 방식 | 요구 사항 |
| --- | --- | --- |
| Tailscale | tailnet 내에서 HTTPS로 제공 | 모든 기기에 Tailscale 설치 및 tailnet에서 MagicDNS와 HTTPS 인증서 활성화 |
| Cloudflare Tunnel | 소유 도메인의 공개 호스트 이름으로 제공 | Cloudflare 계정의 지속 터널 및 직접 실행하는 `cloudflared` 커넥터 |

자체 리버스 프록시도 가능합니다. [호스트 실행](/docs/ko/dream-host#명령줄에서-원격-액세스-사용하기)을 참고하세요.

## 원격 액세스 켜기

1. **설정 → 연결**에서 **원격 액세스**를 찾으세요.
2. **설정**를 클릭하세요.
3. **이 컴퓨터에 연결하는 방법**에서 **Tailscale** 또는 **Cloudflare Tunnel**를 선택하세요.
4. Tailscale은 **HTTPS 포트**를 확인하세요. Cloudflare Tunnel은 **공개 주소**에 `https://dream.example.com` 등을 입력하세요.
5. 고정 포트가 필요 없으면 **로컬 포트**를 비워 두고 **켜기**를 클릭하세요.

연결되면 **페어링된 기기 허용** 옆에 **준비됨**가 표시됩니다. **준비되지 않음**라면 문제를 해결하고 **다시 확인**를 누르세요. **변경**로 설정을 바꾸거나 **페어링된 기기 허용**를 꺼서 페어링을 유지한 채 접속을 중단하세요.

### Cloudflare 터널 설정

`cloudflared`는 직접 실행하세요. Dream에는 공개 주소와 로컬 대상 포트만 필요합니다. 터널 토큰은 필요하지 않습니다.

1. Cloudflare 대시보드에서 터널을 만들고 표시된 설치 명령을 이 컴퓨터에서 실행하세요.
2. 도메인의 호스트 이름에 경로를 추가하고 서비스는 `HTTP`, 대상은 `127.0.0.1:5410` 또는 Dream에 표시된 **로컬 포트**로 설정하세요.
3. 호스트 이름이 직접 API 및 WebSocket 요청을 받도록 하세요. Cloudflare Access 로그인이나 브라우저 검증을 앞에 두지 말고 `/api/*` 캐싱과 버퍼링을 끄세요.

Quick Tunnels는 주소가 바뀌고 채팅 스트림을 전송할 수 없어 지원하지 않습니다.

## 기기 페어링

1. 준비되면 **기기 페어링**를 클릭하세요.
2. **액세스**에서 권한 수준을 선택하세요.
3. **페어링 만들기**를 클릭하면 **페어링 코드** 및 **호스트 주소**가 표시됩니다.
4. 다른 기기의 브라우저에서 호스트 주소를 열고 코드와 **기기 이름**을 입력한 뒤 **페어링**를 누르세요.

다른 데스크톱 앱에서는 같은 주소와 코드로 [이 컴퓨터를 호스트로 추가](/docs/ko/remote-hosts#https로-호스트-페어링)하세요.

코드는 10분간 한 번만 유효합니다. 선택한 권한을 부여하므로 대상 기기에만 전달하세요.

| 접근 권한 | 기기에서 할 수 있는 작업 |
| --- | --- |
| 보기 전용 | 프로젝트, 채팅, 터미널 읽기 |
| 보기 및 작업 | 추가로 사용자 권한으로 에이전트, 터미널, Git 실행 |
| 전체 권한 | 추가로 기기 페어링 및 제거 |

## 페어링한 기기에서 사용

브라우저에 이 컴퓨터의 프로젝트, 채팅, 파일, 터미널, Git이 표시됩니다. **브라우저**, **설정 → 연결**, 다른 호스트의 폴더 열기 및 편집기용 **다음에서 열기**는 데스크톱 전용입니다.

연결이 끊기면 재연결 중이거나 저장된 데이터를 표시 중이라는 배너가 나옵니다. 호스트 작업은 계속됩니다. 기기에서 해제하려면 **설정**에서 **로그아웃**를 선택하세요.

## 페어링된 기기 관리

**페어링된 기기**에서 권한과 마지막 사용 시각을 봅니다. **취소**로 한 대, **모두 취소**로 모두 해제하세요. 해제된 기기의 열린 페이지도 즉시 접근 권한을 잃지만 호스트 작업은 계속됩니다.

## 컴퓨터를 연결 가능한 상태로 유지

컴퓨터가 깨어 있고 호스트가 실행 중이어야 연결할 수 있습니다. 앱이 시작한 호스트는 Dream 종료 시 중지됩니다. 백그라운드나 헤드리스 실행은 [호스트 실행](/docs/ko/dream-host)을 참고하세요.

버전 차이가 표시되면 오래된 쪽을 업데이트하고 호스트를 재시작하세요.
