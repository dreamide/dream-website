title: "원격 액세스"
description: "휴대폰, 브라우저 또는 다른 Dream 데스크톱에서 이 컴퓨터의 프로젝트를 사용합니다."
---

원격 액세스를 사용하면 다른 기기에서 이 컴퓨터의 프로젝트로 작업할 수 있습니다. 휴대폰이나 다른 컴퓨터는 브라우저에서 Dream을 열고, 다른 Dream 데스크톱은 이 컴퓨터를 [원격 호스트](/docs/ko/remote-hosts#https로-호스트-페어링)로 추가할 수 있습니다. 모든 기기는 먼저 페어링해야 하며, 언제든지 액세스를 취소할 수 있습니다.

에이전트, 터미널, Git 명령은 여전히 이 컴퓨터에서 실행됩니다. 페어링된 기기는 이 컴퓨터에서 Dream 호스트가 실행 중일 때만 연결할 수 있습니다. Dream을 닫은 뒤에도 호스트를 계속 실행하려면 [서비스](/docs/ko/host-service)로 설치하세요.

## 시작하기 전에

기기가 이 컴퓨터에 연결할 방법을 선택하세요:

| 연결 방식 | 필요한 것 |
| --- | --- |
| Tailscale | 이 컴퓨터와 각 기기에 Tailscale이 설치되어 로그인되어 있고, tailnet에서 MagicDNS와 HTTPS 인증서가 켜져 있어야 함 |
| Cloudflare Tunnel | Cloudflare 계정의 영구 Cloudflare Tunnel과 호스트 이름(예: `dream.example.com`) |

Cloudflare Tunnel의 경우 전용 원격 관리 터널을 만들고 커넥터 토큰만 복사하세요. 호스트 이름을 Dream에 표시되는 **로컬 포트**의 `http://127.0.0.1`로 라우팅하고, `/api/*`는 캐시를 우회하도록 설정하세요. Quick Tunnel은 지원되지 않으며, 호스트 이름에 대화형 Cloudflare Access 로그인을 요구할 수 없습니다.

## 원격 액세스 켜기

1. **설정 → 연결**을 열고 **원격 액세스**를 찾습니다.
2. **설정**을 선택합니다.
3. **이 컴퓨터에 연결하는 방법**에서 **Tailscale** 또는 **Cloudflare Tunnel**을 선택합니다.
4. Cloudflare Tunnel의 경우 **공개 주소**를 입력하고 **터널 토큰**을 붙여 넣습니다. 커넥터에 **설치되지 않음**이 표시되면 **cloudflared 설치**를 선택합니다.
5. **켜기**를 선택합니다.

Dream은 연결을 확인한 뒤 **준비됨**을 표시합니다. **준비되지 않음**이 표시되면 아래 메시지를 읽고 설정을 수정한 다음 **다시 확인**을 사용하세요. 일부 메시지에는 **설정 페이지 열기**가 포함됩니다.

연결 방식을 바꾸거나 터널 토큰을 교체하려면 **변경**을 사용하세요. 저장된 토큰을 유지하려면 토큰을 비워 두세요. **페어링된 기기 허용** 스위치를 사용하면 설정이나 페어링된 기기를 잃지 않고 원격 액세스를 끄고 켤 수 있습니다.

### 고급 옵션

| 옵션 | 무엇을 하는지 |
| --- | --- |
| HTTPS 포트 | Tailscale이 Dream을 제공하는 포트입니다. Tailscale이 이미 해당 포트에서 다른 것을 제공하고 있으면 변경하세요 |
| 로컬 포트 | 이 컴퓨터에서 원격 연결을 받는 포트입니다. 자동으로 선택하려면 비워 두세요 |
| cloudflared를 직접 실행합니다 | 별도로 설치하고 실행하는 Cloudflare 커넥터를 사용합니다. Dream은 이를 시작, 중지 또는 삭제하지 않습니다 |

## 기기 페어링

1. 원격 액세스가 **준비됨** 상태일 때 **기기 페어링**을 선택합니다.
2. 기기의 **액세스** 수준을 선택합니다.
3. **페어링 만들기**를 선택합니다.
4. 기기에서 QR 코드를 스캔하거나 링크를 엽니다. **링크 복사**를 사용해 링크를 보낼 수도 있습니다.
5. **완료**를 선택합니다.

| 액세스 | 기기에서 할 수 있는 일 |
| --- | --- |
| 보기 전용 | 프로젝트, 채팅, 터미널 읽기 |
| 보기 및 작업 | 추가로 사용자 권한으로 에이전트, 터미널, Git 실행 |
| 전체 | 추가로 기기 페어링 및 제거 |

링크는 한 번만 사용할 수 있으며 10분 후에 만료됩니다. 링크 없이 페어링하려면 기기에서 호스트 주소를 열고, QR 코드 옆에 표시된 페어링 코드를 입력한 다음 기기 이름을 지정하세요. 그러면 이 컴퓨터에서 **확인**을 선택할 때까지 기기가 대기합니다. 확인은 **페어링 대기 중** 아래에서 할 수 있습니다. 알 수 없는 기기는 **거부**를 선택하세요.

다른 Dream 데스크톱을 페어링하려면 해당 데스크톱의 **호스트 추가 → 페어링 링크** 대화 상자에 링크를 붙여 넣으세요. [HTTPS로 호스트 페어링](/docs/ko/remote-hosts#https로-호스트-페어링)을 참조하세요.

## 페어링된 기기에서 Dream 사용

페어링된 기기는 브라우저에서 Dream을 엽니다. 휴대폰에서는 Dream이 간결한 레이아웃을 사용합니다. 기기는 액세스 수준 범위 내에서 이 컴퓨터의 프로젝트, 채팅, 파일, 터미널로 작업할 수 있습니다.

이 컴퓨터에 연결할 수 없으면 배너로 알려 주고, 기기에는 저장된 내용이 표시됩니다. 호스트를 다시 사용할 수 있게 되면 Dream이 다시 연결합니다. 절전 모드인 컴퓨터에는 연결할 수 없습니다.

기기 자체에서 해당 기기의 액세스 권한을 제거하려면 **로그아웃**을 선택하세요. 이 버튼은 **이 기기** 아래에 있습니다. 로그아웃하면 해당 브라우저에 저장된 내용도 삭제됩니다.

## 페어링된 기기 관리

**페어링된 기기**에는 각 기기와 마지막 사용 시점이 나열됩니다. 기기의 액세스 권한을 제거하려면 **취소**를 선택하세요. 해당 기기에서 열린 페이지는 즉시 중지되지만, 이 컴퓨터의 작업은 계속됩니다. 30일 동안 사용하지 않은 기기는 다시 페어링해야 합니다.

## 원격 액세스 문제

| 메시지 또는 증상 | 무엇을 해야 할지 |
| --- | --- |
| Tailscale이 설치되어 있지 않거나 실행 중이 아님 | Tailscale을 설치하고 로그인한 뒤 이 컴퓨터를 연결한 다음 **다시 확인**을 선택하세요 |
| 이 컴퓨터가 승인을 기다리고 있음 | Tailscale 관리 콘솔에서 승인하세요 |
| MagicDNS와 HTTPS 인증서를 켜세요 | Tailscale 관리 콘솔에서 tailnet에 대해 둘 다 활성화하세요 |
| Tailscale이 이 사용자의 Serve 설정 변경을 허용하지 않음 | Linux에서는 `sudo tailscale set --operator=$USER`를 한 번 실행한 다음 다시 확인하세요 |
| 다른 프로그램이 이미 포트를 사용 중임 | 다른 **HTTPS 포트** 또는 **로컬 포트**를 선택하세요. 두 항목은 **고급**에 있습니다 |
| Tailscale을 통해 이 컴퓨터에 연결할 수 없음 | Tailscale이 아직 인증서를 받는 중일 수 있습니다. 1분 후 다시 확인하세요 |
| Cloudflare를 통해 이 컴퓨터에 연결할 수 없음 | Cloudflare에서 호스트 이름의 서비스 URL을 Dream에 표시된 **로컬 포트**의 `http://127.0.0.1`로 설정하세요 |
| Cloudflare 커넥터가 연결되기를 기다리는 중 | 터널 토큰과 이 컴퓨터에서 나가는 연결이 허용되는지 확인하세요 |
| 페어링 링크가 만료되었거나 이미 사용됨 | **기기 페어링**을 다시 선택하고 새 링크를 사용하세요 |
| 기기가 작동하지 않음 | 취소되었거나 30일 동안 사용되지 않았는지 확인한 다음 다시 페어링하세요 |
