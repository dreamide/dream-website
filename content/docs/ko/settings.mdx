드림의 상단에 있는 기어 아이콘으로 **설정**을 열어라. 왼쪽 메뉴에는 **일반**, **제공자**, **SSH 호스트**, **프롬프트**, **스킬**, **MCP 서버**, 그리고 **보관된 채팅**이 있다. 일반 설정은 선택할 때마다 적용된다. 프롬프트, 스킬, 서버 정의에 대한 폼은 각각 자체적인 생성 또는 저장 액션을 제공한다.

## 일반

| 설정 | 어떤 것을 제어하는지 |
| --- | --- |
| 언어 | 인터페이스 언어 |
| 터미널 | 새로운 터미널 세션에 사용되는 쉘 |
| 테마 | 시스템, 밝은, 어두운 모양 |
| 기본 색상 | 인터페이스의 회색 톤들 |
| 강조 색상 | 주요 동작 및 활성 상태 |

터미널 쉘을 변경하면 새 세션에 영향을 미칩니다. 선택을 사용하려면 새 터미널을 열어 주세요; [Terminals](/docs/ko/terminals)을 참조하세요.

### 채팅 메시지

| 설정 | 기본값 | 어떤 것을 제어하는지 |
| --- | --- | --- |
| 추론 요약 표시 | On | 모델이 제공한 요약의 표시 |
| 도구 호출 그룹화 | 비활성화 | 도구 활동의 압축된 그룹화 |
| 도구 호출 펼치기 | 비활성화 | 도구 호출 세부 정보가 확장되는지 여부 |
| 검증 점을 변경합니다 | On | 각 응답 전에 프로젝트 파일을 스�냅샷으로 저장하여 변경 사항을 검토하고 복원할 수 있습니다. |

디스플레이 설정은 프로젝트 간 대화에 영향을 미치지만, 모델의 추론 노력을 변경하거나 추가 도구 권한을 부여하지 않습니다. **변경 체크포인트**를 끄면 새 스토리지가 생성되지 않습니다. [변경 사항 검토 및 복원](/docs/ko/checkpoints) 참조.

### 모델

**모델** 그룹은 일반 그룹의 상단에 위치한다.

| 설정 | 범위 |
| --- | --- |
| 기본 채팅 모델 | 프로젝트 내에서 새로 생성된 채팅들 |
| 기본 권한 | 질문, 편집 승인, 또는 새로운 채팅에 대한 전체 액세스 |
| 추론 강도 | 기본 모델이 지원할 경우 새 채팅에 대한 추론 노력 |
| 속도 | 새로운 채팅용 속도 레이어, 기본 모델이 지원할 경우 |
| 텍스트 생성 모델 | 생성된 커밋 메시지와 풀리퀘스트 텍스트, 자체 노력과 속도로 |

기존 채팅은 자체 선택을 유지합니다. 제공자 아래에서 모델을 활성화한 후 기본 모델로 선택할 수 있습니다. 전체 설정 워크플로우는 [모델과 기본 설정](/docs/ko/models)을 참조하세요.

## 제공자

각 제공자 카드는 탐지된 CLI 상태, 설치된 버전, 새로고침 액션, 그리고 켜기 스위치를 표시합니다. 제공자 및 개별 모델을 켜서 선택자에서 사용 가능하게 합니다. **업데이트 가능** 표시는 탐지된 경우 더 새운 CLI 버전이 존재할 때 나타납니다. CLI를 Dream 외부에서 업데이트한 후 카드를 다시 새로고침합니다.

Dream은 비활성화된 공급자의 CLI 업데이트 확인을 건너뜁니다. 사용 가능한 업데이트를 확인하려면 먼저 공급자를 활성화하세요.

Dream 외부에서 제공업체의 CLI를 설치하고 인증 후 그 카드를 새로고침합니다. Dream 설정은 CLI의 인증 흐름을 대체하지 않습니다. [제공업체 연결](/docs/ko/providers) 참조.

## SSH 호스트

**설정 → SSH 호스트**에서 원격 컴퓨터를 추가, 편집, 연결, 연결 해제 또는 제거할 수 있습니다. 각 항목에는 SSH 대상, 표시 이름, 선택적 호스트 명령, 연결 상태, 연결 오류가 표시됩니다. 설정과 복구 절차는 [SSH 원격 작업 공간](/docs/ko/remote-hosts)을 참고하세요.

## 프롬프트, 기술, 및 MCP 서버

| 섹션 | 당신이 할 수 있는 일 |
| --- | --- |
| [프롬프트](/docs/ko/saved-prompts) | 어떤 프로젝트의 채팅에 대한 재사용 가능한 프롬프트를 생성, 미리보기, 복사, 순서를 재배치하고 편집합니다 |
| [스킬](/docs/ko/skills) | 제공자와 프로젝트별로 기술을 탐색하고 SKILL.md 파일을 미리보기하며 새로운 기술을 생성합니다 |
| [MCP 서버](/docs/ko/mcp-servers) | 도구 서버를 추가하거나 가져오고 연결 설정을 관리합니다 |

## 보관된 채팅

| 제어 | 무엇을 하는지 |
| --- | --- |
| 행 체크박스 | 프로젝트 간에 아카이브된 대화를 선택합니다 |
| 헤더 체크박스 | 모든 아카이브된 대화를 선택하세요 |
| 복원 | 선택한 채팅을 활성 기록으로 되돌림 |
| 삭제 | Dream에서 선택한 채팅과 메시지를 영구적으로 삭제합니다. |
| 다음 일수 후 채팅 보관 | 비활동 종료 기한을 일 기준으로 설정; 기본값 30일 |
| 지금 보관 | 절대값을 만족하는 대화를 아카이브합니다. |

컷오프는 자동 작업을 일정하지 않습니다. bulk actions 또는 영구 삭제를 사용하기 전에 [채팅 보관 및 복원](/docs/ko/archived-chats)을 참조하세요.

## 설정 외의 제어 기능

일부 설정은 개별 채팅이나 프로젝트에 속합니다. 채팅의 모델, 노력 수준, 속도 및 권한은 콤파이터에서 설정할 수 있습니다. 왼쪽 툴바에서 다중 채팅을 전환할 수 있습니다. 채팅 열과 툴 패널은 작업 공간 내에서 직접 크기를 조절할 수 있습니다.
