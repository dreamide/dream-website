**설정 → 프롬프트**를 사용하여 프로젝트 간에 반복적으로 사용하는 지시사항을 설정하십시오. 예를 들어 변경 사항 검토나 리뷰 댓글 대응과 같은 경우입니다. 저장된 프롬프트는 이름과 텍스트를 가집니다. 선택한 대화에서 실행되며, 해당 채팅의 모델과 설정을 사용합니다.

## 드림 IDE를 사용하여 프롬프트를 생성하세요

1. 열린 **설정 → 프롬프트**를 클릭하고 **새 프롬프트**를 클릭합니다.
2. 채팅 메뉴에서 알아볼 수 있는 짧은 **이름**을 입력하세요.
3. **프롬프트**에 지시사항을 작성하고 **만들기**을 클릭하세요.

예를 들어, 프롬프트를 "변경 사항 검토"라고 명명하고 저장하세요:

> 현재 변경 사항에서 버그, 누락된 예외 상황, 의도하지 않은 동작을 검토하세요. 파일 참조와 함께 결과를 보고하세요. 아직 파일을 수정하지 마세요.

프롬프트는 프로젝트 간에 공유 가능합니다. 재사용 가능한 지침을 특정 폴더와 분리하여 유지하되, 텍스트에 포함된 경로는 실행하는 프로젝트에 맞게 적용해야 합니다.

## 채팅에서 프롬프트를 실행합니다

1. 사용하고자 하는 프로젝트 및 대화를 열어주세요.
2. 채팅 모델과 [권한](/docs/ko/agent-modes)을 검토하세요.
3. 메시지 박스 옆의 **+** 메뉴를 열어라.
4. **프롬프트 실행**를 선택한 후 저장된 프롬프트를 선택합니다.

프롬프트를 선택하면 그 텍스트가 즉시 해당 채팅으로 전송됩니다. 먼저 편집 가능한 초안을 삽입하지 않습니다. 이미 콤파이터에 입력한 텍스트는 유지되며, 저장된 프롬프트는 재사용 가능합니다. 전송 전에 텍스트를 조정하고자 한다면 설정에서 복사하여 콤파이터에 직접 붙여넣으세요.

**프롬프트 실행**은 채팅이 바빠 있을 때 사용할 수 없습니다. 다른 프롬프트를 실행하기 전에 응답이 완료될 때까지 기다려 주세요. 제출이 실패하면 프롬프트 텍스트를 확인해 보세요.

**설정 → 프롬프트**에서 프롬프트를 선택하여 그 텍스트를 미리보기하고 복사할 수 있습니다. **편집** 또는 이름을 двой클릭하여 변경할 수 있습니다. **위로 이동**과 **아래로 이동**은 리스트 및 채팅 메뉴에서 그 프롬프트의 위치를 변경합니다. 프롬프트를 삭제하려면 삭제 컨트롤을 클릭한 후 **삭제 확인**을 클릭합니다.

**프롬프트 관리…**을 채팅의 **프롬프트 실행** 메뉴에서 열 수 있습니다.

## 프롬프트를 기술로 변환하기

저장된 프롬프트 옆에 **스킬로 저장**을 클릭하여 이름과 지침이 미리 입력된 스킬 생성 대화상자를 열 수 있습니다. 설명을 추가하고 저장 위치를 선택한 후 **만들기**를 클릭합니다. [에이전트 스킬](/docs/ko/skills)을 참조하여 제공자 지원 및 저장 위치를 확인하세요.

| 당신이 원하는 것은… | 사용하기 |
| --- | --- |
| 다른 채팅에서 동일한 지시를 반복적으로 전송합니다 | 재사용 가능한 프롬프트 |
| 일회성 작업을 나중에 자체 모델 설정으로 준비합니다. | [스태시](/docs/ko/stash) |
| 작업을 위해 재사용 가능한 지침을 제공하여 에이전트가 로드할 수 있도록 하세요. | [스킬](/docs/ko/skills) |
