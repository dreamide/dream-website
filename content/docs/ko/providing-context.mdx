агент에게 결과, 관련 맥락, 그리고 작업을 시작하기 전에 제한 사항을 제공하라. 파일 참조는 코드를 찾는 데 도움이 되며, 첨부 파일은 스크린샷과 같은 추가적인 자료를 제공할 수 있다.

## 프로젝트 파일이나 폴더를 참조하세요

1. 채팅 메시지 상자에 **@**를 입력한 후 파일이나 폴더 경로의 일부를 입력합니다.
2. 목록에서 결과를 선택하세요. **상향화살표**와 **하향화살표**를 사용하여 결과를 이동하고, **Enter** 또는 **Tab**을 눌러 하나를 선택하세요.
3. 삽입된 참조에 대한 지침을 추가하세요.
4. 메시지를 제출합니다.

예를 들어 설정 컴포넌트를 참조하고 질문을 하세요.

> 드림 IDE에서 이 폼이 선호사항을 로드하고 저장하는 방식을 설명하시오. 선택된 값이 사라지는 이유를 찾아라.

작업이 속한 위치를 알고 있을 때는 파일을, 관련 파일들을 검토해야 할 때는 폴더를 선택합니다. 결과 목록은 동일한 이름을 가진 파일들을 구분하기 위해 부모 경로를 표시합니다. **Escape**를 누르면 목록을 닫습니다.

참조는 현재 프로젝트 내의 위치를 식별합니다. 파일 내용을 고정하거나 전체 디렉토리의 복사본을 대화에 연결하지 않습니다.

## 파일을 첨부하세요

1. 메시지 상자 옆의 **파일 첨부** 컨트롤을 클릭하세요.
2. 첨부 작업을 선택하고 컴퓨터에서 파일을 선택하세요.
3. 첨부 파일이 composer에 나타나 있는지 확인합니다.
4. 아이가 그것을 어떻게 사용해야 하는지 설명한 후 메시지를 제출하세요.

스크린샷에 대해 기대되는 동작과 문제점을 설명하십시오. 선택한 제공자와 모델은 사용할 수 있는 첨부 파일 유형을 결정합니다.

## 반복 가능한 지시를 위해 기술을 사용하세요

컴포저에서 **$**를 입력하여 선택한 제공자 및 프로젝트에 대한 [에이전트 기술](/docs/ko/skills)을 찾습니다. 선택한 기술을 선택한 후 작업을 설명합니다. 기술은 메시지에 포함된 파일 참조 및 첨부 파일 외에도 절차나 프로젝트 기준을 제공할 수 있습니다.

반복적으로 보낼 plain text는 [재사용 가능한 프롬프트](/docs/ko/saved-prompts)를 사용하세요.

## 이미지를 확인하고 복사하기

대화에서 이미지를 클릭하면 더 큰 미리보기를 열 수 있습니다. 이미지 위에 마우스를 올리면 상단 우측에 **이미지 복사**가 나타나며, 이를 클릭하여 클립보드에 이미지를 복사할 수 있습니다.

보고서나 다른 채팅에서 드림 자체를 캡처하려면 [윈도우 스크린샷 단축키](/docs/ko/workspace#dream-창을-포착합니다)를 사용하세요.

## 컨텍스트 제거 후 전송

첨부 파일의 제거 컨트롤을 사용하여 콜라서에서 이를 제거합니다. 내부 프로젝트 참조인 경우 메시지에서 그 참조의 언급을 삭제합니다. 참조는 그와 함께 제거됩니다. 남은 텍스트를 확인하여 요청이 여전히 의미가 있는지 확인합니다.

@가 경로를 찾지 못하면 현재 활성 프로젝트를 확인하고 [파일](/docs/ko/files)에서 파일을 검색하세요. 파일이 이동되었거나 이름이 바뀌었으면 현재 경로를 사용하세요.

## 다른 채팅에 충분한 맥락을 제공하세요

별도의 채팅은 메시지를 자동으로 공유하지 않습니다. 구현 채팅 옆에서 리뷰를 시작할 때, 변경된 내용을 파악하고, 어떤 파일이 중요한지, 리뷰어가 확인해야 할 사항을 명확히 하세요.

[브랜치](/docs/ko/branching-chats)를 사용하여 이전 메시지를 다른 대화로 이어가거나, [스태시](/docs/ko/stash)를 사용하여 프로젝트 참조를 포함한 프롬프트를 이후에 저장합니다.
