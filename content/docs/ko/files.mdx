오른쪽 툴바의 **파일**을 클릭하여 활성 프로젝트의 폴더를 탐색할 수 있습니다. 트리에서 파일을 열어 채팅과 함께 검토할 수 있습니다. 파일 탭은 여러 개 열린 파일 사이를 이동할 수 있도록 합니다.

## 파일 찾기

1. **파일** 열기.
2. 트리 위의 **파일 검색**에 파일 이름이나 경로의 일부를 입력하세요.
3. 결과를 선택하여 열 수 있습니다.
4. 검색을 초기화하여 트리 탐색으로 돌아갑니다.

Dream의 파일 작업에서 외부에서 수정된 내용이 트리에 반영되지 않을 경우 **파일 새로 고침**을 사용합니다. 파일을 검색하면 그 파일의 경로를 찾을 수 있으며, 해당 파일 내부의 텍스트를 찾기 위해 편집기의 검색 기능을 사용합니다.

## 파일 내에서 검색 및 대체

1. 파일을 열고 편집 도구바에서 **현재 파일 검색**을 클릭합니다.
2. **찾기**에 텍스트를 입력하세요.
3. **다음 일치 항목** 또는 **이전 일치 항목**을 사용하여 결과를 이동합니다.
4. 필요한 경우 **대소문자 구분**, **단어 단위로 찾기**, 또는 **정규식 사용**을 활성화합니다.

검색 패널은 또한 대체 제어 기능을 제공합니다. **모두 바꾸기**를 사용하기 전에 일치 항목을 확인한 후 파일을 저장하여 디스크에 변경 사항을 기록합니다. 대체는 현재 파일에만 영향을 미칩니다.

## 편집하고 저장

코드 편집기에서 쓰기 가능한 텍스트 파일을 편집합니다. 저장되지 않은 변경 사항은 탭에 표시되며, 패널은 저장되지 않은 초안을 가진 파일 수를 보여줍니다.

편집 도구의 **저장** 버튼을 클릭하거나, 편집기가 초점이 되었을 때 macOS에서는 **Command+S**, Windows/Linux에서는 **Ctrl+S**를 누릅니다. 에이전트나 터미널 명령이 새 내용을 사용하기 전에 수정된 각 파일을 저장해야 합니다. 이러한 도구들은 디스크에 있는 파일을 읽습니다.

파일 탭을 전환하면 다른 파일을 검토하면서 초안을 유지할 수 있습니다. 로컬 초안을 버리고자 한다면 **변경 사항을 버리기**를 사용합니다. 이는 Git을 통해 변경 사항을 되돌리는 것과는 별개입니다.

변경 내용이 저장되지 않은 탭을 닫으면 **저장 / 저장하지 않기 / 취소** 팝업이 나타납니다. **저장**은 초안을 저장하고 탭을 닫습니다. **저장하지 않기**는 초안을 버리고 탭을 닫습니다. **취소**는 탭을 열어두고 있습니다. 저장이 실패하거나 외부 수정과 충돌할 경우 파일은 여전히 열려 있어 문제를 해결할 수 있습니다.

## 편집기 외부에서 파일을 변경하는 경우 처리하기

애그런트, 터미널 명령어, 또는 외부 편집기가 당신이 초안을 가지고 있을 때 동일한 파일을 변경할 수 있으며, Dream은 저장할 때 디스크 내용을 확인하여 더 최신 버전을 무시하지 않고 갈등을 보고 합니다.

1. 원하는 드래프트 텍스트를 유지하세요.
2. 갈등 메시지를 읽으세요.
3. **디스크에서 다시 불러오기**를 사용하여 현재 파일을 로드합니다.
4. 아직 필요한 변경 사항을 다시 적용한 후에 다시 저장하세요.

<Warning>
  디스크에서 다시 불러오기는 당신의 로컬 초안을 대체합니다. 필요할 경우 미저장 작업을 복사하여 사용하세요.
</Warning>

## 시각을 조정하세요

장황한 줄을 위한 **자동 줄 바꿈 사용**을 사용하세요. 파일 트리 및 편집 패널의 크기를 조정하여 내용이 더 많은 공간을 가지도록 하세요. 사용 가능한 **다음에서 열기** 액션을 통해 외부 편집기에서 계속 작업할 수 있습니다.

저장 후 [변경 사항](/docs/ko/git-workflows)을 열어 Git diff를 검토합니다. 파일에 대해 에이전트에게 질문할 경우, 채팅 작성자에서 [@](/docs/ko/providing-context)로 참조합니다.
