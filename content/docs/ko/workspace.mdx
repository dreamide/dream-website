각 Dream 프로젝트는 자체 작업 공간을 가지고 있습니다. 프로젝트 탭은 저장소를 이동하면서 각 프로젝트의 열린 채팅과 도구를 함께 유지할 수 있도록 합니다.

프로젝트는 [SSH 호스트](/docs/ko/remote-hosts)에도 위치할 수 있습니다. 명령을 실행하기 전에 호스트 레이블을 확인하세요. 원격 프로젝트 도구는 해당 컴퓨터에서 작동합니다.

## 프로젝트 추가 및 전환

1. 프로젝트 탭 옆의 **+**를 클릭하거나, 시작하기 화면에서 **폴더 열기**를 사용합니다.
2. 작업할 폴더를 선택하세요.
3. 그 탭을 선택하여 활성 프로젝트로 설정합니다.

활성 프로젝트는 보는 채팅, 파일, 터미널, 브라우저 탭, 스태그 항목을 결정합니다. 작업을 보내거나 명령을 실행하기 전에 선택된 탭을 확인하세요. 관련 프로젝트를 함께 보고 싶을 때 프로젝트 탭을 드래그하여 순서를 조정할 수 있습니다.

## 외부에서 프로젝트를 다시 이름을 지정하거나 열기

프로젝트의 **…** 메뉴를 열고 **편집**을 선택하여 그 표시 이름이나 아이콘을 변경할 수 있습니다. 아이콘을 클릭하여 최대 5MB까지 이미지를 업로드한 후 **저장**을 클릭합니다. 커스텀 아이콘을 다시 설정하면 프로젝트에서 자동 탐지로 돌아갑니다. Dream에서 프로젝트를 이름을 바꾸더라도 디스크에 있는 폴더 이름은 바뀌지 않습니다.

메뉴의 **다음에서 열기** 선택지를 사용하여 프로젝트를 사용 가능한 외부 편집기에서 열 수 있습니다.

## 이전 채팅으로 돌아가기

프로젝트 탭 옆에 **뒤로**과 **앞으로**를 사용하여 열었던 프로젝트와 채팅을 다시 방문할 수 있습니다. Windows 및 Linux에서는 **Alt+Left**와 **Alt+Right**를, macOS에서는 **Command+[**와 **Command+]**를 사용합니다. 마우스의 뒤로, 앞으로 버튼도 작동합니다.

이 기록은 프로젝트 및 채팅 선택을 따라갑니다. 도구 패널을 전환하면 기록이 추가되지 않으며, 내장 브라우저는 자체적인 네비게이션 기록을 가지고 있습니다. 터미널이나 코드 편집기 내부의 키보드 단축키는 각 도구의 설정을 따릅니다.

## 프로젝트를 닫고 다시 열기

1. 프로젝트의 **…** 메뉴를 열고 **닫기**를 선택합니다.
2. 반환하고자 할 경우, 프로젝트 **+** 버튼을 통해 시작하기 페이지를 열어야 합니다.
3. **최근 닫힘**에서 프로젝트를 찾기 위해 검색 필드를 사용할 수 있습니다.
4. 프로젝트를 선택하여 다시 열기.

프로젝트를 닫으면 그 프로젝트의 열린 탭이 제거되지만 폴더는 삭제되지 않습니다. Dream은 가능한 경우 채팅과 열린 도구와 같은 저장된 프로젝트 컨텍스트를 복원합니다. 닫힌 프로젝트를 사용하여 터미널 프로세스를 유지하는 것은 피하십시오.

## 워크스페이스 컨트롤을 찾으세요

왼쪽 툴바에는 **채팅 기록**, **새 채팅**, **멀티 채팅 활성화**가 있습니다. 아이콘을 마우스로 올려두면 라벨을 볼 수 있습니다. 채팅 작성이 선택된 모델, 지원되는 경우 노력과 속도, 그리고 권한을 포함합니다.

오른쪽 도구바는 프로젝트 도구를 열어줍니다:

| 도구 | 당신이 할 수 있는 일 |
| --- | --- |
| [변경 사항](/docs/ko/git-workflows) | Git 차이를 검토하고 파일 변경을 되돌립니다 |
| [파일](/docs/ko/files) | 파일을 탐색하고 경로를 검색하며 파일 내용을 편집합니다 |
| [브라우저](/docs/ko/browser) | URL을 미리보기하고 웹 페이지를 검사합니다 |
| [터미널](/docs/ko/terminals) | 프로젝트 명령을 별도의 세션에서 실행합니다 |
| [Git 작업](/docs/ko/git-workflows) | 커밋, 푸시 및 풀리퀘스트 생성 |
| [풀 리퀘스트](/docs/ko/pull-requests) | 현재 브랜치의 PR를 읽고 댓글을 작성하고 머지합니다 |
| [스태시](/docs/ko/stash) | 프롬프트를 저장하고 나중에 실행합니다 |

**Git 작업**은 오른쪽 툴바의 상단에 있습니다. 저장소 프로젝트에는 Git 제어 기능이 나타납니다. 채팅 아래에 있는 브랜치 제어는 현재 활성 브랜치를 보여주며, 이를 사용하여 브랜치를 전환하거나 [워크트리](/docs/ko/worktrees)를 생성할 수 있습니다. 워크트리 프로젝트에서는 동일한 위치에 **작업 트리** 버튼이 나타나며, 이 버튼을 클릭하면 [워크트리 완료](/docs/ko/worktrees#워크트리를-완료합니다) 대화상자가 열립니다.

## 채팅과 패널을 정리하세요

도구를 클릭하여 그 도구의 패널을 열 수 있습니다. 채팅 공간을 더 확보해야 할 경우 패널의 닫기 또는 축소 컨트롤을 사용하시고, 패널 분할선을 드래그하여 레이아웃을 조절할 수 있습니다. 도구 패널을 닫는 것은 그 도구의 개별 터미널 세션이나 브라우저 탭을 닫는 것과 다릅니다.

[다중 채팅](/docs/ko/multiple-chats)을 활성화하여 대화를 조절 가능한 열에 배치할 수 있습니다. 각 채팅은 자체 대화 기록을 가지고 있지만, 프로젝트 내 모든 채팅은 동일한 파일을 공유합니다. 워크트리를 사용하여 독립적인 체크아웃을 수행합니다.

## Dream 창을 포착합니다

Windows/Linux에서는 **Ctrl+Shift+S**를, macOS에서는 **Command+Shift+S**를 누르면 Dream 창을 캡처할 수 있습니다. Dream은 스크린샷을 클립보드에 복사한 후 PNG로 저장할 수 있도록 대화창을 열며, 저장 대화창을 취소하면 클립보드에 있는 복사본만 유지됩니다. 이미지가 복사되었는지, 저장되었는지, 또는 캡처할 수 없었는지에 대한 알림이 표시됩니다.

웹 페이지의 스크린샷을 원하면 [브라우저 스크린샷 액션](/docs/ko/browser)을 사용하세요.

앱 전체의 외관, 언어, 모델 선호 설정을 찾으려면 [설정](/docs/ko/settings)을 열어주세요. 더 오래된 대화를 찾으려면 [채팅 기록](/docs/ko/chats) 또는 [보관된 채팅](/docs/ko/archived-chats)을 사용하세요.
