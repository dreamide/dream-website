최소 하나의 프로바이더 모델이 활성화된 후에는 Dream에 로컬 폴더를 추가할 수 있습니다.

다른 컴퓨터에서 작업하려면 [SSH 원격 작업 공간](/docs/ko/remote-hosts)을 따라 **SSH 호스트에서 열기**를 선택하세요.

<Steps>
  <Step title="폴더 열기">
    시작 화면에서 **폴더 열기**를 선택하고 Dream이 사용할 프로젝트 디렉토리를 선택합니다.
  </Step>
  <Step title="모델을 선택하세요">
    Dream은 기본 모델에서 시작됩니다. 채팅 작성자에 있는 모델 선택기를 사용하여 다른 활성 제공자 및 모델을 선택할 수 있습니다.
  </Step>
  <Step title="권한 선택">
    새 채팅은 설정의 **기본 권한**을 이어받습니다. 메시지 입력창 아래의 방패 아이콘을 열고 이 작업에 맞게 **물어보기**, **편집 승인** 또는 **전체 액세스**을 선택하세요. [에이전트 권한](/docs/ko/agent-modes)을 참고하세요.
  </Step>
  <Step title="프롬프트를 보내라">
    원하는 결과를 설명하고, 그 결과가 어떻게 검증되어야 하는지 명시하세요. 예: "이 프로젝트가 어떻게 시작되는지 설명하고, 테스트 명령을 식별하며, 설정 페이지를 어디에 추가해야 하는지 제안하세요." Dream은 대화와 프로젝트 도구를 동일한 작업 공간에서 함께 유지합니다.
  </Step>
</Steps>

## 결과를 검토하세요

응답을 읽고 agent가 수행한 내용을 점검하고자 할 경우 도구 세부 정보를 열어보세요. 질문을 하면 동일한 대화에서 답변하세요. 파일을 변경하면 오른쪽 도구바의 **변경 사항**을 열어 차이를 검토하세요. 코드를 확인하려면 **파일**을, 프로젝트의 검사를 실행하려면 **터미널**을 사용하세요.

특정 코드나 스크린샷이 필요한 작업에 대해 요청 전에 [상황을 추가](/docs/ko/providing-context)하세요. 메시지 상자 아래의 선택기를 사용하여 채팅 모델을 변경할 수 있습니다. 향후 채팅의 시작 모델을 변경하려면 **설정 → 일반 → 모델 → 기본 채팅 모델**을 사용하세요.

## 프로젝트로 돌아가기

열린 프로젝트는 탭으로 계속 사용 가능합니다. 하나를 닫으셨다면, 시작하기 화면의 **최근 닫힘**을 사용하여 찾아서 복원할 수 있습니다. Dream은 가능한 경우 채팅과 열린 도구와 같은 프로젝트 컨텍스트를 복원합니다.

## 다른 채팅을 시작하세요

**새 채팅**을 사용하여 동일한 프로젝트에 대한 별도의 대화를 시작합니다. 동시에 여러 채팅을 활성화하고 싶다면 [다중 채팅](/docs/ko/multiple-chats)을 사용합니다. 각 채팅은 자체 메시지를 가집니다만, 같은 프로젝트 내의 채팅들은 파일을 공유합니다.

[채팅 기록](/docs/ko/chats)을 열어 이전 작업으로 돌아갑니다. 작업이 완료되면 [대화를 아카이브](/docs/ko/archived-chats)하여 활성 기록에서 제거하면서도 복구할 수 있도록 유지합니다.
