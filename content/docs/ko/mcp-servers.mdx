모델 컨텍스트 프로토콜(MCP) 서버는 에이전트에게 추가 도구를 제공합니다. 설정 → MCP 서버에서 이를 구성할 수 있습니다. Dream은 **Claude Code**, **Codex**, **OpenCode**, 및 **Grok Build**에 대한 이러한 연결을 지원합니다. Cursor는 Dream 관리 MCP 연결을 지원하지 않습니다.

## 서버 추가

1. 열린 **설정 → MCP 서버** 및 **서버 추가**를 클릭합니다.
2. 영문자, 숫자, 하이픈, 밑줄로 구성된 고유한 **이름**을 선택하세요. 첫 글자는 영문자 또는 숫자여야 합니다.
3. **전송 방식**을 선택하고 서버에서 제공된 연결 정보를 입력하세요.
4. **사용**를 유지하여 서버를 사용 가능하게 하면, **저장**를 클릭합니다.

| 운송 | 필드 |
| --- | --- |
| 명령 (stdio) | **명령**에 실행 파일, **인수**에 한 줄당 하나의 인수, 필요한 경우 **환경 변수** 입력 |
| HTTP | HTTP 또는 HTTPS **URL**과 선택 사항인 **헤더** |
| SSE | HTTP 또는 HTTPS **URL**과 선택 사항인 **헤더** |

환경 변수와 헤더를 하나의 `KEY=VALUE` 쌍으로 한 줄씩 입력하세요. 실행 파일을 그 실행에 필요한 인수와 분리하여 유지하세요. 예를 들어, 로컬 서버는 `node`를 명령으로 사용하고, 진입 파일의 절대 경로를 인수로 사용할 수 있습니다.

서버 정의는 Dream의 로컬 데이터베이스에 저장되며, 입력한 모든 인증 정보도 포함됩니다. 이러한 값들은 암호화되지 않은 상태로 저장됩니다.

## 기존 구성 가져오기

1. 구성할 프로젝트를 선택하세요.
2. 열림 **설정 → MCP 서버 → 가져오기…**.
3. 검색된 서버, 원본 파일, 그리고 경고 사항을 검토합니다.
4. 추가할 서버를 선택하고 **Import**를 클릭합니다.

Dream은 Claude 사용자 및 프로젝트 설정, Codex의 사용자 설정, 그리고 Cursor의 사용자 및 프로젝트 MCP 설정을 스캔합니다. 이미 설정된 이름의 항목은 **이미 존재함**으로 표시되며 다시 가져오지 않습니다.

Dream에 코피 정의를 가져오면, 원본 파일에 대한 나중 변경 사항이 자동으로 동기화되지 않습니다. Cursor 구성 파일을 가져오면 Dream의 지원되는 제공자에 서버가 사용 가능해지며, Dream의 Cursor 채팅에 MCP 지원을 추가하지 않습니다.

**편집**을 사용하여 정의를 변경하고, **저장**을 사용하여 적용합니다. **사용**를 끄면 구성은 유지되지만 이후 에이전트 요청에 노출되지 않습니다. 정의를 제거하려면 **삭제**를 사용하고, **삭제 확인**을 클릭합니다. 정의를 제거하더라도 그 실행 파일은 제거되지 않습니다.

서버를 변경한 후 지원되는 채팅에서 새 요청을 보내세요. 제공자가 여전히 오래된 연결을 사용하고 있다면 새 채팅을 시작하세요. 도구가 사용할 수 없을 경우 실행 파일, URL, 인증 정보, 그리고 채팅 오류를 확인하세요.

Dream의 [내장 브라우저 도구](/docs/ko/browser#애그نت에게-브라우저를-사용하도록-요청하세요)는 지원되는 제공업체에서 자동으로 연결되므로 여기에서 서버를 추가할 필요가 없습니다.
