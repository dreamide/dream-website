Dream은 macOS, Windows, Linux에 대한 데스크톱 애플리케이션으로 제공됩니다.

<Card title="Dream 다운로드" icon="download" href="/ko/download">
  다운로드 페이지를 열어 플랫폼과 아키텍처에 맞는 패키지를 선택합니다.
</Card>

## 사용 가능한 패키지

| 플랫폼 | 패키지 |
| --- | --- |
| macOS | DMG를 Apple 스퀘어(ARM64) 또는 인텔(x64)용으로 제공합니다 |
| Windows | x64 설치 프로그램 |
| Linux | x64용 DEB, RPM, 또는 AppImage |

## 드림을 열기 전에

지원되는 [агент CLI](/docs/ko/providers) 중 하나를 설치하고 인증하세요. Dream은 CLI 및 그가 제공하는 모델을 감지합니다. API 인증 정보와 구독은 해당 제공업체에서 관리됩니다.

## 업데이트

Dream은 애플리케이션 업데이트를 확인합니다. 업데이트가 가능할 경우 앱의 업데이트 기능을 사용하거나 [다운로드 페이지](/ko/download)에서 최신 패키지를 다운로드합니다.

<Tip>
  드림이 설치된 CLI를 감지하지 못하면, 명령어가 일반 터미널에서 정상적으로 작동하는지 확인한 후 드림의 설정에서 제공자를 다시 새로고이세요.
</Tip>

## 다음 단계

설치 후 [제공자 연결](/docs/ko/providers)을 수행하고 최소한 하나의 모델을 활성화하세요. 다음에 [첫 번째 프로젝트를 열기](/docs/ko/first-project)하세요. [설정 → 일반](/docs/ko/settings#일반)에서 인터페이스 언어, 외관, 터미널 쉘을 선택할 수 있습니다.

앱이 열리지만 대화를 시작할 수 없는 경우 [모델 및 제공자 문제 해결](/docs/ko/troubleshooting#모델이-없거나-대화를-시작할-수-없습니다)을 확인하세요.
