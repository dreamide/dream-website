Dream ist als Desktop-Anwendung für macOS, Windows und Linux verfügbar.

<Card title="Dream herunterladen" icon="download" href="/de/download">
  Öffnen Sie die Herunterladen-Seite, um das Paket für Ihre Plattform und Architektur auszuwählen.
</Card>

## Verfügbare Pakete

| Plattform | Pakete |
| --- | --- |
| macOS | DMG für Apple Silicon (ARM64) oder Intel (x64) |
| Windows | Installer für x64 |
| Linux | DEB, RPM oder AppImage für x64 |

## Bevor Dream geöffnet wird

Installieren und authentifizieren Sie mindestens ein [unterstütztes Agent-CLI](/docs/de/providers). Dream erkennt das CLI und die Modelle, die es bereitstellt; API-Zugangsdaten und Abonnements werden weiterhin von dem Anbieter verwaltet.

## Aktualisierungen

Dream prüft auf Aktualisierungen der Anwendung. Wenn ein Update verfügbar ist, verwenden Sie die Aktualisierungsaktion in der App oder laden Sie die neueste Version aus der [Herunterladen-Seite](/de/download) herunter.

<Tip>
  Wenn Dream kein installiertes CLI erkennt, bestätigen Sie, dass der Befehl in Ihrem normalen Terminal funktioniert, dann aktualisieren Sie den Anbieter aus den Einstellungen von Dream.
</Tip>

## Nächste Schritte

Nach der Installation [verbinden Sie einen Anbieter](/docs/de/providers) und aktivieren Sie mindestens ein Modell. Dann [öffnen Sie Ihr erstes Projekt](/docs/de/first-project). Sie können die Sprache der Oberfläche, das Erscheinungsbild und die Terminal-Shell in [Einstellungen → Allgemein](/docs/de/settings#allgemein) wählen.

Wenn die Anwendung öffnet, aber Sie keine Konversation starten können, prüfen Sie [die Behebung von Modell- und Anbieterproblemen](/docs/de/troubleshooting#ein-modell-ist-fehlend-oder-ich-kann-keinen-chat-starten).
