Dream kann Projekte auf entfernten Rechnern neben Ihren lokalen Projekten öffnen. Dateien, Git-Befehle, Agentenprozesse und Terminals laufen auf dem Host des Projekts. Die Host-Anzeige des Projekts zeigt, wo Sie arbeiten.

Verbinden Sie einen Host über SSH, oder koppeln Sie sich über HTTPS mit einem Dream-Host, auf dem der [Fernzugriff](/docs/de/remote-access) aktiviert ist. Ein Host kann mehrere Routen haben, und Dream verwendet die erste, die eine Verbindung herstellt.

Dream installiert über SSH verwaltete Host-Laufzeitumgebungen für Linux x64, Linux ARM64 und macOS mit Apple silicon (ARM64). Dies sind die Plattformen für Remote-Hosts; die Dream-Desktop-App läuft unter Windows, macOS oder Linux. Linux-Host-Laufzeitumgebungen unterstützen Systeme mit glibc 2.31 oder neuer.

## SSH-Host hinzufügen

1. Prüfe in deinem Systemterminal, ob `ssh devbox` funktioniert. Ersetze `devbox` durch deinen SSH-Konfigurationsalias oder `user@host`. Dream verwendet den SSH-Client, die Konfiguration und die Schlüssel deines Systems.
2. Öffnen Sie **Einstellungen → Verbindungen** und wählen Sie **Host hinzufügen → SSH-Host**.
3. Geben Sie das **SSH-Ziel** ein oder wählen Sie einen aus Ihrer `~/.ssh/config` vorgeschlagenen Alias, und füllen Sie optional **Name** aus.
4. Lassen Sie **Host-Befehl** für die automatische Installation der Laufzeitumgebung leer und klicken Sie dann auf **Speichern**. Dream verbindet sich mit dem neuen Host.
5. Beantworte Anfragen zu Host-Schlüsseln, Passwörtern, Passphrasen oder Zwei-Faktor-Authentifizierung in Dream. Das Ablehnen oder Abbrechen einer Anfrage beendet diesen Verbindungsversuch.

Sie können auch **SSH-Host hinzufügen…** im Dialog **Ordner öffnen** wählen.

Verwaltete Laufzeitumgebungen werden pro Version unter `~/.dream/host/versions/` installiert. Kann der Host die Laufzeitumgebung nicht herunterladen, kann Dream sie lokal herunterladen und über SSH übertragen. Installiere die Agenten-CLIs auch auf dem entfernten Rechner und melde dich dort an; sie laufen in dessen Umgebung.

Setze bei einer manuell installierten Laufzeitumgebung **Host-Befehl** auf den Befehl, der `dream-host` auf dem entfernten Rechner startet.

## Host über HTTPS koppeln

Die Kopplung verbindet diesen Desktop ohne SSH mit einem Dream-Host, und zwar über die Adresse, die in den [Fernzugriff](/docs/de/remote-access)-Einstellungen dieses Hosts verwendet wird.

1. Öffnen Sie auf dem Host-Rechner **Einstellungen → Verbindungen** und wählen Sie dann **Gerät koppeln** unter **Fernzugriff**.
2. Öffnen Sie auf diesem Desktop **Einstellungen → Verbindungen** und wählen Sie **Host hinzufügen → Kopplungslink**.
3. Fügen Sie auf dem Tab **Link** den **Kopplungslink** ein. Oder geben Sie auf dem Tab **Code** die **Host-Adresse** und den auf dem Host angezeigten **Kopplungscode** ein.
4. Geben Sie optional einen Namen ein und wählen Sie **Koppeln**.
5. Wenn Sie einen Code verwendet haben, bestätigen Sie diesen Desktop unter **Warten auf Kopplung** in den Fernzugriffseinstellungen des Hosts.

Ein Kopplungslink funktioniert einmal und läuft nach 10 Minuten ab. Dieser Computer muss dem HTTPS-Zertifikat des Hosts vertrauen.

## Entferntes Projekt öffnen

1. Wählen Sie auf dem Startbildschirm **Ordner öffnen**. Mit der Schaltfläche **+** bei den Projekten kehren Sie zu diesem Bildschirm zurück.
2. Wählen Sie unter **Öffnen auf** den Host aus. Verbinden Sie ihn, falls Dream danach fragt.
3. Geben Sie einen **Ordnerpfad** ein; Dream schlägt während der Eingabe Ordner vor. Sie können auch die Liste unter dem Pfad durchsuchen und **Einen Ordner nach oben** verwenden.
4. Klicke auf **Öffnen**. Der entfernte Ordner wird als Projekt-Tab mit eigenen Chats und Werkzeugen geöffnet.

## Routen verwalten

Eine Route ist ein Weg, einen Host zu erreichen: eine SSH-Verbindung oder eine gekoppelte HTTPS-Adresse. Fügen Sie demselben Host mehrere Routen hinzu, um weiterarbeiten zu können, wenn eine nicht verfügbar ist, etwa SSH im Büronetzwerk und HTTPS anderswo.

1. Öffnen Sie **Einstellungen → Verbindungen** und klicken Sie beim Host auf **Bearbeiten**.
2. Prüfen Sie die Routen. Routen werden der Reihe nach versucht, bis eine Verbindung zustande kommt, und **Aktive Route** kennzeichnet die verwendete Route.
3. Ändern Sie die Reihenfolge mit **Nach oben** und **Nach unten**.
4. Wählen Sie **SSH-Route hinzufügen** oder **HTTPS-Route hinzufügen**, um einen weiteren Weg zum selben Host hinzuzufügen, oder **Route entfernen**, um eine zu löschen. Mindestens eine Route muss bestehen bleiben.

Wenn die bevorzugte Route nicht verfügbar ist, wechselt Dream zur nächsten Route und hält weitergeleitete Ports stabil. Das Ändern einer HTTPS-Route erfordert einen neuen Kopplungslink.

## Host erneut verbinden oder entfernen

Jeder Host unter **Einstellungen → Verbindungen** zeigt seinen Status, etwa **Verbunden**, **Verbinde erneut…** oder **Verbindung fehlgeschlagen**. Dream versucht, unterbrochene Verbindungen wiederherzustellen. Projekt-Tabs bleiben sichtbar, während ein Host nicht verfügbar ist, und das Senden von Nachrichten ist deaktiviert, bis er wieder verbunden ist. Wenn die Wiederverbindung abbricht, lesen Sie den angezeigten Fehler und verwenden Sie **Verbinden**.

Mit **Bearbeiten** ändern Sie Name, Ziel oder Befehl eines Hosts. Eine Änderung von Ziel oder Befehl stellt eine aktive Verbindung neu her. **Trennen** lässt die Projekt-Tabs bestehen.

**Entfernen** fragt nach einer Bestätigung, entfernt dann den Host und seine Projekte aus diesem Dream-Arbeitsbereich und beendet ihre Terminals. Dateien und Chats auf dem Host werden nicht gelöscht.

## Verbindungsprobleme

Prüfen Sie zuerst dasselbe SSH-Ziel in Ihrem Systemterminal. Beheben Sie Authentifizierungs- oder Host-Key-Probleme, bevor Sie sich erneut verbinden. Wenn die Host-Laufzeitumgebung nicht startet, lesen Sie den Fehler unter **Einstellungen → Verbindungen** und prüfen Sie den konfigurierten **Host-Befehl** oder die Verfügbarkeit einer Laufzeitumgebung für Ihre Plattform.

Prüfen Sie bei einer HTTPS-Route, ob der Host läuft und sein Fernzugriff **Bereit** ist. Zeigt die Route **Aktion erforderlich** im Dialog **Bearbeiten** des Hosts an, wurde das Gerät möglicherweise widerrufen; koppeln Sie es erneut mit einem neuen Link aus den Fernzugriffseinstellungen des Hosts. Siehe [Probleme mit dem Fernzugriff](/docs/de/remote-access#probleme-mit-dem-fernzugriff).

Für Entwicklungsbuilds gibt es keine veröffentlichte Laufzeitumgebung zum Herunterladen. Führe im Repository der Dream-App `pnpm host:install-dev devbox` aus und verbinde dich erneut mit leerem **Host-Befehl**. Der entfernte Build benötigt Node.js 22 oder neuer, pnpm oder Corepack, make, Python 3 und eine C++-Toolchain (g++ 10 oder neuer). Der Installer stoppt den vorhandenen Entwicklungshost-Daemon, bevor er dessen Laufzeitumgebung ersetzt.
