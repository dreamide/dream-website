title: "Remote-Hosts"
description: "Projekte per SSH oder HTTPS öffnen und Agenten, Dateien, Git und Terminals auf dem anderen Rechner nutzen."
---

Lokale und entfernte Projekte können nebeneinander geöffnet sein. Dateien, Git, Agenten und Terminals laufen auf dem jeweiligen Host. Projekttab und Chat-Fußleiste zeigen seinen Namen.

Dream unterstützt zwei Verbindungswege.

| Route | Geeignet für | Voraussetzungen |
| --- | --- | --- |
| SSH | Die Maschine ist über `ssh` erreichbar | SSH-Ziel. Dream installiert und startet dort den Host. |
| HTTPS | Dream oder `dream-host` läuft dort mit aktiviertem [Fernzugriff](/docs/de/remote-access) | Hostadresse und Kopplungscode |

Ein Host kann beide Routentypen haben. Siehe [Routen](/docs/de/remote-hosts#routen).

## SSH-Host hinzufügen

1. Prüfe in deinem Systemterminal, ob `ssh devbox` funktioniert. Ersetze `devbox` durch deinen SSH-Konfigurationsalias oder `user@host`. Dream verwendet den SSH-Client, die Konfiguration und die Schlüssel deines Systems.
2. Öffnen Sie **Einstellungen → Verbindungen** und wählen Sie unter **Remote-Hosts** erst **Host hinzufügen**, dann **SSH-Host**.
3. Geben Sie das **SSH-Ziel** ein. Dream schlägt Aliase aus der SSH-Konfiguration vor. Ohne Namen wird das Ziel als Name verwendet.
4. Klicken Sie auf **Speichern**. Dream stellt die Verbindung sofort her.
5. Beantworte Anfragen zu Host-Schlüsseln, Passwörtern, Passphrasen oder Zwei-Faktor-Authentifizierung in Dream. Das Ablehnen oder Abbrechen einer Anfrage beendet diesen Verbindungsversuch.

Beim Verbinden installiert Dream die passende Hostversion unter `~/.dream/host/versions/` und startet sie. Ist ein direkter Download nicht möglich, lädt Dream sie lokal herunter und überträgt sie per SSH. Installieren und authentifizieren Sie die Agenten-CLIs auf dem Zielrechner.

SSH-Hosts unterstützen Linux x64 und ARM64 ab glibc 2.31 sowie macOS auf Apple Silicon. Der Desktop-Client läuft auf Windows, macOS und Linux.

## Host über HTTPS koppeln

Ist SSH unpraktisch oder nicht verfügbar, koppeln Sie per Code, etwa für den Zugriff auf den Bürorechner über Tailscale oder Cloudflare Tunnel.

1. Aktivieren Sie auf dem anderen Rechner den [Fernzugriff](/docs/de/remote-access) und erzeugen Sie mit **Gerät koppeln** oder `dream-host pair` einen Code.
2. Wählen Sie auf diesem Rechner unter **Einstellungen → Verbindungen** zuerst **Host hinzufügen** und dann **Kopplungscode**.
3. Geben Sie **Host-Adresse** und **Kopplungscode** ein. Der Name ist optional.
4. Klicken Sie auf **Host koppeln**.

Der Code gilt einmalig für zehn Minuten. Dieser Rechner muss dem HTTPS-Zertifikat vertrauen. Ein Dream-Konto ist nicht erforderlich. Die Kopplung gilt bis zum Widerruf auf dem Host.

## Routen

Unter **Remote-Hosts** erscheint jeder Host einmal. Öffnen Sie seine Routen mit **Bearbeiten** und ergänzen Sie mit **SSH-Route hinzufügen** oder **HTTPS-Route hinzufügen** einen Zugang. Im selben Dialog können Sie den Host umbenennen.

Dream versucht Routen von oben nach unten. Ordnen Sie sie mit **Nach oben** und **Nach unten** und löschen Sie mit **Route entfernen**. Mindestens eine Route muss bleiben. Bei Ausfall wird die nächste versucht.

Für Host-Vorschauen im [Browser](/docs/de/browser) und externe Editoren über **Öffnen in** ist eine SSH-Route nötig. Über HTTPS bleiben Projekte, Chats, Dateien, Git und Terminals verfügbar.

## Entferntes Projekt öffnen

1. Klicken Sie neben den Projekttabs auf **+** und dann auf **Ordner öffnen**.
2. Wählen Sie im Dialog **Ordner öffnen** unter **Öffnen auf** den Host. Dream verbindet sich bei Bedarf.
3. Geben Sie den **Ordnerpfad** ein. Dream schlägt passende Ordner auf dem Host vor. **Tab** vervollständigt den markierten Ordner.
4. Klicke auf **Öffnen**. Der entfernte Ordner wird als Projekt-Tab mit eigenen Chats und Werkzeugen geöffnet.

Ohne gespeicherten Host wählen Sie unten im Dialog **SSH-Host hinzufügen…**.

## Host erneut verbinden oder entfernen

**Einstellungen → Verbindungen** zeigt den Verbindungsstatus. Dream versucht die Verbindung erneut. Projekttabs bleiben sichtbar, Nachrichten können erst nach Wiederverbindung gesendet werden. Bei Abbruch prüfen Sie den Fehler und wählen **Erneut verbinden** im Chat oder **Verbinden** unter **Einstellungen → Verbindungen**.

Laufende Agentenzüge werden auf dem Host fortgesetzt. Nach Wiederverbindung zeigt Dream den Fortschritt wieder an.

**Trennen** lässt Projekttabs bestehen. **Entfernen** entfernt nach Bestätigung Host und Projekte aus dem Workspace und stoppt deren Terminals. Dateien und Chats auf dem Host bleiben erhalten.

## Verbindungsprobleme

Testen Sie das SSH-Ziel im Systemterminal und beheben Sie Anmelde- oder Hostschlüsselfehler. Bei Startfehlern prüfen Sie **Einstellungen → Verbindungen** und die unterstützten Plattformen.

Bei abgelehntem HTTPS-Zugriff unterscheidet Dream inkompatible Versionen und fehlende Berechtigungen. Gleichen Sie die Versionen an oder koppeln Sie erneut mit einem neuen Code.

Für Entwicklungsbuilds führen Sie im Dream-Repository `pnpm host:install-dev devbox` aus und verbinden sich erneut. Der Zielrechner braucht Node.js ab 22, pnpm oder Corepack, make, Python 3 und einen C++-Compiler ab g++ 10. Der Installer stoppt den Entwicklungsdaemon vor dem Austausch.
