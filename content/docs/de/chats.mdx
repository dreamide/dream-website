Ein Chat enthält eine Unterhaltung mit einem Coding-Agenten. Ein Chat gehört in der Regel zu einem Projekt und hat ein eigenes Modell, eigene Berechtigungen und einen eigenen Unterhaltungsverlauf. Verwende getrennte Chats für Aufgaben, zu denen du unabhängig voneinander zurückkehren möchtest, etwa das Beheben eines Fehlers und das Prüfen eines Features.

Um etwas zu fragen, ohne einen Ordner zu öffnen, starte einen [Chat ohne Projekt](/docs/de/standalone-chats).

## Eine Konversation starten

1. Wählen Sie die Projekttaste aus, in der Sie arbeiten möchten.
2. Klicken Sie im linken Toolbar auf **Neuer Chat**.
3. Prüfen Sie das Modell und die Berechtigungen unter der Nachrichtenbox.
4. Beschreibe die Aufgabe und sende deine Nachricht.

Neue Chats verwenden Ihre [Standardmodell-Einstellungen](/docs/de/models). Ein leeres Entwurf kann wieder verwendet werden, wenn Sie **Neuer Chat** erneut klicken, bevor eine Nachricht gesendet wird. Sobald eine Nachricht gesendet wird, erscheint das Gespräch in der Projektgeschichte.

Um eine nützliche erste Nachricht zu generieren, geben Sie dem Agenten ein Ergebnis und eine Möglichkeit, es zu überprüfen. Zum Beispiel:

> Finde heraus, warum das Einstellungsformular nach dem Neuladen seine Werte verliert. Behebe die Ursache und erkläre, wie du die Korrektur überprüft hast.

Verwenden Sie [Dateireferenzen und Anhänge](/docs/de/providing-context), um auf relevante Code oder ein Bild hinzuweisen.

## Zurück zu einem Gespräch

1. Klicken Sie im linken Toolbar auf **Chat-Verlauf**.
2. Durchsuchen Sie die Chats des aktuellen Projekts, wobei zuerst die recently aktualisierten Gespräche angezeigt werden.
3. Geben Sie einen Teil des Chat-Titels in **Suche Geschichte** ein, um die Liste zu verfeinern.
4. Wählen Sie das Gespräch aus, um es zu öffnen.

Die Suche im Verlauf filtert die Titel dieses Projekts. Um Titel und Nachrichtentext projektübergreifend zu durchsuchen, klicke in der oberen Leiste auf **Chats durchsuchen** (standardmäßig **Command+Shift+F** unter macOS oder **Ctrl+Shift+F** unter Windows/Linux). Die Ergebnisse umfassen lokale Projekte, verbundene Remote-Hosts und [Chats ohne Projekt](/docs/de/standalone-chats). Wählst du ein archiviertes Ergebnis aus, wird es wiederhergestellt; wählst du den Chat eines geschlossenen Projekts aus, wird dieses Projekt wieder geöffnet.

Wenn ein Host nicht gesucht werden kann, reconnecten Sie ihn und versuchen Sie es erneut. Beschränken Sie die Abfrage, wenn die Suchergebnisse abgeschnitten werden. Sie können auch ältere Gespräche in [Archivierte Chats](/docs/de/archived-chats) verwalten.

Wenn [multi-chat](/docs/de/multiple-chats) aktiviert ist, kann die Auswahl einer Konversation die Seitenbereitstellung aktivieren. Wenn multi-chat deaktiviert ist, wird eine Konversation zu einem Zeitpunkt angezeigt.

## Ein Chat umbenennen

Dream kann nach dem Beginn einer Konversation einen Titel erzeugen. Um einen konkreteren Namen zu vergeben, öffnen Sie das Menü **…** des Chats und wählen **Bearbeiten** aus, oder klicken Sie einfach doppelt auf den Titel. Im Menü **Chat bearbeiten** geben Sie den Namen ein und klicken auf **Speichern**. Wählen Sie **Abbrechen**, um den bestehenden Namen beizubehalten.

Namensbeispiele wie „Einstellungen der Persistenz beheben“ und „Einstellungen der Tests überprüfen“ sind leichter zu unterscheiden als mehrere Chats, die sich auf das gleiche Projekt beziehen.

## Fortschritt verfolgen

Aktivieren Sie **Desktop-Benachrichtigungen** unter **Einstellungen → Allgemein → Chatnachrichten**, um benachrichtigt zu werden, wenn ein Chat abgeschlossen wird, fehlschlägt oder eine Eingabe benötigt, während Dream im Hintergrund ist. Klicken Sie auf eine Benachrichtigung, um den zugehörigen Chat zu öffnen. **Benachrichtigungston** ist eine separate Option und kann auch ertönen, wenn Dream den Fokus hat.

Benachrichtigungen gibt es auch für Durchläufe, die auf dem Host weiterlaufen, während dieses Fenster sie nicht verfolgt. Ein Durchlauf, den du selbst stoppst, löst keine Benachrichtigung aus.

Eine Ladeanzeige kennzeichnet Chats, die gerade eine Antwort empfangen. Wenn du eine Nachricht sendest, scrollt Dream sie in den sichtbaren Bereich.

Während ein Agent antwortet, wird der Chat seine Fortschritte und Tool-Aktivitäten anzeigen. Offene Tool-Details anzeigen, um Befehle, Datei-Lesungen oder Änderungen zu überprüfen. Wenn der Agent eine Aufgabenliste bereitstellt, zeigt die Aufgabensteuerung neben der Nachrichtenbox ihren Fortschritt an.

Der Chat-Verlauf und die Projekt-Tabs zeigen für jeden Chat einen Status: ein Ladesymbol, solange er antwortet, einen bernsteinfarbenen Punkt, wenn der Agent auf dich wartet, und einen grünen Punkt, wenn er fertig ist und du ihn noch nicht geöffnet hast. Wähle das Projekt aus und öffne die Unterhaltung, um ihre neueste Nachricht zu lesen. Mit dem Stopp-Steuerelement im Composer unterbrichst du eine Antwort. Das Stoppen einer Antwort macht bereits vorgenommene Dateiänderungen nicht rückgängig.

Ein Durchlauf wird auf dem Host des Projekts ausgeführt, nicht im Fenster. Verliert das Fenster die Verbindung zum Host, läuft der Durchlauf weiter, und Dream verbindet sich automatisch wieder mit ihm. Wenn du Dream beendest, wird der von der App gestartete Host samt seinen Durchläufen gestoppt; damit Agenten nach dem Schließen der App weiterarbeiten, [betreibe den Host selbst](/docs/de/dream-host).

Nachdem eine Antwort abgeschlossen ist, verwenden Sie im Footer **Dateiänderungen dieser Antwort anzeigen**, um die Dateien zu sehen, die sie verändert hat, und [eine davon wiederherzustellen](/docs/de/checkpoints).

## Nachrichten einreihen

Du musst nicht warten, bis eine Antwort abgeschlossen ist, bevor du die nächste Anweisung sendest. Gib eine Nachricht ein, während der Agent arbeitet, und sende sie ab. Dream fügt sie der Warteschlange des Chats hinzu und führt sie aus, sobald der aktuelle Durchlauf endet. Während ein Durchlauf läuft, stoppt die Schaltfläche des Composers den Durchlauf, wenn das Nachrichtenfeld leer ist, und sendet die Nachricht, sobald du etwas eingegeben hast.

Die Liste **Warteschlange** erscheint über dem Nachrichtenfeld, wenn eine Nachricht wartet oder eine Ausführung deine Aufmerksamkeit erfordert. Jede Zeile zeigt die Nachricht, ihr Modell und einen Status.

| Status | Bedeutung |
| --- | --- |
| Eingereiht | Wartet auf die Durchläufe vor ihr |
| Läuft | Der Durchlauf, an dem der Agent gerade arbeitet |
| Wartet | Der laufende Durchlauf wartet auf deine Antwort oder Genehmigung |
| Unterbrochen | Vor dem Abschluss gestoppt, etwa durch das Stopp-Steuerelement oder einen Neustart des Hosts |
| Fehlgeschlagen | Mit einem Fehler beendet |

Mit **Abbrechen** nimmst du eine eingereihte Nachricht aus der Warteschlange. Eine fehlgeschlagene oder unterbrochene Ausführung bietet **Wiederholen** und **Entfernen** an. Lies die Antwort, die eine unterbrochene Ausführung hinterlassen hat, bevor du sie wiederholst, denn ein Teil ihrer Arbeit ist möglicherweise schon erledigt.

**Pausieren** hält die eingereihten Nachrichten zurück und lässt den aktuellen Durchlauf zu Ende laufen. **Fortsetzen** startet sie wieder. Das Stopp-Steuerelement wirkt anders: Es beendet den laufenden Durchlauf samt allen Aufgaben, die er [delegiert](/docs/de/delegation) hat, und pausiert die Warteschlange.

Auch eine fehlgeschlagene oder unterbrochene Ausführung pausiert die Warteschlange; in deren Kopfzeile steht dann **Warteschlange pausiert**. Wenn du eine neue Nachricht sendest, wird die Warteschlange fortgesetzt, und diese Ausführungen werden verworfen.

Warteschlangen werden auf dem Host des Projekts gespeichert und bleiben bei einem Neustart von Dream erhalten. Nach einem Neustart des Hosts wird ein Durchlauf, der gerade lief, als unterbrochen markiert, und die Warteschlange bleibt pausiert, bis du sie fortsetzt. Kann eine eingereihte Nachricht nicht gesendet werden, kehrt ihr Text in das Nachrichtenfeld zurück.

## Schließen, archivieren oder löschen?

| Aktion | Ergebnis | Wie Rückkehrung |
| --- | --- | --- |
| Eine Chat-Spalte schließen | Entfernt es aus der mehrfachen Chat-Ausrichtung | Aus dem Chatverlauf öffnen |
| Eine Chat-Vorlage archivieren | Entfernt es aus der aktiven Chat-Geschichte | Wiederherstellen unter Einstellungen → Archivierte Chats |
| Ein archiviertes Chat-Löschen | Entfernt die Chat-Session und ihre Nachrichten dauerhaft aus Dream | Es kann nicht über Dream wiederhergestellt werden. |

Die Schließung einer Spalte ist nützlich, wenn mehr Platz benötigt wird. Die Archivierung ist nützlich, wenn eine Aufgabe abgeschlossen ist. Keine dieser Aktionen rückgängig macht die Änderungen des Agents an den Projektdateien.

Um einen anderen Ansatz auszuprobieren, während die bisherige Konversation erhalten bleibt, [verzweilen Sie eine Nachricht](/docs/de/branching-chats). Um eine Aufgabe für später vorzubereiten, [speichern Sie einen Prompt in Stash](/docs/de/stash). Für Anweisungen, die Sie über verschiedene Projekte hinweg wiederverwenden möchten, erstellen Sie einen [wiederholbaren Prompt](/docs/de/saved-prompts) und führen ihn aus dem Composer-Menü **+ → Prompt ausführen** aus. Geben Sie **$** ein, um ein [Agenten-Fähigkeits](/docs/de/skills) zu aktivieren.
