Dream brings your projects, AI coding agents, files, terminals, browser previews, and Git workflow
into one desktop workspace. Connect a supported agent CLI, open a folder, and work with one or more
chats without switching tools.

## What Dream includes

- A multi-project workspace with persistent project tabs
- Multiple side-by-side chats, chat branching, and an Activity panel that tracks every open chat
- Per-reply checkpoints for reviewing and restoring the files an agent changed
- Support for Codex CLI, Claude Code CLI, OpenCode CLI, Cursor Agent CLI, and Grok Build CLI
- A file explorer, file search and editing, integrated terminals, and browser previews
- Git status, branch, diff, commit, push, pull request, and worktree workflows, including merging
  a finished worktree back into its base branch
- Line-level diff feedback and browser element selection that send targeted messages to a chat

<Note>
  Dream runs coding agents through their installed CLIs. You need at least one supported CLI before
  you can begin a chat.
</Note>

## Understand the workspace

A **project** is a local folder with its own chats and tools. A **chat** is a conversation with its
own model and settings. Multiple chats in one project share its files; a **worktree** gives a task a
separate Git checkout.

Use [Agent modes and permissions](/docs/agent-modes) to choose how an agent works, and
[Context and usage](/docs/context-and-usage) to understand the information below the composer.
The [settings reference](/docs/settings) lists app-wide preferences. If something is missing or
fails to run, start with [Troubleshooting](/docs/troubleshooting).
