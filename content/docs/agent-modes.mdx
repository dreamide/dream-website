title: Agent permissions
description: Choose Ask, Accept edits, or Full access and respond to agent requests.
---

Each chat has a **Permissions** control beneath its message box. New chats inherit
**Settings → General → Models → Default permissions**, which starts at **Full access**.
Changing the default does not change existing chats.

## Choose permissions

1. Open the shield control beneath the message box. Its tooltip is **Permissions**.
2. Select **Ask**, **Accept edits**, or **Full access**.
3. Review your task and submit it.

| Permission | Intended behavior |
| --- | --- |
| Ask | Request approval for actions that require permission under the provider's configuration |
| Accept edits | Allow file edits automatically while retaining approval handling for other actions |
| Full access | Give the agent broader access to act without approval prompts |

The selected provider determines the exact permission behavior. **Ask** does not mean every read
or tool call prompts, and **Accept edits** does not approve every command.

<Note>
  Dream no longer has separate Build and Plan controls. To plan first, ask the agent to investigate
  and propose an approach before making changes. That instruction is not a read-only filesystem
  boundary; choose permissions appropriate to the task as well.
</Note>

## Respond to questions and approvals

An agent may ask you to clarify a requirement, choose an option, or approve an action. Read the
request in the conversation and respond using the controls it provides. A project tab can indicate
that an agent is waiting for your answer. Open that project and return to the conversation to
read the request.

If the request requires changing the task, give the agent the revised instruction in that chat.
Use the stop control to interrupt a response when necessary. Stopping does not roll back edits or
commands that already completed; inspect [Changes](/docs/git-workflows) afterward, or use the
reply's [checkpoint](/docs/checkpoints) to restore files it changed.

For parallel tasks that need separate files, use [worktrees](/docs/worktrees). Permission settings
do not give two chats in the same folder independent checkouts.
