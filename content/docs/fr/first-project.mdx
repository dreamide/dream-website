Une fois qu'au moins un modèle fourni est activé, vous pouvez ajouter un dossier local à Dream.

<Steps>
  <Step title="Ouvrir un dossier">
    À partir de l'écran de démarrage, sélectionnez **Ouvrir un dossier** et choisissez le répertoire du projet que Dream doit utiliser.
  </Step>
  <Step title="Choisir un modèle">
    Dream commence avec votre modèle par défaut. Utilisez le sélecteur de modèle dans le composant de discussion pour choisir n'importe quel autre fournisseur et modèle activé.
  </Step>
  <Step title="Choisir les permissions">
    Les nouvelles conversations héritent des **Autorisations par défaut** des Paramètres. Ouvrez le contrôle avec l’icône de bouclier sous la zone de message et choisissez **Demander**, **Accepter les modifications** ou **Accès complet** pour cette tâche. Consultez [Autorisations des agents](/docs/fr/agent-modes).
  </Step>
  <Step title="Envoyer un prompt">
    Décrivez le résultat souhaité et la manière dont il doit être vérifié. Par exemple : « Expliquez comment ce projet commence, identifiez sa commande de test et suggérez où ajouter une page de paramètres. » Dream maintient la conversation et les outils du projet dans le même espace de travail.
  </Step>
</Steps>

## Inspectez le résultat

Lisez la réponse et ouvrez les détails de l'outil lorsque vous souhaitez inspecter ce que l'agent a fait. Si une question est posée, répondez dans la même conversation. Si des fichiers sont modifiés, ouvrez **Modifications** dans la barre d'outils de droite pour consulter la différence. Utilisez **Fichiers** pour inspecter le code ou **Terminal** pour exécuter les vérifications du projet.

Pour les tâches nécessitant du code spécifique ou une capture d'écran, [ajoutez du contexte](/docs/fr/providing-context) avant d'envoyer la demande. Vous pouvez changer le modèle de conversation en utilisant le sélecteur situé sous la boîte de message. Pour changer le modèle de départ pour les conversations futures, utilisez **Paramètres → Général → Modèles → Modèle de chat par défaut**.

## Retourner vers un projet

Les projets ouverts restent disponibles sous forme de tabs. Si vous les fermez, utilisez **Fermés récemment** sur l'écran de démarrage pour les retrouver et les restaurer. Dream restaure le contexte du projet, comme les discussions et les outils ouverts, lorsque possible.

## Commencez une autre conversation

Utilisez **Nouveau chat** pour commencer une conversation séparée pour le même projet. Activez [multi-chat](/docs/fr/multiple-chats) lorsque vous souhaitez des conversations côte à côte. Chaque conversation possède ses propres messages, mais les chats dans le même projet partagent leurs fichiers.

Ouvrir [l'historique des chats](/docs/fr/chats) pour revenir à un travail antérieur. Lorsqu'une tâche est terminée, [archiver la conversation](/docs/fr/archived-chats) pour la supprimer de l'historique actif tout en la conservant disponible pour la restaurer.
