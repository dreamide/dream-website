title: "Hôtes distants"
description: "Ouvrez des projets sur d'autres machines via SSH ou HTTPS ; les agents, les fichiers, Git et les terminaux s'y exécutent."
---

Dream peut ouvrir des projets sur d'autres machines aux côtés de vos projets locaux. Les fichiers, les commandes Git, les processus des agents et les terminaux s'exécutent sur l'hôte du projet. L'onglet du projet et le pied de page sous le chat indiquent sur quel hôte vous travaillez.

Dream atteint un hôte de l'une des deux façons suivantes :

| Route | À utiliser lorsque | Ce qu'il vous faut |
| --- | --- | --- |
| SSH | Vous pouvez déjà exécuter `ssh` vers la machine | Une cible SSH. Dream y installe et y exécute son hôte |
| HTTPS | La machine exécute Dream ou `dream-host` avec l'[accès à distance](/docs/fr/remote-access) activé | L'adresse de l'hôte et un code d'association |

Un hôte peut avoir des routes des deux types. Consultez [Routes](/docs/fr/remote-hosts#routes).

## Ajouter un hôte SSH

1. Vérifiez que `ssh devbox` fonctionne dans votre terminal système, en remplaçant `devbox` par votre alias de configuration SSH ou `user@host`. Dream utilise le client SSH, la configuration et les clés de votre système.
2. Ouvrez **Paramètres → Connexions**. Sous **Hôtes distants**, choisissez **Ajouter un hôte**, puis **Hôte SSH**.
3. Saisissez la **Cible SSH**. Dream suggère des alias issus de votre configuration SSH. Le nom est facultatif et correspond par défaut à la cible.
4. Cliquez sur **Enregistrer**. Dream se connecte immédiatement à l'hôte.
5. Répondez dans Dream aux demandes de clé d'hôte, mot de passe, phrase secrète ou authentification à deux facteurs. Refuser ou annuler une demande arrête cette tentative de connexion.

Lors de la connexion, Dream installe sur cette machine l'hôte correspondant à la version de votre application sous `~/.dream/host/versions/`, puis le démarre. Rien ne doit y être installé au préalable. Si la machine ne peut pas télécharger l'hôte, Dream le télécharge localement et le transfère via SSH. Installez également les CLI des agents sur la machine distante et connectez-vous à leurs comptes ; ils s'exécutent dans l'environnement de cette machine.

Via SSH, Dream prend en charge les machines Linux x64, Linux ARM64 et macOS sur Apple silicon (ARM64). Les machines Linux nécessitent glibc 2.31 ou une version ultérieure. L'application de bureau depuis laquelle vous vous connectez peut fonctionner sur Windows, macOS ou Linux.

## Associer un hôte via HTTPS

Utilisez un code d'association lorsque SSH est indisponible ou peu pratique, par exemple pour atteindre l'ordinateur de votre bureau depuis un ordinateur portable via Tailscale ou un tunnel Cloudflare.

1. Sur l'autre ordinateur, activez l'[accès à distance](/docs/fr/remote-access) et créez un code avec **Associer un appareil**, ou exécutez `dream-host pair`.
2. Sur cet ordinateur, ouvrez **Paramètres → Connexions** et choisissez **Ajouter un hôte**, puis **Code d’association**.
3. Saisissez l'**Adresse de l’hôte** et le **Code d’association**. Le nom est facultatif.
4. Cliquez sur **Associer un hôte**.

Un code ne fonctionne qu'une fois et expire dix minutes après sa création. Cet ordinateur doit faire confiance au certificat HTTPS de l'hôte. Aucun compte Dream n'intervient ; cet ordinateur reste associé jusqu'à sa révocation sur l'hôte.

## Routes

Chaque hôte dispose d'une seule entrée sous **Hôtes distants**, quel que soit le nombre de façons de l'atteindre. Cliquez sur **Modifier** sur un hôte pour ouvrir ses routes, puis utilisez **Ajouter une route SSH** ou **Ajouter une route HTTPS** pour ajouter un autre accès. Vous pouvez renommer l'hôte dans la même boîte de dialogue.

Les routes sont essayées de haut en bas jusqu'à ce que l'une d'elles se connecte. Utilisez **Monter** et **Descendre** pour définir l'ordre, et **Supprimer la route** pour en supprimer une ; un hôte conserve toujours au moins une route. Lorsque la route préférée est indisponible, Dream bascule sur la suivante.

La prévisualisation, dans le [navigateur](/docs/fr/browser) de Dream, d'un site qui s'exécute sur l'hôte et l'ouverture du projet dans un éditeur externe avec **Ouvrir dans** nécessitent toutes deux une route SSH. Un hôte accessible uniquement en HTTPS fournit tout de même ses projets, ses chats, ses fichiers, Git et ses terminaux.

## Ouvrir un projet distant

1. Cliquez sur le **+** à côté des onglets de projet, puis sur **Ouvrir un dossier**.
2. Dans la boîte de dialogue **Ouvrir le dossier**, choisissez l'hôte sous **Ouvrir sur**. Dream s'y connecte si nécessaire.
3. Saisissez le **Chemin du dossier**. Dream liste les dossiers correspondants sur cet hôte au fil de la saisie ; appuyez sur **Tab** pour compléter celui qui est en surbrillance.
4. Cliquez sur **Ouvrir**. Le dossier distant s'ouvre dans un onglet de projet avec ses propres conversations et outils.

Si vous n'avez pas encore ajouté d'hôte, utilisez **Ajouter un hôte SSH…** en bas de la boîte de dialogue.

Les projets distants fermés apparaissent dans **Fermés récemment** avec leur hôte et leur chemin. Les rouvrir connecte cet hôte. Les chemins distants appartiennent à la machine distante ; utilisez un éditeur connecté à cette machine pour ouvrir des fichiers hors de Dream.

## Reconnecter ou supprimer un hôte

Chaque hôte affiche son état de connexion dans **Paramètres → Connexions**. Dream retente les connexions interrompues. Les onglets de projet restent visibles lorsqu'un hôte est indisponible, et l'envoi de messages est désactivé jusqu'à sa reconnexion. Si la reconnexion s'arrête, lisez l'erreur affichée et utilisez **Se reconnecter** dans le chat, ou **Se connecter** dans **Paramètres → Connexions**.

Les tours d'agent s'exécutent sur l'hôte ; un tour déjà en cours se poursuit donc pendant que cet ordinateur est déconnecté. Dream reprend le suivi du tour lorsqu'il se reconnecte.

**Se déconnecter** laisse en place les onglets de projet d'un hôte. **Supprimer** demande une confirmation, puis retire l'hôte et ses projets de cet espace de travail Dream et arrête leurs terminaux. Les fichiers et les chats présents sur l'hôte ne sont pas touchés.

## Problèmes de connexion

Vérifiez d'abord la même cible SSH dans votre terminal système. Corrigez les problèmes d'authentification ou de clé d'hôte avant de vous reconnecter. Si l'hôte ne peut pas démarrer, lisez l'erreur dans **Paramètres → Connexions** et vérifiez que la plateforme de la machine est prise en charge.

Lorsqu'un hôte HTTPS refuse la connexion, l'erreur précise si l'hôte exécute une version incompatible ou si cet ordinateur n'est pas autorisé. Mettez Dream à jour vers la même version sur les deux ordinateurs, ou créez un nouveau code d'association sur l'hôte et recommencez l'association.

Les versions de développement n'ont pas d'hôte publié à télécharger. Depuis le dépôt de l'application Dream, exécutez `pnpm host:install-dev devbox`, puis reconnectez-vous. La compilation distante nécessite Node.js 22 ou ultérieur, pnpm ou Corepack, make, Python 3 et une chaîne d'outils C++ (g++ 10 ou ultérieur). L'installateur arrête le démon de l'hôte de développement existant avant de remplacer son environnement d'exécution.
