title: "Travailler avec les conversations"

Un chat contient une conversation avec un agent de programmation. Un chat appartient généralement à un projet et possède son propre modèle, ses propres autorisations et son propre historique de conversation. Utilisez des chats distincts pour les tâches que vous souhaitez reprendre indépendamment, comme la correction d'un bug et la revue d'une fonctionnalité.

Pour poser une question sans ouvrir de dossier, démarrez un [chat sans projet](/docs/fr/standalone-chats).

## Commencer une conversation

1. Sélectionnez l'onglet projet dans lequel vous souhaitez travailler.
2. Cliquez sur **Nouveau chat** dans la barre latérale.
3. Vérifiez le modèle et les permissions ci-dessous la boîte de message.
4. Décrivez la tâche et envoyez votre message.

Les nouveaux chats utilisent vos [paramètres de modèle par défaut](/docs/fr/models). Un brouillon vide peut être réutilisé lorsque vous cliquez sur **Nouveau chat** à nouveau avant d'envoyer un message. Une fois que vous envoyez un message, la conversation apparaît dans l'historique du projet.

Pour un premier message utile, donnez à l'agent un résultat et une méthode pour le vérifier. Par exemple :

> Cherche pourquoi le formulaire de paramètres perd ses valeurs après une actualisation. Corrige la cause et explique comment tu as vérifié la correction.

Utilisez [les références de fichiers et les pièces jointes](/docs/fr/providing-context) pour pointer vers du code pertinent ou une image.

## Retourner à une conversation

1. Cliquez sur **Historique des discussions** dans la barre latérale gauche.
2. Parcourir les échanges du projet actuel, avec les conversations récemment mises à jour en premier lieu.
3. Saisissez une partie du titre d'un échange dans **Rechercher l'historique** pour affiner la liste.
4. Sélectionnez la conversation pour l'ouvrir.

La recherche dans l'historique filtre les titres de ce projet. Pour rechercher dans les titres et le texte des messages de tous les projets, cliquez sur **Rechercher dans les chats** dans la barre supérieure (par défaut **Command+Shift+F** sur macOS ou **Ctrl+Shift+F** sur Windows/Linux). Les résultats incluent les projets locaux, les hôtes distants connectés et les [chats sans projet](/docs/fr/standalone-chats). Sélectionner un résultat archivé le restaure ; sélectionner un chat d'un projet fermé rouvre ce projet.

Si un hôte ne peut pas être recherché, reconnectez-le et réessayez. Affinez la requête lorsque les résultats sont tronqués. Vous pouvez également gérer des conversations plus anciennes dans [Chats archivés](/docs/fr/archived-chats).

Lorsque [multi-chat](/docs/fr/multiple-chats) est activé, le choix d'une conversation peut l'afficher dans un layout côte à côte. Lorsque multi-chat est désactivé, vous visualisez une conversation à la fois.

## Renommer un chat

Dream peut générer un titre après que la conversation ait commencé. Pour lui donner un nom plus précis, ouvrez le menu **…** de la discussion et choisissez **Modifier**, ou cliquez deux fois sur le titre. Dans **Modifier le chat**, saisissez le nom et cliquez sur **Enregistrer**. Utilisez **Annuler** pour garder le nom existant.

Des noms comme « Corriger la persistance des paramètres » et « Vérifier les tests des paramètres » sont plus faciles à distinguer que plusieurs discussions nommées après le même projet.

## Suivre le travail en cours

Activez **Notifications de bureau** dans **Paramètres → Général → Messages de chat** pour recevoir une alerte lorsqu’un chat se termine, échoue ou attend votre réponse pendant que Dream est en arrière-plan. Cliquez sur une notification pour ouvrir le chat correspondant. **Son de notification** est une option distincte qui peut aussi retentir lorsque Dream est au premier plan.

Les notifications couvrent aussi les tours qui continuent de s'exécuter sur l'hôte alors que cette fenêtre ne les suit pas. Un tour que vous arrêtez vous-même n'en envoie pas.

Un indicateur de chargement signale les conversations qui reçoivent une réponse en continu. Lorsque vous envoyez un message, Dream le fait défiler dans la zone visible.

Pendant que l'agent réagit, le chat affiche son progrès et l'activité des outils. Ouvrir les détails de l'outil pour inspecter les commandes, les lectures de fichiers ou les modifications. Lorsque l'agent fournit une liste de tâches, le contrôle des tâches situé à côté de la boîte de message indique son progrès.

L'historique des discussions et les onglets de projet affichent un état pour chaque chat : un indicateur de chargement pendant qu'il répond, un point ambre lorsque l'agent vous attend et un point vert lorsqu'il a terminé et que vous ne l'avez pas encore ouvert. Sélectionnez le projet et ouvrez la conversation pour lire son dernier message. Utilisez le contrôle d'arrêt de la zone de saisie pour interrompre une réponse. Arrêter une réponse n'annule pas les modifications de fichiers déjà effectuées.

Un tour s'exécute sur l'hôte du projet, et non dans la fenêtre. Si la fenêtre perd sa connexion à l'hôte, le tour continue de s'exécuter et Dream s'y reconnecte automatiquement. Quitter Dream arrête l'hôte démarré par l'application, ainsi que ses tours ; pour que les agents continuent de travailler après la fermeture de l'application, [exécutez l'hôte vous-même](/docs/fr/dream-host).

Après que une réponse soit terminée, utilisez **Voir les fichiers modifiés par cette réponse** dans son pied de page pour voir les fichiers qu'elle a modifiés et [reconstituer l'un d'entre eux](/docs/fr/checkpoints).

## Mettre des messages en file d'attente

Vous n'avez pas besoin d'attendre la fin d'une réponse pour envoyer l'instruction suivante. Saisissez un message pendant que l'agent travaille et envoyez-le. Dream l'ajoute à la file d'attente du chat et l'exécute à la fin du tour en cours. Pendant qu'un tour est en cours, le bouton de la zone de saisie arrête le tour lorsque la zone de message est vide et envoie le message dès que vous avez saisi du texte.

La liste **File d’attente** apparaît au-dessus de la zone de message lorsqu'un message est en attente ou qu'une exécution requiert votre attention. Chaque ligne affiche le message, son modèle et un état.

| État | Signification |
| --- | --- |
| En attente | Attend la fin des tours qui le précèdent |
| En cours | Le tour sur lequel l'agent travaille actuellement |
| Attend une réponse | Le tour en cours attend votre réponse ou votre approbation |
| Interrompu | Arrêté avant la fin, par exemple par le contrôle d'arrêt ou un redémarrage de l'hôte |
| Échec | Terminé avec une erreur |

Utilisez **Annuler** sur un message en attente pour le retirer de la file d'attente. Une exécution en échec ou interrompue propose **Réessayer** et **Supprimer**. Lisez la réponse laissée par une exécution interrompue avant de la relancer, car une partie de son travail est peut-être déjà faite.

**Suspendre** retient les messages en attente et laisse le tour en cours se terminer. **Reprendre** les relance. Le contrôle d'arrêt est différent : il met fin au tour en cours, ainsi qu'aux tâches qu'il a [déléguées](/docs/fr/delegation), et met la file d'attente en pause.

Une exécution en échec ou interrompue met aussi la file d'attente en pause, et l'en-tête de la file indique **File en pause**. L'envoi d'un nouveau message relance la file d'attente et écarte ces exécutions.

Les files d'attente sont enregistrées sur l'hôte du projet et survivent au redémarrage de Dream. Après un redémarrage de l'hôte, un tour qui était en cours est marqué comme interrompu et la file d'attente reste en pause jusqu'à ce que vous la repreniez. Si un message en attente ne peut pas être envoyé, son texte revient dans la zone de message.

## Fermer, archiver ou supprimer ?

| Action | Résultat | Comment revenir |
| --- | --- | --- |
| Fermer une colonne de chat | Le retire du layout multi-chat | Ouvrir depuis l'historique des chats |
| Archiver un chat | Le retire de l'historique de conversation actif | Le restaurer dans Paramètres → Chats archivés |
| Supprimer une conversation archivée | Supprime définitivement la conversation et ses messages de Dream | Il ne peut pas être restauré via Dream |

Fermer une colonne est utile lorsque vous avez besoin d'espace supplémentaire. L'archivage est utile lorsque la tâche est terminée. Aucune de ces actions ne rétablit les modifications effectuées par l'agent sur les fichiers du projet.

Pour essayer une approche différente tout en conservant la conversation jusqu'à présent, [déclenchez une branche à partir d'un message](/docs/fr/branching-chats). Pour préparer une tâche à plus tard, [enregistrez un prompt dans Stash](/docs/fr/stash). Pour des instructions que vous souhaitez réutiliser dans plusieurs projets, créez un [prompt réutilisable](/docs/fr/saved-prompts) et exécutez-le depuis le menu **+ → Exécuter le prompt** du composant. Tapez **$** pour activer une [compétence d'agent](/docs/fr/skills).
