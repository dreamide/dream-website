Ouvrez les **Paramètres** avec l’icône d’engrenage en haut de Dream. La barre latérale contient **Général**, **Fournisseurs**, **Hôtes SSH**, **Prompts**, **Skills**, **Serveurs MCP** et **Chats archivés**. Les préférences générales s’appliquent dès que vous les sélectionnez. Les formulaires de prompts, de skills et de définition des serveurs disposent de leur propre action Créer ou Enregistrer.

## Général

| Paramètres | Ce que cela contrôle |
| --- | --- |
| Langue | La langue de l'interface |
| Terminal | Le shell utilisé pour les nouvelles sessions de terminal |
| Thème | Apparence Système, Claire ou Sombre |
| Couleur de base | Les tons gris de l'interface |
| Couleur d’accent | Actions principales et états actifs |

Modifier le shell du terminal affecte les nouvelles sessions. Ouvrir un nouveau terminal pour utiliser le choix ; voir [Terminals](/docs/fr/terminals).

### Messages de chat

| Paramètres | Par défaut | Ce que cela contrôle |
| --- | --- | --- |
| Afficher les résumés de raisonnement | On | Affichage des résumés fournis par le modèle |
| Grouper les appels d’outils | Désactivé | Regroupement compact de l'activité des outils |
| Développer les appels d’outils | Désactivé | Si les détails des appels d'outils commencent déployés |
| Modifier les points d'ancrage | On | Prendre des snapshots des fichiers du projet avant chaque réponse afin que vous puissiez les revue et les restaurer |

Les paramètres d'affichage influencent les conversations au sein des projets. Ils n'ont pas d'effet sur l'effort de raisonnement du modèle ni sur les autorisations supplémentaires des outils. Désactiver **Checkpoints de modifications** arrête la création de nouveaux snapshots ; voir [Vérifier et restaurer les modifications](/docs/fr/checkpoints).

### Modèles

Le groupe **Modèles** se trouve en haut de Général.

| Paramètres | Portée |
| --- | --- |
| Modèle de chat par défaut | Chats nouvellement créés dans les projets |
| Autorisations par défaut | Demander, accepter les modifications ou accès complet pour les nouveaux échanges |
| Effort | Effort de raisonnement pour les nouveaux chats, lorsque pris en charge par le modèle par défaut |
| Vitesse | Niveau de vitesse pour les nouveaux échanges, lorsque pris en charge par le modèle par défaut |
| Modèle de génération de texte | Messages de commit et texte de demande de fusion générés avec leur propre efficacité et rapidité |

Les discussions existantes conservent leurs propres choix. Activez un modèle sous Fournisseurs avant de le choisir comme modèle par défaut. Consultez [Modèles et valeurs par défaut](/docs/fr/models) pour le workflow complet de configuration.

## Fournisseurs

Chaque carte de fournisseur affiche l’état de détection de son CLI, la version installée, une action d’actualisation et un interrupteur d’activation. Activez le fournisseur et les modèles souhaités pour les rendre disponibles dans les sélecteurs. Un badge **Mise à jour disponible** signale une version plus récente du CLI lorsqu’elle est détectée ; mettez le CLI à jour en dehors de Dream, puis actualisez la carte.

Dream ignore les vérifications de mise à jour des CLI pour les fournisseurs désactivés. Activez un fournisseur avant de vérifier ses mises à jour disponibles.

Installez et connectez-vous via le CLI du fournisseur en dehors de Dream, puis rafraîchissez sa carte. Les paramètres de Dream ne remplacent pas le flux d'authentification du CLI. Voir [Connecter un fournisseur](/docs/fr/providers).

## Hôtes SSH

Ajoutez, modifiez, connectez, déconnectez ou supprimez des machines distantes dans **Paramètres → Hôtes SSH**. Chaque entrée présente une cible SSH, un nom, une commande d'hôte facultative, l'état de connexion et les éventuelles erreurs. Consultez [Espaces de travail distants SSH](/docs/fr/remote-hosts) pour la configuration et le rétablissement de la connexion.

## Chats archivés

| Contrôle | Ce que cela fait |
| --- | --- |
| Cases à cocher par ligne | Sélectionner des conversations archivées par projet |
| Case à cocher en haut | Sélectionner toutes les conversations archivées |
| Restaurer | Retourne les discussions sélectionnées dans l'historique actif |
| Supprimer | Supprime de manière permanente les discussions et messages sélectionnés dans Dream |
| Archiver les chats après | Définit le seuil de non-activité en jours ; par défaut 30 |
| Archiver maintenant | Archives de conversations qui répondent à ce seuil |

Le seuil ne planifie pas une tâche automatique. Voir [Archiver et restaurer des conversations](/docs/fr/archived-chats) avant d'utiliser des actions en masse ou la suppression permanente.

## Contrôles en dehors des Paramètres

Certains préférences appartiennent à des échanges ou à des projets individuels. Définissez le modèle, l'effort, la vitesse et les autorisations d'un échange dans son composant. Activez le mode multi-échanges dans le panneau de gauche. Redimensionnez les colonnes des échanges et les panneaux d'outils directement dans l'espace de travail.
