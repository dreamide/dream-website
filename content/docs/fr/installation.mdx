Dream est disponible sous forme d'application de bureau pour macOS, Windows et Linux.

<Card title="Télécharger Dream" icon="download" href="/fr/download">
  Ouvrir la page de téléchargement pour sélectionner le package correspondant à votre plateforme et à votre architecture.
</Card>

## Packages disponibles

| Plateforme | Paquets |
| --- | --- |
| macOS | DMG pour Apple Silicon (ARM64) ou Intel (x64) |
| Windows | Installeur pour x64 |
| Linux | DEB, RPM ou AppImage pour x64 |

## Avant d'ouvrir Dream

Installez et authentifiez au moins un [agent CLI pris en charge](/docs/fr/providers). Dream détecte le CLI et les modèles qu'il met à disposition ; les credentials API et les abonnements restent gérés par ce fournisseur.

## Mises à jour

Dream vérifie les mises à jour de l'application. Lorsqu'une mise à jour est disponible, utilisez l'action Mise à jour dans l'application ou téléchargez le package le plus récent depuis la [page de téléchargement](/fr/download).

<Tip>
  Si Dream ne détecte pas une interface de ligne de commande installée, vérifiez que la commande fonctionne dans votre terminal normal, puis actualisez le fournisseur depuis les paramètres de Dream.
</Tip>

## Étapes suivantes

Après l'installation, [connectez un fournisseur](/docs/fr/providers) et activez au moins un modèle. Ensuite, [ouvrez votre premier projet](/docs/fr/first-project). Vous pouvez choisir la langue de l'interface, l'apparence et le shell terminal dans [Paramètres → Général](/docs/fr/settings#général).

Si l'application s'ouvre mais que vous ne pouvez pas commencer une conversation, vérifiez [la résolution des problèmes liés au modèle et à l'éditeur](/docs/fr/troubleshooting#un-modèle-est-manquant-ou-je-ne-peux-pas-démarrer-une-conversation).
