---
title: "將任務委派給其他代理"
description: "讓代理將部分任務交給另一個提供者，稍後再檢查結果。"
---

代理可以將部分工作交給你已設定好的另一個代理提供者。例如，Claude Code 聊天可以在撰寫測試的同時，請 Codex 審查某項變更。不需要開啟任何設定，在訊息中提出要求即可。

## 要求代理委派任務

指明提供者，並說明它應該完成的工作：

> 在你撰寫測試的同時，請 Codex 審查此分支上的變更是否有錯誤。它完成後，回報它的發現。

代理會啟動該任務，繼續進行自己的工作，並在之後的回合檢查結果。委派的任務在同一個專案中執行，並共用專案的檔案。它不會收到父對話的內容，因此代理會為該任務另外撰寫指示。

每個任務都是同一個專案中的新聊天。其標題以 `Task:` 開頭，後面接著那些指示的開頭部分。開啟該聊天即可跟隨另一個代理的工作。

## 哪些提供者可以委派

Claude Code、Codex、OpenCode 和 Grok Build 的聊天可以委派任務，Cursor 和 Antigravity 的聊天則不行。六個提供者都可以接收任務，只要其 CLI 已安裝並登入即可。請參閱[連接提供者](/docs/zh-Hant/providers)。

## 權限與限制

- 委派的任務一開始會沿用父聊天的[權限](/docs/zh-Hant/agent-modes)，且權限永遠不會比它更廣。
- 停止父聊天的回合，也會停止它所委派的任務。
- 一個聊天最多可同時有 8 個進行中的委派任務。委派的任務可以再往下委派，最多 4 層。

<Warning>
  委派的任務與父聊天編輯同一個專案資料夾。請要求它進行審查或研究，或告訴每個代理該修改哪些檔案。任務需要獨立的檢出時，請使用 [Git 工作樹](/docs/zh-Hant/worktrees)。
</Warning>
