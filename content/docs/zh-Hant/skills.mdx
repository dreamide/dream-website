一項技能將指令打包到 `SKILL.md` 檔案中。Dream 透過該供應商的技能位置來發現選定代理和專案中的技能。技能選擇器支援 **Claude Code**、**Codex**、**OpenCode** 和 **Cursor Agent**。

## 在聊天中使用一個技能

1. 開啟聊天並選擇您想要使用的模型。
2. 在訊息框中輸入 **$** 再加上技能名稱的一部分。
3. 從選擇器中選擇一項技能並新增您的任務說明。
4. 傳送這條訊息。

例如，選擇 `release-checklist` 技能，並要求它在發布前審查目前的變更。Dream 將所選技能顯示為行內提及，並在已傳送的訊息上顯示技能徽章。切換聊天的供應商或專案時，可用技能可能會變化。

技能呼叫由所選供應商處理。提及一個技能會提供指令；它不會改變聊天的[許可權設定](/docs/zh-Hant/agent-modes)。

## 瀏覽和預覽技能

1. 開啟 **設定 → 技能**。
2. 選擇供應商分頁和要檢查的專案。
3. 選擇一個技能以檢視其描述、來源、路徑以及 `SKILL.md` 預覽。
4. 使用 **開啟資料夾** 在您首選的編輯器中編輯其檔案。

技能按範圍分組，例如 **專案**、**個人**、**外掛**、**受管理** 和 **內建**，當這些來源可用時。如果技能尚未出現，請在安裝或編輯後使用 **重新整理**。

## 啟用或禁用一個技能

Claude Code 和 Codex 提供按技能切換的功能。這些設定會更新供應商自身的配置，因此也會影響 Dream 之外的技能可用性。Claude Code 將覆蓋設定儲存在 `~/.claude/settings.json` 中；Codex 透過其應用伺服器將其儲存在 `~/.codex/config.toml` 中。

OpenCode 和 Cursor 在 Dream 中不提供按技能切換的功能。要停止載入某個技能，請在供應商的技能位置中管理其資料夾。

## 建立一個技能

1. 在 **設定 → 技能** 中，如果技能應屬於某個專案，則選擇該專案。
2. 點選 **新增技能**。
3. 輸入一個**名稱**，一個**說明**，說明在什麼情況下使用它，以及**說明 (SKILL.md)**。
4. 選擇一個或多個 **位置** 選項。
5. 可選地選擇 **僅在被提及時執行**，然後點選 **建立**。

名稱使用小寫字母、數字和連字元，最多 64 個字元。Dream 會在每個選定位置建立一個該名稱的資料夾，並在其中建立一個 `SKILL.md` 檔案。

| 位置 | 預期用途 |
| --- | --- |
| 專案 · `.agents/skills` | Codex、OpenCode 和 Cursor 的共享專案技能 |
| 專案 · `.claude/skills` | Claude Code 的專案技能 |
| 個人 · `~/.agents/skills` | Codex、OpenCode 和 Cursor 共享的個人技能 |
| 個人 · `~/.claude/skills` | Claude Code 的個人技能 |

專案位置需要一個開啟的專案。**僅在被提及時執行**才會寫入技能的 `disable-model-invocation` 設定；該設定如何被強制執行取決於供應商。

你也可以從 **儲存為技能** 開始，在 [設定 → 提示詞](/docs/zh-Hant/saved-prompts) 中。

## 如果某個技能缺失

檢查所選供應商和專案，重新整理列表，並檢視設定中顯示的任何發現錯誤。確認該技能位於供應商可讀的位置，並且未被禁用。一個供應商可用的技能並不一定在另一個供應商中可用。
