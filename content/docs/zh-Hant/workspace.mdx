每個 Dream 專案都有自己的工作區。專案標籤頁讓你在不同倉庫之間切換，同時保持每個專案開啟的聊天記錄和工具在一起。

專案也可以位於 [SSH 主機](/docs/zh-Hant/remote-hosts)上。執行指令前請檢查主機標籤；遠端專案的工具在該機器上運作。

## 新增和切換專案

1. 點選專案分頁旁邊的 **+**，或在入門螢幕使用 **開啟資料夾**。
2. 選擇你想要工作的資料夾。
3. 選擇其分頁以使其成為當前專案。

當前專案決定了你可見的聊天記錄、檔案、終端、瀏覽器標籤頁和存檔項。在傳送任務或執行命令前，請檢查所選標籤頁。當你希望相關專案放在一起時，可以拖動專案標籤頁進行排序。

## 在外部重新命名或開啟專案

開啟專案的 **…** 選單，選擇 **編輯** 來更改其顯示名稱或圖示。點選圖示上傳最多 5 MB 的影象，然後點選 **儲存**。重置自定義圖示以恢復專案自動檢測功能。在 Dream 中重新命名專案不會更改其磁碟上的資料夾名稱。

使用選單中的 **開啟於** 選項，在可用的外部編輯器中開啟專案。

## 後退到之前的聊天

在專案標籤旁邊使用 **返回** 和 **下一頁** 可以返回之前開啟的專案和聊天記錄。在 Windows 和 Linux 上，使用 **Alt+Left** 和 **Alt+Right**；在 macOS 上，使用 **Command+[** 和 **Command+]**。滑鼠上的後退和前進按鈕也有效。

該專案和聊天選擇的歷史記錄會隨之更新。切換工具面板不會新增條目，嵌入式瀏覽器有其獨立的導航歷史。終端或程式碼編輯器內的鍵盤快捷鍵由相應工具本身提供。

## 關閉並重新開啟專案

1. 開啟專案中的 **…** 選單並選擇 **關閉**。
2. 當你想要返回時，透過專案 **+** 按鈕開啟入門螢幕。
3. 在 **最近關閉** 中查詢專案，如有需要可使用搜尋欄位。
4. 選擇專案以重新開啟它。

關閉一個專案會移除其開啟的標籤頁；它不會刪除其資料夾。Dream 在可能的情況下會恢復已儲存的專案上下文，例如聊天記錄和已開啟的工具。不要將關閉的專案用作保持終端程序執行的方法。

## 查詢工作區控制元件

左側工具欄包含 **聊天記錄**、**新聊天** 和 **啟用多聊天**。將滑鼠懸停在圖示上可檢視其標籤。聊天輸入框中包含所選模型、在支援情況下包含努力程度和速度，以及許可權。

右側工具欄開啟專案工具：

| 工具 | 你可以做什麼 |
| --- | --- |
| [更改](/docs/zh-Hant/git-workflows) | 審查 Git 差分並還原檔案更改 |
| [檔案](/docs/zh-Hant/files) | 瀏覽檔案、搜尋路徑和編輯檔案內容 |
| [瀏覽器](/docs/zh-Hant/browser) | 預覽 URL 並檢查網頁 |
| [終端](/docs/zh-Hant/terminals) | 在單獨會話中執行專案命令 |
| [Git 操作](/docs/zh-Hant/git-workflows) | 提交、推送並建立拉取請求 |
| [拉取請求](/docs/zh-Hant/pull-requests) | 閱讀當前分支的拉取請求，釋出評論，併合並 |
| [暫存](/docs/zh-Hant/stash) | 儲存提示詞並稍後執行它們 |

**Git 操作**位於右側工具欄的頂部。倉庫專案會顯示 Git 控制選項。聊天區域下方的分支控制項顯示當前活動分支；可使用該功能切換分支或[建立一個工作樹](/docs/zh-Hant/worktrees)。在工作樹專案中，相同位置會顯示一個**工作樹**按鈕，用於開啟[完整工作樹](/docs/zh-Hant/worktrees#完成一個工作樹)對話方塊。

## 整理聊天記錄和麵板

點選工具以開啟其面板。當需要更多聊天空間時，使用面板的關閉或摺疊控制元件，並拖動面板分隔條來調整佈局。關閉工具面板與關閉其單獨的終端會話或瀏覽器標籤頁是不同的。

啟用 [多聊天](/docs/zh-Hant/multiple-chats) 功能，以可調整大小的列形式組織對話。每個聊天都有自己的對話歷史，而專案中的所有聊天共享相同的檔案。使用工作樹進行獨立檢出。

## 捕獲 Dream 視窗

在 Windows/Linux 上按 **Ctrl+Shift+S**，或在 macOS 上按 **Command+Shift+S** 可以捕獲 Dream 視窗。Dream 將截圖複製到剪貼簿，然後開啟對話方塊將其儲存為 PNG 檔案。取消儲存對話方塊會保留剪貼簿中的截圖。會有一個通知報告截圖是否被複制、儲存，或無法捕獲。

對於網頁的截圖，使用 [瀏覽器的截圖操作](/docs/zh-Hant/browser)。

對於應用程式的整體外觀、語言和模型偏好，開啟 [設定](/docs/zh-Hant/settings)。要查詢舊的對話，請使用 [聊天記錄](/docs/zh-Hant/chats) 或 [已歸檔聊天](/docs/zh-Hant/archived-chats)。
