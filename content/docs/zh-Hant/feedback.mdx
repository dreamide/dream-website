title: "向聊天傳送回饋"

---

Dream 可以根據你所看到的內容為你生成訊息。在差異列表中選擇行，或在瀏覽器預覽中選擇某個元素，新增評論，Dream 會將該評論以及一個代理可以操作的引用一起傳送出去。

## 在差異中註釋行

1. 在右側工具欄中開啟 **變更** 並展開一個檔案。
2. 拖動行號以選擇一段範圍，或懸停在行號上並點選其 **+** 控制元件來選擇單行。已選擇的行會高亮顯示。
3. 在彈出框的 **詢問任何問題...** 輸入框中輸入您的評論。
4. 如果希望評論開始一個獨立的對話，請啟用 **新聊天**。
5. 按 **Enter** 或點選 **傳送訊息**。

代理接收您的評論，隨後是一個包含檔案路徑、行範圍、行來自舊版本還是新版本以及所選行內容的**引用差異**塊。您可以選擇統一差異或分離差異的任一側的行，選擇可以跨越兩側。

行選擇僅在更改面板中可用。聊天訊息中顯示的差異、[此回覆中的更改](/docs/zh-Hant/checkpoints)以及工作樹完成對話方塊中的差異均不提供該功能。

例如，選擇新條件的行並詢問：

> 當列表為空時，該分支永遠不會執行。處理這種情況並新增一個測試。

## 從瀏覽器傳送一個頁面元素

1. 開啟 **瀏覽器** 並載入你想要討論的頁面。
2. 在瀏覽器工具欄點選 **選擇元素並傳送到聊天**。同一操作也可在瀏覽器操作選單中找到。
3. 將游標移動到頁面上。Dream 標註游標所指元素，並顯示其名稱和大小。
4. 點選元素。在此模式下點選會選擇元素，而不是啟用連結或按鈕。按 **Escape** 鍵退出該模式且不選擇任何內容。
5. 在“傳送到聊天”表單中，檢查縮圖和元素名稱，輸入您的評論，選擇是否啟用“新聊天”，然後點選“傳送到聊天”。

訊息包含頁面 URL 和標題、元素的名稱和 CSS 選擇器、其父級元素、尺寸和位置、可見文字、計算後的樣式以及 HTML。對於 React 和 Vue 應用程式，Dream 會附加元件鏈，在開發構建中還會附加原始檔位置。元素的截圖以 `browser-element.png` 的形式附帶。

在 Dream 中，元素選擇操作針對當前活動的瀏覽器標籤頁進行。嵌入式框架內的元素無法單獨選擇；選擇其中一個會選中整個框架。導航或重新載入頁面會取消選擇，長屬性值、文字和 HTML 內容會被截斷。

## 訊息的去向

| 新聊天 | 目標位置 |
| --- | --- |
| 關閉 | 專案的第一個公開聊天，成為當前聊天 |
| 在 | 當啟用多聊天功能時，在當前聊天旁邊開啟一個新聊天 |

如果目標聊天正在忙碌，傳送控制元件將被禁用並顯示 **聊天忙碌中**。訊息不會被排隊放在當前響應之後；請等待其完成或啟用 **新聊天**。

你在聊天 composer 中已經輸入的文字會被保留。如果訊息無法傳送，Dream 會將你的評論附加到該 composer 中，以便你自己傳送。按 **Escape** 或點選 popover 外部以在傳送前丟棄該評論。

在您想要指向檔案而無需選擇特定行時，使用 [專案引用和附件](/docs/zh-Hant/providing-context)；在您想要稍後儲存提示時，使用 [暫存](/docs/zh-Hant/stash)。
