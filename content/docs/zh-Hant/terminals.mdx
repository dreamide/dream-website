整合的終端可以在不離開 Dream 的情況下執行專案命令。點選右側工具欄的 **終端機** 可以開啟它。一個普通專案的終端預設啟動於專案資料夾中。

## 在聊天的同時執行命令

使用終端檢查專案、執行測試或啟動其本地應用，使用該專案文件中記錄的命令。終端和代理聊天在此工作區中使用相同的檔案。

為了進行瀏覽器預覽，啟動專案的應用，記下它列印的 URL，並在 Dream 的 [瀏覽器](/docs/zh-Hant/browser) 中開啟該 URL。開啟瀏覽器不會自動啟動伺服器。

## 管理終端會話

1. 開啟 **終端機**。
2. 點選 **開啟另一個終端機**，**+** 控制按鈕，建立另一個會話。
3. 選擇一個終端標籤頁以切換會話。
4. 在使用完終端後，請關閉其控制權。

為長時間執行的應用程式和偶爾的命令（如測試）使用獨立會話。關閉終端會話將終止其程序。關閉面板會保留您已使用的會話，但 Dream 會自動清理那些未收到使用者輸入的已開啟會話。

使用 **展開終端機** 為面板提供更多空間，使用 **收合終端機** 恢復其常規大小。展開或摺疊會改變佈局但不會關閉會話。

複製文字時，請先選中文字。在 macOS 上使用 **Command+C**，在 Windows/Linux 上使用 **Ctrl+C** 可複製選定的終端文字。如果沒有選中內容，終端可能會將 Ctrl+C 傳遞給前臺命令以中斷該命令。

## 選擇一個 shell

1. 開啟 **設定 → 一般**。
2. 查詢 **終端機**，並從其選擇器中選擇一個可用的 shell。
3. 開啟一個新的終端會話以使用選定的 shell。

現有的會話會保留它們啟動時的 shell。如果某個 shell 或命令不可用，請確認它是否已安裝，並且在您的系統終端中可以正常執行。

## 在終端中繼續一個 Claude 聊天記錄

對於一個已建立可恢復會話的 Claude 對話：

1. 等待當前響應完成。
2. 開啟聊天頭部分的 **…** 選單。
3. 選擇 **在終端機中繼續**。

Dream 在該會話的當前工作目錄中開啟一個名為 **Claude** 的終端，並執行 CLI 的 resume 命令。此操作僅適用於 Claude 會話；它不是針對每個供應商的通用匯出操作。

如果該選項缺失，請檢查聊天是否使用了 Claude 且已啟動了供應商會話。更改其模型或速度可能會重置該會話。如果續寫失敗，請驗證原始工作目錄仍存在且 Claude CLI 可用。
