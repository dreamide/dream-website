在右側面板中點選 **檔案** 以瀏覽當前專案的資料夾。從樹形結構中開啟一個檔案，以便與聊天內容一起檢視該檔案。檔案標籤頁讓你在多個已開啟的檔案之間切換。

## 查詢檔案

1. 開啟 **檔案**。
2. 在樹結構上方的“搜尋檔案”中輸入檔名或路徑的一部分。
3. 選擇一個結果以開啟它。
4. 清除搜尋以返回瀏覽樹。

在檔案動作中使用 **重新整理檔案**，當在 Dream 外部所做的變更未反映在樹狀結構中時。搜尋檔案可定位其路徑；使用 **在檔案中尋找** 可搜尋專案內容。

## 在檔案中尋找

要搜尋整個專案，請在檔案面板中選取 **在檔案中尋找**。輸入您的查詢，並根據需要使用 **區分大小寫**、**全字相符** 或 **使用規則運算式**。在 **檔案過濾器** 中，設定要包含的檔案（例如，`src, *.ts`）或要排除的檔案（例如，`*.test.ts`）。選取結果以開啟相符的行。如果結果被截斷，請縮小您的查詢或過濾條件。

專案搜尋會在磁碟上尋找文字。請先儲存編輯草稿；取代操作可在檔案內進行。

## 在檔案中搜尋和替換

1. 開啟檔案並在編輯器工具欄中點選 **搜尋目前檔案**。
2. 在 **尋找** 中輸入文字。
3. 使用 **下一個相符項目** 或 **上一個相符項目** 來瀏覽結果。
4. 如果需要，請啟用 **區分大小寫**、**全字相符** 或 **使用規則運算式**。

搜尋面板還提供了替換控制元件。使用 **全部取代** 之前，請先檢查匹配項，然後儲存檔案以將更改寫入磁碟。替換操作僅影響當前檔案。

## 編輯並儲存

在程式碼編輯器中編輯可寫文字檔案。未儲存的更改會在其標籤頁中標記，面板可以顯示有多少檔案有未儲存的草稿。

在編輯器工具欄點選 **儲存**，或在 macOS 上按 **Command+S**，在 Windows/Linux 上按 **Ctrl+S**（編輯器處於焦點狀態時）。在請求代理或終端命令使用新內容之前，必須先儲存每個已編輯的檔案；這些工具會讀取磁碟上的檔案。

切換檔案分頁可以讓你在檢查其他檔案的同時保留草稿。使用 **丟棄更改** 可以放棄本地草稿。這與透過 Git 撤銷更改是分開的。

雙擊檔案標籤以固定它，因此開啟另一個預覽不會取代它。

關閉帶有未儲存更改的標籤頁會開啟一個 **儲存 / 不儲存 / 取消** 提示。選擇“儲存”會寫入草稿並關閉標籤頁，“不儲存”會丟棄草稿並關閉標籤頁，而“取消”則保持標籤頁開啟。如果儲存失敗或與外部編輯發生衝突，檔案會保持開啟狀態，以便你可以解決該問題。

## 處理編輯器外部更改的檔案

當代理、終端命令或外部編輯器在您有草稿時修改了同一個檔案，Dream 在儲存時會檢查磁碟內容，並報告衝突，而不是靜默地覆蓋該較新版本。

1. 保留你想要保留的任何草稿文字。
2. 閱讀衝突資訊。
3. 使用 **從磁碟重新載入** 載入當前檔案。
4. 重新應用你仍然需要的更改，然後再次儲存。

<Warning>
  從磁碟重新載入會替換你的本地草稿。在使用它之前，請複製你需要的未儲存工作。
</Warning>

## 調整檢視

使用 **啟用自動換行** 處理長行。調整檔案樹和編輯器面板的大小，為內容提供更多的空間。使用可用的 **開啟於** 動作繼續編輯。

儲存後，開啟[更改](/docs/zh-Hant/git-workflows)檢查 Git 差異。如果要向代理詢問某個檔案，請在聊天輸入框中[使用 @ 引用該檔案](/docs/zh-Hant/providing-context)。
