title: "代理權限"

每個聊天在其訊息框下方都有一個**權限**控制。新聊天繼承**設定 → 一般 → 模型 → 預設權限**，預設值為**完整存取**。更改預設許可權不會影響現有的聊天。

## 選擇許可權

1. 開啟訊息輸入框下方的盾牌圖示控制項，其工具提示為**權限**。
2. 選擇 **詢問**、**接受編輯** 或 **完整存取**。
3. 檢查任務內容並送出。

| 許可權 | 預期行為 |
| --- | --- |
| 詢問 | 請求批准在供應商配置中需要許可權的操作 |
| 接受編輯 | 允許在保留其他操作審批處理的情況下自動進行檔案編輯 |
| 完整存取 | 給予代理更廣泛的行動許可權，無需審批提示 |

具體的權限行為由所選供應商決定。**詢問**並不表示每次讀取或工具呼叫都會要求核准，**接受編輯**也不表示核准所有命令。

<Note>
  Dream 不再提供獨立的 Build 和 Plan 控制項。如果希望先擬定計畫，請讓代理在進行變更前調查問題並提出方案。這項指示不會將檔案系統存取限制為唯讀；還應為任務選擇適當的權限。
</Note>

## 響應問題和審批

一個代理可能會要求你澄清需求、選擇選項或批准某個操作。閱讀對話中的請求，並使用提供的控制元件作出回應。一個專案標籤可能表示代理正在等待你的回答。開啟該專案，返回對話中閱讀請求。

如果需要調整任務，請在該聊天中向代理提供修改後的指示。必要時使用停止控制項中斷回應。停止不會復原已完成的編輯或命令；之後請檢查[變更](/docs/zh-Hant/git-workflows)，或使用該回應的[檢查點](/docs/zh-Hant/checkpoints)還原它修改的檔案。

對於需要單獨檔案的並行任務，請使用 [worktrees](/docs/zh-Hant/worktrees)。許可權設定不會為同一資料夾中的兩個聊天提供獨立的檢出。
