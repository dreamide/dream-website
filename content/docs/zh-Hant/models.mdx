title: "模型與預設設定"

Dream 將可用於使用的模型與特定任務所選擇的模型分開。**設定 → 提供者** 控制模型的可用性。**設定 → 一般**，在 **模型** 組中，控制預設設定。每個聊天訊息框下方的選擇器控制該次對話。

## 啟用模型

1. 安裝並認證一個 [支援的供應商 CLI](/docs/zh-Hant/providers)。
2. 開啟 **設定 → 提供者** 並啟用該供應商。
3. 重新整理供應商以檢測其 CLI 和可用模型。
4. 啟用您希望出現在 Dream 選擇器中的模型。

你可以啟用多個供應商提供的模型。如果某個模型在選擇器中缺失，請首先檢查此處是否已啟用。重新整理會檢測模型的可用性；它與選擇預設模型是分開的。

## 為新聊天設定預設值

1. 開啟 **設定 → 一般 → 模型**。
2. 在 **預設聊天模型** 中，選擇一個已啟用的模型。
3. 如果所選模型提供那些控制選項，請選擇 **推理強度** 和 **速度**。
4. 返回專案並開始新的聊天以使用選擇。

預設設定適用於專案中新建的聊天。現有對話會保留自己的模型設定。如果“新聊天”恢復了你已開啟的空草稿，請檢查其編輯器並根據需要更改模型。

## 為提交和拉取請求草稿設定一個模型

在相同的 **模型** 組中，選擇 **文字生成模型** 及其效能和速度（如果支援）。Dream 會在撰寫提交資訊和拉取請求文字時使用這些設定。

例如，你可以為實現聊天使用一個模型，為 Git 摘要使用另一個模型。更改 Git 撰寫模型不會影響你的聊天模型。有關在釋出前審查和編輯生成文字的詳細資訊，請參見 [Git 工作流程](/docs/zh-Hant/git-workflows)。

## 更改聊天的模型

1. 開啟對話並等待其當前響應完成。
2. 點選訊息框下方的模型名稱。
3. 選擇一個啟用的模型，包括需要時從其他供應商選擇模型。
4. 在傳送下一條訊息之前，請檢查努力程度和速度控制。

在 Dream 中，對話內容會持續可見。更改模型會重置其努力程度和速度選擇，如果需要特定值，請重新選擇。模型變更還會為後續工作啟動一個新的供應商會話；它不會改變已生成的訊息。

## 推理強度和速度

| 控制 | 目的 |
| --- | --- |
| 推理強度 | 選擇該模型提供的推理努力級別 |
| 速度 | 選擇一個支援的速度層級，例如標準或快速 |

這些控制元件僅在所選模型支援時出現。可用的努力級別因模型而異。速度等級可能有不同的使用影響；在選擇等級時，請參考選項描述以及您供應商的使用資訊。

預設的努力程度和速度適用於新聊天。在某個聊天中更改其中一項會影響力該對話。更改速度也會重置其提供者的會話，以供後續工作使用。

## 如果預設選項不可用

禁用選定的預設模型或重新整理已更改的模型列表可能會導致 Dream 選擇另一個啟用的模型。在更改啟用模型後，請重新檢查兩個預設選擇器。如果沒有任何模型處於啟用狀態，請在開始新對話前啟用一個模型。

對於缺失控制元件或檢測失敗，請參見 [故障排查](/docs/zh-Hant/troubleshooting)。
