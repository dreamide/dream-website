---
title: "遠端存取"
description: "透過 Tailscale 或 Cloudflare Tunnel 配對裝置，從手機或另一台電腦使用這台電腦上的專案。"
---

遠端存取可讓其他裝置使用這台電腦上的專案。已配對的裝置會在其瀏覽器中開啟 Dream，或從另一個 Dream 桌面應用程式連線，而代理、檔案、終端機和 Git 指令仍在這台電腦上執行。

遠端存取在你開啟之前會保持關閉，且每台裝置都必須先配對才能連線。Dream 不使用帳戶或中繼服務：網路路由由你提供，誰能連入則由配對控管。

## 選擇裝置存取這台電腦的方式

| 選項 | 運作方式 | 所需條件 |
| --- | --- | --- |
| Tailscale | 在你的 tailnet 內透過 HTTPS 提供 Dream | 這台電腦和每台裝置上都有 Tailscale，且已為 tailnet 開啟 MagicDNS 和 HTTPS 憑證 |
| Cloudflare Tunnel | 在你自己網域的公開主機名稱上提供 Dream | Cloudflare 帳戶中的常設通道，以及由你自行執行的 `cloudflared` 連接器 |

你也可以在主機前方架設自己的反向代理。請參閱[執行主機](/docs/zh-Hant/dream-host#從命令列使用遠端存取)。

## 開啟遠端存取

1. 開啟**設定 → 連線**，找到**遠端存取**。
2. 按一下**設定**。
3. 在**透過以下方式存取這台電腦**下，選擇 **Tailscale** 或 **Cloudflare Tunnel**。
4. 使用 Tailscale 時，保留或變更 **HTTPS 連接埠**。使用 Cloudflare Tunnel 時，輸入**公開位址**，例如 `https://dream.example.com`。
5. 除非需要特定連接埠，否則請將**本機連接埠**留空，然後按一下**開啟**。

一旦 Dream 能透過該位址連上這台電腦，**允許已配對裝置**旁的狀態就會顯示**就緒**。如果顯示**未就緒**，請依照顯示的訊息修正問題，然後按一下**重新檢查**。之後可使用**變更**編輯設定。關閉**允許已配對裝置**可停止為裝置提供服務，而不必解除配對。

### 設定 Cloudflare 通道

Dream 不會安裝或執行 `cloudflared`，也從不需要你的通道權杖。它只需要公開位址，以及該主機名稱所路由到的本機連接埠。

1. 在 Cloudflare 儀表板中建立通道，並在這台電腦上執行它顯示的安裝指令。
2. 為你網域上的某個主機名稱新增路由。將其服務設為 `HTTP` 和 `127.0.0.1:5410`，或設為 Dream 中顯示的**本機連接埠**。
3. 請確認該主機名稱可接受直接的 API 和 WebSocket 請求。不要在它前面加上 Cloudflare Access 登入或瀏覽器質詢，也不要快取或緩衝 `/api/*`。

不支援 Quick Tunnels。其位址會變動，而且無法傳輸聊天串流。

## 配對裝置

1. 遠端存取就緒後，按一下**配對裝置**。
2. 為該裝置選擇**存取權限**等級。
3. 按一下**建立配對**。Dream 會顯示**配對碼**和**主機位址**。
4. 在另一台裝置上，用瀏覽器開啟主機位址，輸入配對碼和**裝置名稱**，然後按一下**配對**。

若要改用另一個 Dream 桌面應用程式（而非瀏覽器）連線，請使用相同的位址和配對碼，[在該應用程式中將這台電腦新增為主機](/docs/zh-Hant/remote-hosts#透過-https-與主機配對)。

配對碼只能使用一次，並會在 10 分鐘後過期。任何輸入配對碼的人都會取得你所選的存取權限，因此請只將它提供給你要配對的裝置。

| 存取權限 | 裝置可執行的操作 |
| --- | --- |
| 僅檢視 | 讀取專案、聊天和終端機 |
| 檢視與工作 | 還能以你的身分執行代理、終端機和 Git |
| 完整存取 | 還能配對和移除裝置 |

## 從已配對的裝置使用 Dream

已配對的瀏覽器會顯示這台電腦上的專案，以及專案的聊天、檔案、終端機和 Git 面板。有幾項功能仍只在桌面應用程式中提供：內嵌的**瀏覽器**工具、**設定 → 連線**、在其他主機上開啟資料夾，以及用於外部編輯器的**開啟於**。

如果裝置失去連線，會出現橫幅提示正在重新連線，或提示無法連上主機、目前顯示的是先前儲存的內容。無論哪種情況，主機上的工作都會繼續進行。若要從裝置端解除配對，請在該裝置上開啟**設定**並選擇**登出**。

## 管理已配對的裝置

**已配對的裝置**會列出每台裝置及其存取權限等級和上次使用時間。按一下**撤銷**可移除一台裝置，按一下**全部撤銷**則會移除所有裝置。遭撤銷的裝置會立即失去存取權，其已開啟的頁面也會停止運作；這台電腦上的工作則會繼續。

## 讓這台電腦保持可用

只有在 Dream 的主機正在執行且這台電腦處於喚醒狀態時，裝置才能連線。由桌面應用程式啟動的主機會在你結束 Dream 時停止。若要讓主機在背景持續執行，或要分享沒有桌面工作階段的機器，請參閱[執行主機](/docs/zh-Hant/dream-host)。

如果「設定」回報這台電腦的主機版本與應用程式不同，請更新較舊的那一個，然後重新啟動主機。
