---
title: "遠端存取"
description: "從手機、瀏覽器或另一個 Dream 桌面應用程式使用這台電腦上的專案。"
---

遠端存取讓其他裝置可以使用這台電腦上的專案。手機或其他電腦會在瀏覽器中開啟 Dream，另一個 Dream 桌面應用程式則可以將這台電腦新增為[遠端主機](/docs/zh-Hant/remote-hosts#透過-https-配對主機)。每台裝置都必須先配對，你也可以隨時撤銷其存取權限。

代理、終端機和 Git 指令仍在這台電腦上執行。只有當 Dream 的主機在這台電腦上執行時，已配對裝置才能連線到它。若要在關閉 Dream 後讓主機持續執行，請將其安裝為[服務](/docs/zh-Hant/host-service)。

## 開始之前

選擇裝置連線到這台電腦的方式：

| 連線方式 | 所需條件 |
| --- | --- |
| Tailscale | 在這台電腦和每台裝置上安裝並登入 Tailscale，並為你的 tailnet 開啟 MagicDNS 和 HTTPS 憑證 |
| Cloudflare Tunnel | 你的 Cloudflare 帳戶中有一個持久的 Cloudflare Tunnel 和主機名稱，例如 `dream.example.com` |

對於 Cloudflare Tunnel，請建立一個專用、遠端管理的隧道，並只複製其連接器權杖。將其主機名稱路由到 Dream 顯示的 **本機連接埠** 上的 `http://127.0.0.1`，並對 `/api/*` 略過快取。不支援 Quick Tunnels，且該主機名稱不能要求互動式的 Cloudflare Access 登入。

## 開啟遠端存取

1. 開啟 **設定 → 連線**，找到 **遠端存取**。
2. 選擇 **設定**。
3. 在 **透過以下方式存取這台電腦** 下，選擇 **Tailscale** 或 **Cloudflare Tunnel**。
4. 對於 Cloudflare Tunnel，輸入 **公開位址** 並貼上 **隧道權杖**。如果連接器顯示 **未安裝**，請選擇 **安裝 cloudflared**。
5. 選擇 **開啟**。

Dream 會先檢查連線，然後才顯示 **就緒**。如果顯示 **未就緒**，請閱讀其下方的訊息，修正設定後使用 **重新檢查**。部分訊息會附帶 **開啟設定頁面**。

使用 **變更** 切換連線方式或替換隧道權杖。將權杖留空即可保留已儲存的權杖。**允許已配對裝置** 開關可關閉或開啟遠端存取，而不會遺失設定或已配對裝置。

### 進階選項

| 選項 | 它能做什麼 |
| --- | --- |
| HTTPS 連接埠 | Tailscale 為 Dream 提供服務的連接埠。如果 Tailscale 已在該連接埠上提供其他服務，請變更此連接埠 |
| 本機連接埠 | 這台電腦上接收遠端連線的連接埠。留空則自動選擇 |
| 我自行執行 cloudflared | 使用你另行安裝和執行的 Cloudflare 連接器。Dream 不會啟動、停止或刪除它 |

## 配對裝置

1. 遠端存取顯示 **就緒** 後，選擇 **配對裝置**。
2. 為裝置選擇 **存取權限** 等級。
3. 選擇 **建立配對**。
4. 在裝置上掃描 QR 碼或開啟連結。你也可以使用 **複製連結** 將其傳送出去。
5. 選擇 **完成**。

| 存取權限 | 裝置可執行的操作 |
| --- | --- |
| 僅檢視 | 讀取專案、聊天和終端機 |
| 檢視與工作 | 還能以你的身分執行代理、終端機和 Git |
| 完整存取 | 還能配對和移除裝置 |

連結只能使用一次，並會在 10 分鐘後過期。若要不透過連結進行配對，請在裝置上開啟主機位址，輸入 QR 碼旁顯示的配對碼，並為裝置命名。之後裝置會一直等待，直到你在這台電腦上選擇 **確認**（位於 **等待配對** 下）。對於任何你不認得的裝置，請選擇 **拒絕**。

若要配對另一個 Dream 桌面應用程式，請將連結貼到其 **新增主機 → 配對連結** 對話方塊中。請參閱[透過 HTTPS 配對主機](/docs/zh-Hant/remote-hosts#透過-https-配對主機)。

## 在已配對裝置上使用 Dream

已配對裝置會在瀏覽器中開啟 Dream。在手機上，Dream 會使用精簡版面配置。裝置可以在其存取權限範圍內，使用這台電腦上的專案、聊天、檔案和終端機。

如果無法連線到這台電腦，裝置上會顯示橫幅提示，並顯示其已儲存的內容。主機恢復可用後，Dream 會重新連線。處於睡眠狀態的電腦無法連線。

若要在裝置本身上移除其存取權限，請選擇 **登出**（位於 **此裝置** 下）。登出也會移除該瀏覽器儲存的內容。

## 管理已配對裝置

**已配對裝置** 列出每台裝置及其上次使用時間。選擇 **撤銷** 可移除裝置的存取權限。該裝置上開啟的頁面會立即停止運作；這台電腦上的工作會繼續進行。30 天內未使用的裝置必須重新配對。

## 遠端存取問題

| 訊息或症狀 | 該做什麼 |
| --- | --- |
| Tailscale 未安裝或未執行 | 安裝 Tailscale、登入並連線這台電腦，然後選擇 **重新檢查** |
| 這台電腦正在等待核准 | 在 Tailscale 管理主控台中核准它 |
| 開啟 MagicDNS 和 HTTPS 憑證 | 在 Tailscale 管理主控台中為你的 tailnet 同時啟用這兩項 |
| Tailscale 不允許此使用者變更其 Serve 設定 | 在 Linux 上，執行一次 `sudo tailscale set --operator=$USER`，然後重新檢查 |
| 連接埠已被其他程式占用 | 選擇其他 **HTTPS 連接埠** 或 **本機連接埠**（位於 **進階** 下） |
| 無法透過 Tailscale 連到這台電腦 | Tailscale 可能仍在取得憑證；請一分鐘後重新檢查 |
| 無法透過 Cloudflare 連到這台電腦 | 在 Cloudflare 中將該主機名稱的服務 URL 設為 `http://127.0.0.1`，並使用 Dream 中顯示的 **本機連接埠** |
| 正在等待 Cloudflare 連接器連線 | 檢查隧道權杖，並確認這台電腦允許對外連線 |
| 配對連結已過期或已被使用 | 再次選擇 **配對裝置** 並使用新連結 |
| 某台裝置停止運作 | 檢查它是否已被撤銷或已 30 天未使用，然後重新配對 |
