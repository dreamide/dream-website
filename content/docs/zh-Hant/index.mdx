Dream 將你的專案、AI 編碼代理、檔案、終端、瀏覽器預覽和 Git 工作流整合到一個桌面工作區中。連線一個受支援的代理 CLI，開啟一個資料夾，並在不切換工具的情況下與一個或多個聊天進行協作。

## Dream 包含了什麼

- 一個支援多專案的工作區，具有持久化的專案標籤頁
- 多個並排聊天視窗和聊天分支
- 專案間可複用的提示詞及供應商感知的代理技能
- 每條回覆的檢查點用於審查和恢復代理更改的檔案
- 支援 Codex CLI、Claude Code CLI、OpenCode CLI、Cursor Agent CLI 和 Grok Build CLI
- 檔案資源管理器、檔案搜尋與編輯、整合終端和瀏覽器預覽
- Git 狀態、分支、差異、提交、推送、拉取請求和工作樹工作流程，包括將完成的工作樹合併回其基礎分支
- 逐行差異回饋和瀏覽器元素選擇，可向聊天傳送定向訊息
- 一個用於審查程式碼、釋出評論、編輯詳情和合並的 GitHub 拉取請求面板
- 可配置的 MCP 伺服器和內建的瀏覽器互動代理工具

<Note>
  Dream 透過其已安裝的 CLI 執行程式碼代理。在開始聊天之前，你需要至少一個支援的 CLI。
</Note>

## 瞭解工作區

一個**專案**是包含自己聊天記錄和工具的本地資料夾。一個**聊天**是與特定模型和設定的對話。同一個專案中的多個聊天共享其檔案；一個**工作樹**為任務提供獨立的 Git 檢出。

使用 [智慧體許可權](/docs/zh-Hant/agent-modes) 來選擇智慧體的工作方式，並透過 [上下文與用量](/docs/zh-Hant/context-and-usage) 來了解 composer 以下的資訊。[設定參考](/docs/zh-Hant/settings) 列出了全域性應用偏好設定。如果某個功能缺失或無法執行，請先檢視 [故障排查](/docs/zh-Hant/troubleshooting)。
