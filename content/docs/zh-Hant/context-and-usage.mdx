Dream 顯示當前對話的資訊，以及在可用情況下所選供應商的使用限制。這些問題分別回答了不同的內容：聊天使用了多少上下文，以及供應商的配額使用了多少。

## 檢查對話上下文

使用訊息框下方的上下文指示器來檢查對話的上下文使用情況。上下文視窗是模型在生成響應時可以考慮的內容量，包括對話內容和工具結果。

Dream 在供應商提供使用資訊時會使用這些資訊，否則可能會根據訊息內容估算使用情況。將該指示視為指導而非精確的計費測量。更換模型可能會改變可用的上下文視窗。

## 理解壓縮

一些供應商透過總結舊的上下文來壓縮長對話。當供應商報告此操作時，Dream會在對話中顯示 **壓縮上下文…** 或 **上下文已壓縮**。

壓縮有助於代理繼續執行長時間任務，但摘要可能不會保留每個細節。如果對話已遠離原始請求，重新陳述關鍵要求並引用當前檔案。Dream 顯示的會話記錄和供應商使用的上下文並不一定完全相同。

壓縮行為由供應商整合控制。它與歸檔聊天不同，也不會釋放供應商賬戶的使用配額。

## 檢查供應商使用情況

1. 使用您想要檢查的供應商開啟一個聊天。
2. 點選訊息框下方的使用量計數器。
3. 審查可用的使用資訊和重置時間。

## 讓工具活動更易於閱讀

開啟 **設定 → 一般**，找到 **聊天訊息**：

| 設定 | 效果 |
| --- | --- |
| 顯示推理摘要 | 顯示模型提供的推理摘要 |
| 群組工具呼叫 | 將組工具活動歸類為緊湊的計數晶片 |
| 展開工具呼叫 | 預設展開工具呼叫詳情 |

這些設定僅改變呈現方式，不會改變模型所需推理的努力；請在 [模型與預設設定](/docs/zh-Hant/models) 中配置該部分。同一組包含 **變更檢查點**，用於控制 Dream 是否在每次回覆前儲存快照；詳情請參見 [審查與恢復更改](/docs/zh-Hant/checkpoints)。
