title: "MCP 伺服器"
description: "為支援的編碼代理新增或匯入外部工具。"
---

MCP 伺服器為代理提供了額外的工具。請在 **設定 → MCP 伺服器** 中配置它們。Dream 支援為 **Claude Code**、**Codex**、**OpenCode** 和 **Grok Build** 提供這些連線。Cursor 不支援 Dream 管理的 MCP 連線。

## 新增一個伺服器

1. 開啟 **設定 → MCP 伺服器**，並點選 **新增伺服器**。
2. 選擇一個唯一的**名稱**，可使用字母、數字、連字號和底線，並以字母或數字開頭。
3. 選擇 **傳輸方式** 並輸入伺服器提供的連線詳情。
4. 保持 **已啟用** 選項以使伺服器可用，然後點選 **儲存**。

| 傳輸 | 欄位 |
| --- | --- |
| 命令（標準輸入輸出） | 在**指令**中填寫執行檔，在**參數**中每行填寫一個引數，並視需要填寫**環境變數** |
| HTTP | HTTP 或 HTTPS **URL**，以及選填的**標頭** |
| SSE | HTTP 或 HTTPS **URL**，以及選填的**標頭** |

以每行一個 `KEY=VALUE` 對的形式輸入環境變數和頭資訊。將可執行檔案與其引數分開。例如，一個本地伺服器可能使用 `node` 作為其命令，絕對路徑到其入口檔案作為引數。

伺服器定義儲存在 Dream 的本地資料庫中，包括你輸入的任何憑據。這些值以未加密的形式儲存。

## 匯入現有配置

1. 選擇您想要包含其配置的專案。
2. 開啟 **設定 → MCP 伺服器 → 匯入…**。
3. 審查檢測到的伺服器、其原始檔以及任何警告。
4. 選擇要新增的伺服器並點選 **匯入**。

Dream 掃描 Claude 使用者和專案配置、Codex 的使用者配置，以及 Cursor 的使用者和專案 MCP 配置。名稱已配置的條目被標記為 **已存在**，且不會再次匯入。

將副本定義匯入 Dream 中。原始檔案的後續更改不會自動同步。匯入 Cursor 配置會使其伺服器可供 Dream 支援的供應商使用；它不會為 Dream 中的 Cursor 聊天新增 MCP 支援。

使用 **編輯** 來修改定義，使用 **儲存** 來應用該定義。切換 **已啟用** 為關閉以保留其配置，但不使其對後續代理請求可用。要刪除該定義，請使用 **刪除**，然後點選 **確認刪除**。刪除定義不會解除安裝其可執行檔案。

在更換伺服器後，向支援的聊天中傳送新的請求。如果供應商仍使用舊連線，請啟動一個新的聊天。檢查可執行檔案、URL、憑據以及聊天錯誤，以確保工具可用。

Dream 的[內建瀏覽器工具](/docs/zh-Hant/browser#要求代理使用瀏覽器)會為支援的供應商自動連線，無需在此處為它們新增伺服器。
