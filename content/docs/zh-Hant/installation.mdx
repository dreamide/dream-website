Dream 可作為 macOS、Windows 和 Linux 桌面應用程式使用。

<Card title="下載 Dream" icon="download" href="/zh-Hant/download">
  開啟下載頁面以選擇適用於您平臺和架構的包。
</Card>

## 可用的包

| 平臺 | 包 |
| --- | --- |
| macOS | 適用於 Apple 晶片（ARM64）或 Intel（x64）的 DMG 檔案 |
| Windows | x64 版本的安裝程式 |
| Linux | 適用於 x64 的 DEB、RPM 或 AppImage |

## 在開啟 Dream 之前

安裝並認證至少一個[支援的代理 CLI](/docs/zh-Hant/providers)。Dream 會檢測該 CLI 及其提供的模型；API 憑證和訂閱仍由該供應商管理。

## 更新

Dream 檢查應用程式更新。當有更新可用時，請在應用中使用更新操作，或從 [下載頁面](/zh-Hant/download) 下載最新版本。

<Tip>
  如果 Dream 未檢測到已安裝的 CLI，請確認該命令在您的普通終端中可以正常執行，然後從 Dream 的設定中重新整理供應商。
</Tip>

## 下一步

安裝後，請[連線一個供應商](/docs/zh-Hant/providers)並啟用至少一個模型。然後[開啟你的第一個專案](/docs/zh-Hant/first-project)。你可以在[設定 → 通用](/docs/zh-Hant/settings#一般)中選擇介面語言、外觀和終端 shell。

如果應用程式已開啟但無法開始對話，請檢查[模型和供應商故障排除](/docs/zh-Hant/troubleshooting#模型缺失或我無法開始聊天)。
