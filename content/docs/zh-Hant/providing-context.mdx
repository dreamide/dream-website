給代理一個結果，相關的上下文，以及它開始工作前的任何約束。檔案引用有助於它定位程式碼；附件可以提供額外材料，如截圖。

## 引用專案檔案或資料夾

1. 在聊天訊息框中輸入 **@** 再加上檔案或資料夾路徑的一部分。
2. 從列表中選擇一個結果。使用 **向上箭頭** 和 **向下箭頭** 在結果之間移動，然後按 **Enter** 或 **Tab** 來選擇一個。
3. 在插入的參考文獻周圍新增您的指令。
4. 提交該訊息。

例如，引用設定元件並提問：

> 解釋這個表單是如何載入和儲存首選項的。查詢為什麼重新整理會丟失所選值。

在你知道任務屬於哪個檔案時選擇檔案，或當代理需要檢查多個相關檔案時選擇資料夾。結果列表顯示父路徑，以幫助區分同名檔案。按 **Escape** 鍵取消列表。

引用標識當前專案中的位置。它們不會凍結檔案內容，也不會將整個目錄的副本附加到對話中。

## 附加一個檔案

1. 點選訊息框旁邊的“附加檔案”控制元件。
2. 選擇附件操作並從你的計算機中選擇一個檔案。
3. 檢查附件是否出現在 composer 中。
4. 解釋代理應該怎樣使用它，然後提交訊息。

對於截圖，描述預期行為以及存在的問題。所選的供應商和模型決定了它們可以使用的附件型別。

## 使用技能執行可重複的指令

在 composer 中輸入 **$** 可以查詢選定供應商和專案對應的 [代理技能](/docs/zh-Hant/skills)。選擇它後，描述你的任務。技能可以提供操作流程或專案規範，以及你訊息中提到的檔案引用和附件。

對於需要重複傳送的純文字，使用 [可重用提示](/docs/zh-Hant/saved-prompts)。

## 檢視和複製影象

在對話中點選圖片以開啟其更大的預覽。將滑鼠懸停在圖片上，可在右上角顯示 **複製圖片**，然後點選它將圖片複製到剪貼簿。

要為報告或其他聊天捕獲 Dream 視窗，請使用 [視窗截圖快捷方式](/docs/zh-Hant/workspace#捕獲-dream-視窗)。

## 在傳送之前移除上下文

使用附件的移除控制元件將其從編者中移除。對於內聯專案引用，刪除其在訊息中的提及；隨著引用的刪除，該引用也隨之被移除。檢查剩餘文字以確保請求仍然合理。

如果 **@** 未找到路徑，請驗證當前專案，並在 [檔案](/docs/zh-Hant/files) 中查詢該檔案。如果該檔案已被移動或重新命名，請使用其當前路徑。

## 為另一個聊天提供足夠的上下文

不同的聊天記錄不會自動共享它們的訊息。在開始一個審查聊天時，旁邊一個實現聊天，需要明確哪些內容發生了變化，哪些檔案是相關的，以及審查者應該檢查什麼。

使用 [分支](/docs/zh-Hant/branching-chats) 將之前的對話內容帶入另一個對話，或使用 [暫存](/docs/zh-Hant/stash) 儲存帶有專案引用的提示以供後續使用。
