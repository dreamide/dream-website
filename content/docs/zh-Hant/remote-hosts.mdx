title: "遠端主機"
description: "透過 SSH 或 HTTPS 開啟其他機器上的專案，代理、檔案、Git 和終端機都在該機器上執行。"
---

Dream 可以開啟其他機器上的專案，與本機專案並排使用。檔案、Git 指令、代理程序和終端機均在專案所屬的主機上執行。專案分頁和聊天下方的底部列會顯示你目前在哪台主機上工作。

Dream 透過以下兩種方式之一連上主機：

| 路由 | 適用時機 | 所需條件 |
| --- | --- | --- |
| SSH | 你已經可以用 `ssh` 連上該機器 | SSH 目標。Dream 會在該機器上安裝並執行其主機 |
| HTTPS | 該機器正在執行 Dream 或 `dream-host`，且已開啟[遠端存取](/docs/zh-Hant/remote-access) | 主機的位址和配對碼 |

一台主機可以同時擁有這兩種路由。請參閱[路由](/docs/zh-Hant/remote-hosts#路由)。

## 新增 SSH 主機

1. 在系統終端機中確認 `ssh devbox` 可以正常執行，將 `devbox` 替換為 SSH 設定別名或 `user@host`。Dream 使用系統的 SSH 用戶端、設定和金鑰。
2. 開啟**設定 → 連線**。在**遠端主機**下選擇**新增主機**，再選擇 **SSH 主機**。
3. 輸入 **SSH 目標**。Dream 會從你的 SSH 設定中建議別名。名稱為選填，預設與目標相同。
4. 按一下**儲存**。Dream 會立即連線至該主機。
5. 在 Dream 中回答主機金鑰、密碼、金鑰密語或雙因素驗證提示。拒絕或取消提示會停止這次連線嘗試。

連線時，Dream 會在該機器的 `~/.dream/host/versions/` 下安裝與你的應用程式版本相符的主機並將其啟動。該機器上不需要預先安裝任何東西。如果該機器無法下載主機，Dream 會先在本機下載，再透過 SSH 上傳。也請在遠端機器上安裝代理 CLI 並登入；它們在該機器的環境中執行。

透過 SSH 連線時，Dream 支援 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）機器。Linux 機器需要 glibc 2.31 或更新版本。你用來連線的桌面應用程式可以在 Windows、macOS 或 Linux 上執行。

## 透過 HTTPS 與主機配對

無法使用 SSH 或使用 SSH 不方便時，請使用配對碼，例如從筆記型電腦透過 Tailscale 或 Cloudflare 通道連上辦公室的電腦。

1. 在另一台電腦上開啟[遠端存取](/docs/zh-Hant/remote-access)，並使用**配對裝置**建立配對碼，或執行 `dream-host pair`。
2. 在這台電腦上開啟**設定 → 連線**，選擇**新增主機**，再選擇**配對碼**。
3. 輸入**主機位址**和**配對碼**。名稱為選填。
4. 按一下**配對主機**。

配對碼只能使用一次，並會在建立十分鐘後過期。這台電腦必須信任主機的 HTTPS 憑證。過程中不需要 Dream 帳戶；這台電腦會維持配對狀態，直到在主機上被撤銷為止。

## 路由

無論有多少種方式可以連上，每台主機在**遠端主機**下都只有一個項目。按一下主機上的**編輯**以開啟其路由，然後使用**新增 SSH 路由**或**新增 HTTPS 路由**加入另一種連線方式。你也可以在同一個對話方塊中重新命名主機。

Dream 會由上而下依序嘗試各個路由，直到其中一個連線成功。使用**上移**和**下移**設定順序，使用**移除路由**刪除路由；主機一律至少保留一個路由。偏好的路由無法使用時，Dream 會切換到下一個。

在 Dream 的[瀏覽器](/docs/zh-Hant/browser)中預覽在主機上執行的網站，以及使用**開啟於**在外部編輯器中開啟專案，都需要 SSH 路由。只能透過 HTTPS 連上的主機仍可提供其專案、聊天、檔案、Git 和終端機。

## 開啟遠端專案

1. 按一下專案分頁旁的 **+**，再按一下**開啟資料夾**。
2. 在**開啟資料夾**對話方塊中，於**開啟位置**下選擇主機。如有需要，Dream 會連線至該主機。
3. 輸入**資料夾路徑**。Dream 會在你輸入時列出該主機上相符的資料夾；按 **Tab** 可自動完成反白的資料夾。
4. 按一下**開啟**。遠端資料夾將作為專案分頁開啟，擁有自己的聊天和工具。

如果尚未新增主機，請使用對話方塊底部的**新增 SSH 主機…**。

## 重新連線或移除主機

每台主機的連線狀態都會顯示在**設定 → 連線**中。Dream 會重試中斷的連線。主機無法使用時，專案分頁仍然可見，但在重新連線之前無法傳送訊息。如果重新連線停止，請閱讀顯示的錯誤，然後在聊天中使用**重新連線**，或使用**連線**（位於**設定 → 連線**）。

代理回合是在主機上執行，因此這台電腦中斷連線時，已在執行的回合會繼續進行。重新連線後，Dream 會重新接上該回合。

**中斷連線**會保留主機的專案分頁。**移除**會先要求確認，接著從這個 Dream 工作區移除該主機及其專案，並停止它們的終端機。主機上的檔案和聊天不受影響。

## 連線問題

先在系統終端機中檢查相同的 SSH 目標。解決驗證或主機金鑰問題後再重新連線。如果主機無法啟動，請閱讀**設定 → 連線**中的錯誤，並確認該機器的平台受到支援。

HTTPS 主機拒絕連線時，錯誤訊息會說明是主機執行的版本不相容，還是這台電腦未獲授權。請將兩台電腦上的 Dream 更新為相同版本，或在主機上建立新的配對碼並重新配對。

開發版本沒有已發布的主機可供下載。請在 Dream 應用程式儲存庫中執行 `pnpm host:install-dev devbox`，然後重新連線。遠端建置需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3，以及 C++ 工具鏈（g++ 10 或更新版本）。安裝程式會先停止現有的開發主機常駐程式，再替換其執行環境。
