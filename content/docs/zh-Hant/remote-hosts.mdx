title: "遠端主機"
description: "透過 SSH 或 HTTPS 連線到另一台機器，並使用其專案、代理、檔案、Git 和終端機。"
---

Dream 可以開啟遠端機器上的專案，與本機專案並排使用。檔案、Git 指令、代理程序和終端機均在專案所屬的主機上執行。專案的主機標籤會顯示目前的工作位置。

透過 SSH 連線主機；或者，當另一台機器已開啟[遠端存取](/docs/zh-Hant/remote-access)時，透過 HTTPS 與該 Dream 主機配對。一個主機可以有多條路由，Dream 會使用第一條連線成功的路由。

Dream 透過 SSH 為 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）安裝受管理的主機執行環境。這些是遠端主機平台；Dream 桌面應用程式可以在 Windows、macOS 或 Linux 上執行。Linux 主機執行環境支援 glibc 2.31 或更新版本的系統。

## 新增 SSH 主機

1. 在系統終端機中確認 `ssh devbox` 可以正常執行，將 `devbox` 替換為 SSH 設定別名或 `user@host`。Dream 使用系統的 SSH 用戶端、設定和金鑰。
2. 開啟 **設定 → 連線**，然後選擇 **新增主機 → SSH 主機**。
3. 輸入 **SSH 目標**（或從 `~/.ssh/config` 建議的別名中選擇一個），以及選填的 **名稱**。
4. 將 **主機指令** 留空以自動安裝執行環境，然後按一下 **儲存**。Dream 會連線到新主機。
5. 在 Dream 中回答主機金鑰、密碼、金鑰密語或雙因素驗證提示。拒絕或取消提示會停止這次連線嘗試。

你也可以選擇 **新增 SSH 主機…**，該選項位於 **開啟資料夾** 對話方塊中。

受管理的執行環境依版本安裝在 `~/.dream/host/versions/` 下。如果主機無法下載執行環境，Dream 可以先在本機下載，再透過 SSH 上傳。也請在遠端機器上安裝代理 CLI 並登入；它們在該機器的環境中執行。

如果手動安裝了執行環境，請將**主機指令**設為在遠端機器上執行 `dream-host` 的指令。

## 透過 HTTPS 配對主機

配對可讓此桌面應用程式無需 SSH，即可透過該主機[遠端存取](/docs/zh-Hant/remote-access)設定所使用的位址連線到 Dream 主機。

1. 在主機上開啟 **設定 → 連線**，然後選擇 **配對裝置**（位於 **遠端存取** 下）。
2. 在此桌面應用程式上開啟 **設定 → 連線**，然後選擇 **新增主機 → 配對連結**。
3. 在 **連結** 分頁上貼上 **配對連結**。或者，在 **程式碼** 分頁上輸入主機上顯示的 **主機位址** 和 **配對碼**。
4. 輸入選填的名稱，然後選擇 **配對**。
5. 如果使用的是配對碼，請在主機遠端存取設定的 **等待配對** 下確認此桌面應用程式。

配對連結只能使用一次，並會在 10 分鐘後過期。這台電腦必須信任該主機的 HTTPS 憑證。

## 開啟遠端專案

1. 在入門畫面選擇 **開啟資料夾**。使用專案 **+** 按鈕可返回該畫面。
2. 在 **開啟位置** 中選擇主機。如果 Dream 提示，請連線該主機。
3. 輸入 **資料夾路徑**；Dream 會在你輸入時建議資料夾。你也可以瀏覽路徑下方的清單，並使用 **上一層資料夾**。
4. 按一下**開啟**。遠端資料夾將作為專案分頁開啟，擁有自己的聊天和工具。

已關閉的遠端專案會顯示在**最近關閉**中，並附有主機和路徑。重新開啟專案時會連線至該主機。遠端路徑屬於遠端機器；在 Dream 外開啟檔案時，請使用已連線至該機器的編輯器。

## 管理路由

路由是連到主機的一種方式：一個 SSH 連線或一個已配對的 HTTPS 位址。為同一主機新增多條路由，可在其中一條無法使用時繼續工作，例如在辦公室網路中使用 SSH，在其他地方使用 HTTPS。

1. 開啟 **設定 → 連線**，然後按一下主機上的 **編輯**。
2. 檢視路由。Dream 會依序嘗試各條路由，直到有一條連線成功；**目前路由** 會標示正在使用的那一條。
3. 使用 **上移** 和 **下移** 變更順序。
4. 選擇 **新增 SSH 路由** 或 **新增 HTTPS 路由**，為同一主機新增另一種連線方式；或選擇 **移除路由** 刪除一條路由。至少必須保留一條路由。

當首選路由無法使用時，Dream 會切換到下一條路由，並保持轉送連接埠不變。變更 HTTPS 路由需要新的配對連結。

## 重新連線或移除主機

**設定 → 連線** 中的每個主機都會顯示其狀態，例如 **已連線**、**正在重新連線…** 或 **連線失敗**。Dream 會重試中斷的連線。主機無法使用時，專案分頁仍然可見，但在重新連線之前無法傳送訊息。如果重新連線停止，請閱讀顯示的錯誤，然後使用 **連線**。

使用 **編輯** 變更主機的名稱、目標或指令。變更目標或指令會重新建立目前的連線。**中斷連線** 會保留其專案分頁。

**移除** 會先要求確認，然後從此 Dream 工作區中移除該主機及其專案，並停止其終端機。主機上的檔案和聊天不會被刪除。

## 連線問題

先在系統終端機中檢查相同的 SSH 目標。解決驗證或主機金鑰問題後再重新連線。如果主機執行環境無法啟動，請閱讀 **設定 → 連線** 中的錯誤，並檢查設定的 **主機指令** 或該平台是否有可用的執行環境。

對於 HTTPS 路由，請檢查主機是否正在執行，且遠端存取顯示 **就緒**。如果該路由顯示 **需要處理**（見主機的 **編輯** 對話方塊），表示裝置可能已被撤銷；請使用主機遠端存取設定中的新連結重新配對。請參閱[遠端存取問題](/docs/zh-Hant/remote-access#遠端存取問題)。

開發版本沒有已發布的執行環境可供下載。請在 Dream 應用程式存放庫中執行 `pnpm host:install-dev devbox`，然後將**主機指令**留空並重新連線。遠端建置需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3，以及 C++ 工具鏈（g++ 10 或更新版本）。安裝程式會先停止現有的開發主機常駐程序，再替換執行環境。
