title: "SSH 遠端工作區"
description: "連線至 SSH 主機，使用遠端專案、代理、檔案、Git 和終端機進行開發。"
---

Dream 可以透過 SSH 開啟遠端機器上的專案，與本機專案並排使用。檔案、Git 指令、代理程序和終端機均在專案所屬的主機上執行。專案的主機標籤會顯示目前的工作位置。

SSH 工作區從 Dream v0.25.0 開始提供。此版本包含適用於 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）的受管理主機執行環境。這些是遠端主機平台；Dream 桌面應用程式可以在 Windows、macOS 或 Linux 上執行。

1. 在系統終端機中確認 `ssh devbox` 可以正常執行，將 `devbox` 替換為 SSH 設定別名或 `user@host`。Dream 使用系統的 SSH 用戶端、設定和金鑰。
2. 開啟**設定 → SSH 主機**，然後選擇**新增 SSH 主機**。輸入 **SSH 目標**及選填的**名稱**。
3. 將**主機指令**留空以自動安裝執行環境。按一下**儲存**，再按一下**連線**。
4. 在 Dream 中回答主機金鑰、密碼、金鑰密語或雙因素驗證提示。拒絕或取消提示會停止這次連線嘗試。

受管理的執行環境依版本安裝在 `~/.dream/host/versions/` 下。如果主機無法下載執行環境，Dream 可以先在本機下載，再透過 SSH 上傳。也請在遠端機器上安裝代理 CLI 並登入；它們在該機器的環境中執行。

如果手動安裝了執行環境，請將**主機指令**設為在遠端機器上執行 `dream-host` 的指令。

## 開啟遠端專案

如果尚未新增主機，**在 SSH 主機上開啟**會直接前往**設定 → SSH 主機**。在那裡新增主機後，返回入門畫面以開啟其資料夾。

1. 在入門畫面選擇**在 SSH 主機上開啟**。使用專案 **+** 按鈕可返回該畫面。
2. 選擇**主機**，如有需要請先連線。使用**主資料夾**、**上一層資料夾**或**顯示隱藏資料夾**瀏覽資料夾，也可以直接輸入**資料夾路徑**。
3. 按一下**開啟**。遠端資料夾將作為專案分頁開啟，擁有自己的聊天和工具。

已關閉的遠端專案會顯示在**最近關閉**中，並附有主機和路徑。重新開啟專案時會連線至該主機。遠端路徑屬於遠端機器；在 Dream 外開啟檔案時，請使用已連線至該機器的編輯器。

## 重新連線或移除主機

Dream 會重試中斷的連線。主機無法使用時，專案分頁仍然可見，但傳送訊息會被停用，直到重新連線。如果重新連線停止，請閱讀顯示的錯誤，然後使用**重新連線**，或使用**連線**（位於**設定 → SSH 主機**）。

使用**編輯**更改主機名稱、目標或指令。更改目標或指令會重新建立目前的連線。**中斷連線**會保留專案分頁。**移除**會從目前 Dream 工作區移除主機及其專案，但不會刪除遠端檔案或主機目錄資料。

## 連線問題

先在系統終端機中檢查相同的 SSH 目標。解決驗證或主機金鑰問題後再重新連線。如果主機執行環境無法啟動，請閱讀**設定 → SSH 主機**中的錯誤，並檢查設定的**主機指令**或該平台是否有可用的執行環境。

開發版本沒有已發布的執行環境可供下載。請在 Dream 應用程式存放庫中執行 `pnpm host:install-dev devbox`，然後將**主機指令**留空並重新連線。遠端建置需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3，以及 C++ 工具鏈（g++ 10 或更新版本）。安裝程式會先停止現有的開發主機常駐程序，再替換執行環境。
