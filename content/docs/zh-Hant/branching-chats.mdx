---
title: "分支對話"
description: "從同一工作區的早期訊息或獨立的 Git 工作樹中繼續。"
---

當您希望探索另一種方法時，可以分支一個聊天。Dream會將選定訊息中的對話內容複製到一個新的聊天中，並保留原始對話。在該點之後的訊息不會包含在新聊天中。

## 在同一個工作區繼續

1. 開啟源對話並等待其響應完成。
2. 查詢您想要從中分支的訊息。
3. 使用其 **從此訊息繼續…** 動作。
4. 在“分支聊天”下選擇“此工作區”。
5. 在新對話中傳送一條跟進訊息，描述你想要嘗試的替代方案。

新的聊天會繼承源聊天的模型和許可權設定。在多聊天模式下，它會位於源聊天旁邊；在單聊天佈局中，它會成為可見的對話。

例如，當代理解釋了某個錯誤後，可以要求新的聊天記錄對比一個較小的修復方案。兩個對話都可以使用當前專案檔案。

<Note>
  分支會複製對話歷史。它不會將檔案系統恢復到選定訊息傳送時的狀態。工作區中的兩個聊天仍然共享相同的檔案。
</Note>

## 在新的工作樹中繼續

對於獨立檢出，使用 **從此訊息繼續… → 新工作樹**。此選項需要 Git 倉庫。Dream 建立一個工作樹專案，並生成一個包含複製歷史的新聊天。

此快捷方式以當前分支為基線，並從聊天標題生成分支名稱。它不會提示您選擇自定義的基引用。要自己選擇基引用和分支名稱，請[從分支切換器建立一個工作樹](/docs/zh-Hant/worktrees#建立一個工作樹)。

<Warning>
  一個新的工作樹從已提交的 Git 歷史記錄開始。它不包含未提交的更改，也不會重現所選訊息的確切檔案狀態。在進入工作樹分支之前，請儲存並提交新檢出中需要的任何更改。
</Warning>

## 選擇正確的分支型別

| 你想要…… | 使用 |
| --- | --- |
| 問一個關於當前程式碼的不同問題 | 此工作區 |
| 比較推理過程，同時保持之前的討論 | 此工作區 |
| 讓另一個代理編輯一個獨立檢出 | 新工作樹 |
| 在不復制任何訊息的情況下開始一個任務 | 新聊天 |

在處理響應時無法進行分支操作。如果工作樹選項不可用，請檢查專案是否位於 Git 倉庫中。有關開啟和移除生成專案的工作樹，請參見[工作樹](/docs/zh-Hant/worktrees)。
