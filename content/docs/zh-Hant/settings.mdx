在 Dream 頂部的齒輪圖示處開啟 **設定**。側邊欄包含 **一般**、**提供者**, **SSH 主機**、**提示詞**、**技能**、**MCP 伺服器** 和 **已封存聊天**。通用偏好設定在選擇時即生效。提示詞、技能和伺服器定義的表單各自擁有建立或儲存的操作。

## 一般

| 設定 | 它控制了什麼 |
| --- | --- |
| 語言 | 介面語言 |
| 終端機 | 新終端會話使用的 shell |
| 主題 | 系統/淺色/深色外觀 |
| 基礎色 | 介面的灰色調 |
| 強調色 | 主要操作和啟用狀態 |

更改終端外殼會影響新會話。開啟一個新的終端以使用選定的設定；參見 [終端](/docs/zh-Hant/terminals)。

### 聊天訊息

| 設定 | 預設值 | 它控制了什麼 |
| --- | --- | --- |
| 顯示推理摘要 | 在 | 模型提供的摘要的顯示 |
| 群組工具呼叫 | 關閉 | 工具活動的緊湊分組 |
| 展開工具呼叫 | 關閉 | 是否展開工具呼叫詳情 |
| 更改檢查點 | 在 | 在每次回覆前快照專案檔案，以便您審查和恢復更改 |

顯示設定會影響跨專案的對話，但不會改變模型的推理強度，也不會授予額外的工具許可權。關閉 **變更檢查點** 會停止生成新的快照；詳情請參見 [審查與恢復更改](/docs/zh-Hant/checkpoints)。

### 模型

**模型**組位於通用組的頂部。

| 設定 | 範圍 |
| --- | --- |
| 預設聊天模型 | 各專案中新建的聊天記錄 |
| 預設權限 | 提問、接受編輯或完全訪問新的聊天 |
| 推理強度 | 新聊天的推理開銷，當預設模型支援時 |
| 速度 | 新聊天的速度等級，當預設模型支援時 |
| 文字生成模型 | 生成提交資訊和拉取請求文字，具有自身努力和速度 |

現有的聊天記錄會保留各自的設定。在供應商中啟用一個模型之前，請選擇它作為預設模型。請參閱 [模型與預設設定](/docs/zh-Hant/models) 以獲取完整的設定流程。

## 提供者

每個供應商卡片顯示其檢測到的 CLI 狀態、已安裝版本、重新整理操作以及啟用開關。啟用供應商和具體模型以使其在選擇器中可用。當檢測到新版本時，會顯示“更新可用”徽章；請在 Dream 之外更新 CLI，然後重新整理卡片。

Dream 會略過已停用供應商的 CLI 更新檢查。請先啟用供應商，再檢查可用更新。

透過 Dream 之外的供應商 CLI 安裝並登入，然後重新整理其卡片。Dream 設定不會替代 CLI 的認證流程。請參見 [連線服務商](/docs/zh-Hant/providers)。

## SSH 主機

在**設定 → SSH 主機**中新增、編輯、連線、中斷連線或移除遠端機器。每個項目都包含 SSH 目標、顯示名稱、選填的主機指令、連線狀態及連線錯誤。設定和復原步驟請參閱 [SSH 遠端工作區](/docs/zh-Hant/remote-hosts)。

## 提示詞、技能和 MCP 伺服器

| 部分 | 你可以做什麼 |
| --- | --- |
| [提示詞](/docs/zh-Hant/saved-prompts) | 為任何專案的聊天建立、預覽、複製、重新排序和編輯可重用的提示 |
| [技能](/docs/zh-Hant/skills) | 按供應商和專案瀏覽技能，預覽 SKILL.md 檔案，並建立新技能 |
| [MCP 伺服器](/docs/zh-Hant/mcp-servers) | 新增或匯入工具伺服器並管理其連線設定 |

## 已封存聊天

| 控制 | 它能做什麼 |
| --- | --- |
| 行復選框 | 在不同專案中選擇已歸檔的對話 |
| 標題核取方塊 | 選擇所有已歸檔的對話 |
| 復原 | 將選中的聊天記錄返回到活動歷史記錄中 |
| 刪除 | 永久刪除 Dream 中選定的聊天記錄和訊息 |
| 在以下天數後封存聊天 | 設定不活動截止天數；預設值為30天 |
| 立即封存 | 歸檔符合該截止日期的聊天記錄 |

截止時間不會安排自動任務。在使用批次操作或永久刪除之前，請參閱[歸檔與恢復聊天](/docs/zh-Hant/archived-chats)。

## 設定之外的控制元件

某些偏好屬於單個聊天或專案。在聊天的編輯器中設定聊天的模型、努力程度、速度和許可權。在左側工具欄中切換多聊天模式。直接在工作區中調整聊天列和工具面板的大小。
