Dream está disponible como aplicación de escritorio para macOS, Windows y Linux.

<Card title="Descargar Dream" icon="download" href="/es/download">
  Abre la página de descarga para seleccionar el paquete para tu plataforma y arquitectura.
</Card>

## Paquetes disponibles

| Plataforma | Paquetes |
| --- | --- |
| macOS | DMG para Apple Silicon (ARM64) o Intel (x64) |
| Windows | Instalador para x64 |
| Linux | DEB, RPM o AppImage para x64 |

## Antes de abrir Dream

Instale y autentique al menos un [CLI del agente compatible](/docs/es/providers). Dream detecta el CLI y los modelos que ofrece; las credenciales de API y las suscripciones siguen siendo gestionadas por ese proveedor.

## Actualizaciones

Dream verifica actualizaciones de la aplicación. Cuando esté disponible una actualización, use la acción de actualización en la app o descargue el paquete más reciente desde la [página de descarga](/es/download).

<Tip>
  Si Dream no detecta un CLI instalado, verifica que el comando funcione en tu terminal normal, luego actualiza el proveedor desde las configuraciones de Dream.
</Tip>

## Pasos siguientes

Después de la instalación, [conéctate a un proveedor](/docs/es/providers) y activa al menos un modelo. Luego [abre tu primer proyecto](/docs/es/first-project). Puedes elegir el idioma de la interfaz, el aspecto y la shell del terminal en [Configuración → General](/docs/es/settings#general).

Si la aplicación se abre pero no puedes iniciar una conversación, revisa [solución de problemas de modelo y proveedor](/docs/es/troubleshooting#un-modelo-está-faltando-o-no-puedo-iniciar-una-conversación).
