Abre **Configuración** con el icono de engranaje en la parte superior de Dream. El panel lateral tiene **General**, **Proveedores**, **Hosts SSH**, **Prompts**, **Skills**, **Servidores MCP** y **Chats archivados**. Las preferencias generales se aplican al seleccionarlas. Los formularios para prompts, habilidades y definiciones de servidor tienen sus propios botones de Crear o Guardar.

## General

| Configuración | Qué controla |
| --- | --- |
| Idioma | El idioma de la interfaz |
| Terminal | La shell utilizada para nuevas sesiones de terminal |
| Tema | Apariencia Sistema, Claro o Oscuro |
| Color base | Los tonos grises de la interfaz |
| Color de acento | Acciones principales y estados activos |

Cambiar el shell del terminal afecta a las nuevas sesiones. Abre un nuevo terminal para usar la selección; consulta [Terminales](/docs/es/terminals).

### Mensajes de chat

| Configuración | Predeterminado | Qué controla |
| --- | --- | --- |
| Mostrar resúmenes de razonamiento | En | Mostrar resúmenes proporcionados por el modelo |
| Agrupar llamadas de herramientas | Apagado | Agrupación compacta de actividad de herramientas |
| Expandir llamadas de herramientas | Apagado | Si los detalles de llamada a herramientas comienzan expandidos |
| Cambiar puntos de control | En | Tomar instantáneas de los archivos del proyecto antes de cada respuesta para que puedas revisar y restaurar los cambios |

Las configuraciones de visualización afectan las conversaciones entre proyectos. No modifican el esfuerzo de razonamiento del modelo ni otorgan permisos adicionales para herramientas. Desactivar **Checkpoints de cambios** detiene la creación de nuevos instantáneos; consulte [Revisión y restauración de cambios](/docs/es/checkpoints).

### Modelos

El grupo **Modelos** se encuentra en la parte superior de General.

| Configuración | Alcance |
| --- | --- |
| Modelo de chat predeterminado | Chats recién creados en los proyectos |
| Permisos predeterminados | Preguntar, Aceptar ediciones o Acceso completo para nuevos chats |
| Esfuerzo | Esfuerzo de razonamiento para nuevos chats, cuando está soportado por el modelo predeterminado |
| Velocidad | Velocidad de tier para nuevos chats, cuando sea compatible con el modelo predeterminado |
| Modelo de generación de texto | Commit mensajes generados y texto de solicitud de incorporación, con su propio esfuerzo y velocidad |

Los chats existentes mantienen sus propias selecciones. Actível un modelo bajo Proveedores antes de elegirlo como predeterminado. Siga [Modelos y predeterminados](/docs/es/models) para el flujo completo de configuración.

## Proveedores

Cada tarjeta de proveedor muestra el estado de detección de su CLI, la versión instalada, una acción para actualizar la información y un interruptor de activación. Activa el proveedor y los modelos que quieras usar para que aparezcan en los selectores. La etiqueta **Actualización disponible** indica que se ha detectado una versión más reciente del CLI; actualízalo fuera de Dream y luego actualiza la información de la tarjeta.

Dream omite las comprobaciones de actualizaciones de CLI para proveedores desactivados. Activa un proveedor antes de comprobar sus actualizaciones disponibles.

Instale y inicie sesión a través de la CLI del proveedor fuera de Dream, luego actualice su tarjeta. Las configuraciones de Dream no reemplazan el flujo de autenticación de la CLI. Consulte [Conectar un proveedor](/docs/es/providers).

## Hosts SSH

Añade, edita, conecta, desconecta o elimina máquinas remotas en **Configuración → Hosts SSH**. Cada entrada muestra un destino SSH, nombre, comando del host opcional, estado de conexión y posibles errores. Consulta [Espacios de trabajo remotos por SSH](/docs/es/remote-hosts) para la configuración y recuperación.

## Chats archivados

| Control | Qué hace |
| --- | --- |
| Casillas de verificación de fila | Seleccionar conversaciones archivadas entre proyectos |
| Casilla de verificación del encabezado | Seleccionar todas las conversaciones archivadas |
| Restaurar | Devuelve los chats seleccionados a la historia activa |
| Eliminar | Elimina permanentemente los chats y mensajes seleccionados de Dream |
| Archivar chats después de | Establece el umbral de inactividad en días; predeterminado 30 |
| Archivar ahora | Archivos los chats que cumplan con ese umbral |

El límite no programa un trabajo automático. Consulte [Archivado y recuperación de chats](/docs/es/archived-chats) antes de usar acciones en masa o eliminación permanente.

## Controles fuera de Configuración

Algunas preferencias pertenecen a chats individuales o proyectos. Establezca el modelo, el esfuerzo, la velocidad y los permisos de un chat en su compositor. Active el modo multi-chat en la barra lateral izquierda. Redimensionar columnas de chat y paneles de herramientas directamente en el espacio de trabajo.
