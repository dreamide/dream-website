Dream lleva tus proyectos, agentes de codificación con inteligencia artificial, archivos, terminales, previsualizaciones de navegador y flujo de trabajo de Git a un solo espacio de trabajo en la escritorio. Conecta un CLI de agente compatible, abre una carpeta y trabaja con una o más conversaciones sin cambiar de herramienta.

## ¿Qué incluye Dream?

- Un espacio de trabajo multifunción con pestañas de proyecto persistentes
- [Espacios de trabajo remotos por SSH](/docs/es/remote-hosts) con agentes, archivos, Git y terminales remotos
- Múltiples chats lado a lado y ramificación de chats
- Prompts reutilizables entre proyectos y habilidades de agentes conscientes del proveedor
- Puntos de control por respuesta para revisar y restaurar los archivos que cambió un agente
- Soporte para Codex CLI, Claude Code CLI, OpenCode CLI, Cursor Agent CLI y Grok Build CLI
- Un explorador de archivos, búsqueda y edición de archivos, terminales integrados y previsualización de navegadores
- Estado de Git, rama, diferencia, commit, empuje, solicitud de incorporación y flujos de trabajo de árbol de trabajo, incluyendo la fusión de un árbol de trabajo terminado en su rama base
- Comentarios de diferencia de nivel de línea y selección de elementos del navegador que envían mensajes dirigidos a un chat
- Un panel de solicitud de pull en GitHub para revisar el código, publicar comentarios, editar detalles y fusionar
- Servidores MCP configurables y herramientas integradas de agentes para interacción con el navegador

<Note>
  Dream ejecuta agentes de programación a través de sus CLIs instalados. Necesitas al menos un CLI compatible antes de poder comenzar una conversación.
</Note>

## Entender el entorno de trabajo

Un **proyecto** es una carpeta de tu equipo o de un host SSH con sus propios chats y herramientas. Un **chat** es una conversación con su propio modelo y configuración. Varios chats de un proyecto comparten sus archivos; un **árbol de trabajo** proporciona una copia de trabajo de Git independiente para una tarea.

Use [Permisos del agente](/docs/es/agent-modes) para elegir cómo funciona un agente, y [Contexto y uso](/docs/es/context-and-usage) para comprender la información que se encuentra debajo del compositor. La [referencia de configuraciones](/docs/es/settings) lista las preferencias generales del aplicativo. Si algo está faltando o no se ejecuta, comienza con [Solución de problemas](/docs/es/troubleshooting).
