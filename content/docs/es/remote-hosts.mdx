Dream permite abrir proyectos en otras máquinas junto a tus proyectos locales. Los archivos, comandos de Git, procesos de agentes y terminales se ejecutan en el host del proyecto. La pestaña del proyecto y el pie situado debajo del chat muestran en qué host estás trabajando.

Dream accede a un host de una de estas dos formas:

| Ruta | Úsala cuando | Qué necesitas |
| --- | --- | --- |
| SSH | Ya puedes conectarte a la máquina con `ssh` | Un destino SSH. Dream instala y ejecuta allí su host |
| HTTPS | La máquina ejecuta Dream o `dream-host` con el [acceso remoto](/docs/es/remote-access) activado | La dirección del host y un código de vinculación |

Un host puede tener rutas de ambos tipos. Consulta [Rutas](/docs/es/remote-hosts#rutas).

## Añadir un host SSH

1. Comprueba que `ssh devbox` funciona en tu terminal del sistema, sustituyendo `devbox` por tu alias de configuración SSH o `user@host`. Dream usa el cliente SSH, la configuración y las claves de tu sistema.
2. Abre **Configuración → Conexiones**. En **Hosts remotos**, elige **Añadir host** y luego **Host SSH**.
3. Introduce el **Destino SSH**. Dream sugiere alias de tu configuración de SSH. El nombre es opcional y, si no lo indicas, se usa el destino.
4. Haz clic en **Guardar**. Dream se conecta al host de inmediato.
5. Responde en Dream a las solicitudes de clave del host, contraseña, frase de contraseña o autenticación de dos factores. Rechazar o cancelar una solicitud detiene ese intento de conexión.

Al conectarse, Dream instala en esa máquina, en `~/.dream/host/versions/`, el host que corresponde a la versión de tu aplicación y lo inicia. No hace falta instalar nada allí antes. Si la máquina no puede descargar el host, Dream lo descarga localmente y lo sube por SSH. Instala también las CLI de los agentes en la máquina remota e inicia sesión en ellas; se ejecutan en el entorno de esa máquina.

Por SSH, Dream admite máquinas Linux x64, Linux ARM64 y macOS con Apple silicon (ARM64). Las máquinas Linux necesitan glibc 2.31 o posterior. La aplicación de escritorio desde la que te conectas puede ejecutarse en Windows, macOS o Linux.

## Vincular con un host por HTTPS

Usa un código de vinculación cuando SSH no esté disponible o no resulte práctico, por ejemplo para acceder al equipo de tu oficina desde un portátil mediante Tailscale o un túnel de Cloudflare.

1. En el otro equipo, activa el [acceso remoto](/docs/es/remote-access) y crea un código con **Vincular un dispositivo**, o ejecuta `dream-host pair`.
2. En este equipo, abre **Configuración → Conexiones** y elige **Añadir host** y luego **Código de vinculación**.
3. Introduce la **Dirección del host** y el **Código de vinculación**. El nombre es opcional.
4. Haz clic en **Vincular host**.

Un código funciona una sola vez y caduca diez minutos después de crearse. Este equipo debe confiar en el certificado HTTPS del host. No interviene ninguna cuenta de Dream; este equipo permanece vinculado hasta que se revoque en el host.

## Rutas

Cada host tiene una sola entrada en **Hosts remotos**, sin importar de cuántas formas puedas acceder a él. Haz clic en **Editar** en un host para abrir sus rutas y usa **Añadir ruta SSH** o **Añadir ruta HTTPS** para añadir otra vía de acceso. Puedes cambiar el nombre del host en el mismo diálogo.

Las rutas se prueban de arriba abajo hasta que una conecta. Usa **Subir** y **Bajar** para establecer el orden, y **Eliminar ruta** para borrar una; un host siempre conserva al menos una ruta. Cuando la ruta preferida no está disponible, Dream cambia a la siguiente.

Tanto previsualizar en el [navegador](/docs/es/browser) de Dream un sitio que se ejecuta en el host como abrir el proyecto en un editor externo con **Abrir en** requieren una ruta SSH. Un host al que solo se accede por HTTPS sigue ofreciendo sus proyectos, chats, archivos, Git y terminales.

## Abrir un proyecto remoto

1. Haz clic en el **+** situado junto a las pestañas de proyecto y luego en **Abrir carpeta**.
2. En el diálogo **Abrir carpeta**, elige el host en **Abrir en**. Dream se conecta a él si es necesario.
3. Introduce la **Ruta de la carpeta**. Dream muestra las carpetas coincidentes de ese host a medida que escribes; pulsa **Tab** para completar la resaltada.
4. Haz clic en **Abrir**. La carpeta remota se abre como una pestaña de proyecto con sus propios chats y herramientas.

Si aún no has añadido ningún host, usa **Añadir host SSH…** en la parte inferior del diálogo.

Los proyectos remotos cerrados aparecen en **Cerrados recientemente** con su host y ruta. Al volver a abrirlos, Dream se conecta a ese host. Las rutas remotas pertenecen a la máquina remota; usa un editor conectado a ella para abrir archivos fuera de Dream.

## Reconectar o eliminar un host

Cada host muestra su estado de conexión en **Configuración → Conexiones**. Dream reintenta las conexiones interrumpidas. Las pestañas de proyecto siguen visibles cuando un host no está disponible y el envío de mensajes se desactiva hasta que se reconecta. Si la reconexión se detiene, lee el error mostrado y usa **Reconectar** en el chat, o **Conectar** en **Configuración → Conexiones**.

Los turnos de los agentes se ejecutan en el host, así que un turno que ya está en ejecución continúa mientras este equipo está desconectado. Dream retoma el turno cuando se reconecta.

**Desconectar** conserva las pestañas de proyecto del host. **Quitar** pide confirmación y luego quita el host y sus proyectos de este espacio de trabajo de Dream y detiene sus terminales. Los archivos y los chats del host no se tocan.

## Problemas de conexión

Primero comprueba el mismo destino SSH en tu terminal del sistema. Corrige los problemas de autenticación o de clave del host antes de reconectar. Si el host no puede iniciarse, lee el error en **Configuración → Conexiones** y comprueba que la plataforma de la máquina sea compatible.

Cuando un host HTTPS rechaza la conexión, el error indica si el host ejecuta una versión incompatible o si este equipo no está autorizado. Actualiza Dream a la misma versión en ambos equipos, o crea un nuevo código de vinculación en el host y vuelve a vincular.

Las compilaciones de desarrollo no tienen un host publicado para descargar. Desde el repositorio de la aplicación Dream, ejecuta `pnpm host:install-dev devbox` y vuelve a conectar. La compilación remota requiere Node.js 22 o posterior, pnpm o Corepack, make, Python 3 y herramientas de C++ (g++ 10 o posterior). El instalador detiene el demonio del host de desarrollo existente antes de sustituir su entorno de ejecución.
