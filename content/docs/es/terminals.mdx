El terminal integrado ejecuta comandos en tu proyecto sin dejar de estar en Dream. Haz clic en **Terminal** en la barra lateral derecha para abrirlo. Un terminal normal de proyecto comienza en el directorio del proyecto.

En un [proyecto SSH](/docs/es/remote-hosts), los comandos del terminal se ejecutan en el host remoto. Instala los comandos y herramientas de desarrollo que necesites en esa máquina.

## Ejecutar comandos junto a una conversación

Use un terminal para inspeccionar el proyecto, ejecutar pruebas o iniciar su aplicación local utilizando los comandos documentados por ese proyecto. El terminal y los chats de agente trabajan con los mismos archivos en este entorno.

Para una vista previa en navegador, inicie la aplicación del proyecto, observe la URL que imprime y abra esa URL en el [Navegador](/docs/es/browser) de Dream. Abrir el Navegador no inicia automáticamente un servidor.

## Gestionar sesiones de terminal

1. Abrir **Terminal**.
2. Haga clic en **Abrir otra terminal**, el control **+**, para crear otra sesión.
3. Elige una pestaña de terminal para cambiar de sesión.
4. Use el control de cierre de un terminal cuando ya no lo necesites.

Use sesiones separadas para una aplicación de larga duración y comandos ocasionales como pruebas. Cerrar una sesión de terminal termina su proceso. Cerrar el panel conserva las sesiones que has usado, pero Dream limpia automáticamente las sesiones abiertas que no han recibido ninguna entrada del usuario.

Use **Expandir terminal** para darle más espacio al panel y **Contraer terminal** para restaurar su tamaño habitual. Expandir o contraer cambia el diseño sin cerrar la sesión.

Al cambiar de panel de herramientas, las vistas del terminal se mantienen cargadas para que puedas volver a la misma sesión y su salida. Dream también intenta recuperar el renderizador del terminal si pierde su contexto gráfico.

Cuando se copia texto, selecciónelo primero. **Command+C** en macOS o **Ctrl+C** en Windows/Linux copia el texto seleccionado del terminal. Sin una selección, el terminal puede pasar Ctrl+C hasta interrumpir el comando en primer plano.

## Elige una shell

1. Abrir **Configuración → General**.
2. Busca **Terminal** y elige una shell disponible desde su selector.
3. Abrir una nueva sesión de terminal para usar la shell seleccionada.

Las sesiones existentes mantienen la shell con la que fueron iniciadas. Si una shell o comando no está disponible, verifique que esté instalado y funcione en su terminal de sistema.

## Continuar una conversación con Claude en un terminal

Para una conversación con Claude con una sesión establecida y reutilizable:

1. Espera hasta que la respuesta actual termine.
2. Abre el menú **…** del encabezado de la conversación.
3. Elige **Continuar en la terminal**.

Dream abre un terminal llamado **Claude** en el directorio de trabajo de esa sesión y ejecuta el comando resume del CLI. Esta acción es específica de las sesiones de Claude; no es una acción general de exportación para cada proveedor.

Si la opción está ausente, verifica que el chat use Claude y que haya iniciado una sesión de proveedor. Cambiar su modelo o velocidad puede reiniciar esa sesión. Si el continuación falla, verifica que el directorio de trabajo original siga existiendo y que el CLI de Claude esté disponible.
