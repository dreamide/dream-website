title: "Proyectos y espacio de trabajo"

Cada proyecto de Dream tiene su propio espacio de trabajo. Las pestañas de proyectos te permiten moverte entre repositorios mientras mantienes los chats y herramientas abiertos de cada proyecto juntos.

## Agregar y cambiar de proyecto

1. Haga clic en el **+** junto a las pestañas del proyecto, o use **Abrir carpeta** en la pantalla de inicio.
2. Elige el carpeta en la que quieres trabajar.
3. Selecciona su pestaña para hacer que sea el proyecto activo.

El proyecto activo determina qué chats, archivos, terminales, pestañas del navegador y elementos de stash ves. Revisa la pestaña seleccionada antes de enviar una tarea o ejecutar un comando. Arrastra las pestañas de proyecto para reordenarlas cuando quieras que los proyectos relacionados estén uno al lado del otro.

## Renombrar o abrir un proyecto externamente

Abre el menú **…** del proyecto y elige **Editar** para cambiar su nombre de visualización o icono. Haz clic en el icono para subir una imagen de hasta 5 MB, luego **Guardar**. Restablece un icono personalizado para volver a la detección automática desde el proyecto. Renombrar un proyecto en Dream no renombra su carpeta en disco.

Use las opciones **Abrir en** del menú para abrir el proyecto en un editor externo disponible.

## Vuelve a una conversación anterior

Use **Atrás** y **Adelante** junto a las pestañas de proyecto para volver a visitar proyectos y chats que abrió. En Windows y Linux, use **Alt+Left** y **Alt+Right**; en macOS, use **Command+[** y **Command+]**. Los botones de navegación de ratón también funcionan.

Esta historia sigue las selecciones de proyecto y de chat. Cambiar paneles de herramientas no añade entradas, y el navegador integrado tiene su propia historia de navegación. Los atajos de teclado dentro del terminal o del editor de código los deja a los mismos herramientas.

## Cerrar y volver a abrir un proyecto

1. Abre el menú **…** del proyecto y elige **Cerrar**.
2. Cuando quieras regresar, abre la pantalla de inicio rápidamente a través del botón **+** del proyecto.
3. Busca el proyecto en **Cerrados recientemente**, usando su campo de búsqueda si es necesario.
4. Selecciona el proyecto para reiniciarlo.

Cerrar un proyecto elimina su pestaña abierta; no borra su carpeta. Dream restaura el contexto del proyecto guardado, como chats y herramientas abiertas, cuando sea posible. No use un proyecto cerrado como medio para mantener un proceso de terminal activo.

## Buscar los controles del espacio de trabajo

La barra lateral contiene **Historial de chat**, **Nuevo chat** y **Activar multichat**. Pasa el ratón sobre un icono para ver su etiqueta. El compositor de chat contiene el modelo seleccionado, el esfuerzo y la velocidad cuando estén disponibles, y los permisos.

La barra lateral derecha abre las herramientas del proyecto:

| Herramienta | Lo que puedes hacer |
| --- | --- |
| [Cambios](/docs/es/git-workflows) | Revisar diferencias de Git y revertir cambios de archivo |
| [Archivos](/docs/es/files) | Explorar archivos, buscar rutas y editar el contenido de los archivos |
| [Navegador](/docs/es/browser) | Ver URLs y inspeccionar páginas web |
| [Terminal](/docs/es/terminals) | Ejecutar comandos de proyecto en sesiones separadas |
| [Acciones de Git](/docs/es/git-workflows) | Comitear, empujar y crear solicitudes de extracción |
| [Solicitudes de incorporación](/docs/es/pull-requests) | Lee el PR de la rama actual, publique comentarios y realice la fusión |
| [Stash](/docs/es/stash) | Guardar prompts y ejecútalos más tarde |

**Acciones de Git** se encuentra en la parte superior de la barra lateral derecha. Los controles de Git aparecen para los proyectos de repositorio. El control de ramas debajo del chat muestra la rama activa; use este para cambiar de rama o [crear un árbol de trabajo](/docs/es/worktrees). En un proyecto de árbol de trabajo, el mismo lugar muestra un botón de **árbol de trabajo** que abre el diálogo [Completar árbol de trabajo](/docs/es/worktrees#completear-un-árbol-de-trabajo).

## Organice conversaciones y paneles

Haga clic en una herramienta para abrir su panel. Use el control de cierre o colapso del panel cuando necesite más espacio para los chats, y arrastre los divisores de panel para reorganizar el diseño. Cerrar un panel de herramienta es diferente de cerrar sus sesiones individuales de terminal o sus pestañas de navegador.

Habilite [multi-chat](/docs/es/multiple-chats) para organizar conversaciones en columnas resizables. Cada chat tiene su propia historia de conversación, mientras que todos los chats en el proyecto utilizan los mismos archivos. Use árboles de trabajo para checkouts independientes.

## Capturar la ventana de Dream

Presione **Ctrl+Shift+S** en Windows/Linux o **Command+Shift+S** en macOS para capturar la ventana de Dream. Dream copia la captura de pantalla al portapapeles, luego abre un cuadro de diálogo para guardarlo como PNG. Cancelar el cuadro de diálogo de guardado mantiene la copia en el portapapeles. Un aviso informa si la imagen fue copiada, guardada o no se pudo capturar.

Para una captura de pantalla de una página web, use la acción de captura de pantalla del [navegador](/docs/es/browser).

Para el aspecto general de la aplicación, el idioma y las preferencias de modelo, abre [Configuración](/docs/es/settings). Para encontrar conversaciones antiguas, utiliza [Historial de chats](/docs/es/chats) o [Chats archivados](/docs/es/archived-chats).
