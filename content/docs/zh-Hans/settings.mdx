在 Dream 顶部的齿轮图标处打开 **设置**。侧边栏包含 **通用**、**提供商**, **SSH 主机**、**提示词**、**技能**、**MCP 服务器** 和 **已归档聊天**。通用偏好设置在选择时即生效。提示词、技能和服务器定义的表单各自拥有创建或保存的操作。

## 通用

| 设置 | 它控制了什么 |
| --- | --- |
| 语言 | 界面语言 |
| 终端 | 新终端会话使用的 shell |
| 主题 | 系统/浅色/深色外观 |
| 基础色 | 界面的灰色调 |
| 强调色 | 主要操作和激活状态 |

更改终端外壳会影响新会话。打开一个新的终端以使用选定的设置；参见 [终端](/docs/zh-Hans/terminals)。

### 聊天消息

| 设置 | 默认值 | 它控制了什么 |
| --- | --- | --- |
| 显示推理摘要 | 在 | 模型提供的摘要的显示 |
| 分组工具调用 | 关闭 | 工具活动的紧凑分组 |
| 展开工具调用 | 关闭 | 是否展开工具调用详情 |
| 更改检查点 | 在 | 在每次回复前快照项目文件，以便您审查和恢复更改 |

显示设置会影响跨项目的对话，但不会改变模型的推理强度，也不会授予额外的工具权限。关闭 **更改检查点** 会停止生成新的快照；详情请参见 [审查与恢复更改](/docs/zh-Hans/checkpoints)。

### 模型

**模型**组位于通用组的顶部。

| 设置 | 范围 |
| --- | --- |
| 默认聊天模型 | 各项目中新建的聊天记录 |
| 默认权限 | 提问、接受编辑或完全访问新的聊天 |
| 推理强度 | 新聊天的推理开销，当默认模型支持时 |
| 速度 | 新聊天的速度等级，当默认模型支持时 |
| 文本生成模型 | 生成提交信息和拉取请求文本，具有自身努力和速度 |

现有的聊天记录会保留各自的设置。在提供商中启用一个模型之前，请选择它作为默认模型。请参阅 [模型与默认设置](/docs/zh-Hans/models) 以获取完整的设置流程。

## 提供商

每个提供商卡片显示其检测到的 CLI 状态、已安装版本、刷新操作以及启用开关。启用提供商和具体模型以使其在选择器中可用。当检测到新版本时，会显示“更新可用”徽章；请在 Dream 之外更新 CLI，然后刷新卡片。

Dream 会跳过已禁用提供商的 CLI 更新检查。请先启用提供商，再检查可用更新。

通过 Dream 之外的提供商 CLI 安装并登录，然后刷新其卡片。Dream 设置不会替代 CLI 的认证流程。请参见 [连接服务商](/docs/zh-Hans/providers)。

## SSH 主机

在**设置 → SSH 主机**中添加、编辑、连接、断开或移除远程机器。每个条目都包含 SSH 目标、显示名称、可选的主机命令、连接状态及连接错误。设置和恢复步骤请参阅 [SSH 远程工作区](/docs/zh-Hans/remote-hosts)。

## 提示词、技能和 MCP 服务器

| 部分 | 你可以做什么 |
| --- | --- |
| [提示词](/docs/zh-Hans/saved-prompts) | 为任何项目的聊天创建、预览、复制、重新排序和编辑可重用的提示 |
| [技能](/docs/zh-Hans/skills) | 按提供商和项目浏览技能，预览 SKILL.md 文件，并创建新技能 |
| [MCP 服务器](/docs/zh-Hans/mcp-servers) | 添加或导入工具服务器并管理其连接设置 |

## 已归档聊天

| 控制 | 它能做什么 |
| --- | --- |
| 行复选框 | 在不同项目中选择已归档的对话 |
| 标题复选框 | 选择所有已归档的对话 |
| 恢复 | 将选中的聊天记录返回到活动历史记录中 |
| 删除 | 永久删除 Dream 中选定的聊天记录和消息 |
| 在以下天数后归档聊天 | 设置不活动截止天数；默认值为30天 |
| 立即归档 | 归档符合该截止日期的聊天记录 |

截止时间不会安排自动任务。在使用批量操作或永久删除之前，请参阅[归档与恢复聊天](/docs/zh-Hans/archived-chats)。

## 设置之外的控件

某些偏好属于单个聊天或项目。在聊天的编辑器中设置聊天的模型、努力程度、速度和权限。在左侧工具栏中切换多聊天模式。直接在工作区中调整聊天列和工具面板的大小。
