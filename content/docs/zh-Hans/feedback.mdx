Dream 可以根据你所看到的内容为你生成消息。在差异列表中选择行，或在浏览器预览中选择某个元素，添加评论，Dream 会将该评论以及一个代理可以操作的引用一起发送出去。

## 在差异中注释行

1. 在右侧工具栏中打开 **更改** 并展开一个文件。
2. 拖动行号以选择一段范围，或悬停在行号上并点击其 **+** 控件来选择单行。已选择的行会高亮显示。
3. 在弹出框的 **询问任何问题...** 输入框中输入您的评论。
4. 如果希望评论开始一个独立的对话，请启用 **新聊天**。
5. 按 **Enter** 或点击 **发送消息**。

代理接收您的评论，随后是一个包含文件路径、行范围、行来自旧版本还是新版本以及所选行内容的**引用差异**块。您可以选择统一差异或分离差异的任一侧的行，选择可以跨越两侧。

行选择仅在更改面板中可用。聊天消息中显示的差异、[此回复中的更改](/docs/zh-Hans/checkpoints)以及工作树完成对话框中的差异均不提供该功能。

> 当列表为空时，该分支永远不会执行。处理这种情况并添加一个测试。

## 从浏览器发送一个页面元素

1. 打开 **浏览器** 并加载你想要讨论的页面。
2. 在浏览器工具栏点击 **选择元素并发送到聊天**。同一操作也可在浏览器操作菜单中找到。
3. 将光标移动到页面上。Dream 标注光标所指元素，并显示其名称和大小。
4. 点击元素。在此模式下点击会选择元素，而不是激活链接或按钮。按 **Escape** 键退出该模式且不选择任何内容。
5. 在“发送到聊天”表单中，检查缩略图和元素名称，输入您的评论，选择是否启用“新聊天”，然后点击“发送到聊天”。

消息包含页面 URL 和标题、元素的名称和 CSS 选择器、其父级元素、尺寸和位置、可见文本、计算后的样式以及 HTML。对于 React 和 Vue 应用程序，Dream 会附加组件链，在开发构建中还会附加源文件位置。元素的截图以 `browser-element.png` 的形式附带。

在 Dream 中，元素选择操作针对当前活动的浏览器标签页进行。嵌入式框架内的元素无法单独选择；选择其中一个会选中整个框架。导航或重新加载页面会取消选择，长属性值、文本和 HTML 内容会被截断。

## 消息的去向

| 新聊天 | 目标位置 |
| --- | --- |
| 关闭 | 项目的第一个公开聊天，成为当前聊天 |
| 在 | 当启用多聊天功能时，在当前聊天旁边打开一个新聊天 |

如果目标聊天正在忙碌，发送控件将被禁用并显示 **聊天正忙**。消息不会被排队放在当前响应之后；请等待其完成或启用 **新聊天**。

你在聊天 composer 中已经输入的文本会被保留。如果消息无法发送，Dream 会将你的评论附加到该 composer 中，以便你自己发送。按 **Escape** 或点击 popover 外部以在发送前丢弃该评论。

在您想要指向文件而无需选择特定行时，使用 [项目引用和附件](/docs/zh-Hans/providing-context)；在您想要稍后保存提示时，使用 [暂存](/docs/zh-Hans/stash)。
