一项技能将指令打包到 `SKILL.md` 文件中。Dream 通过该提供商的技能位置来发现选定代理和项目中的技能。技能选择器支持 **Claude Code**、**Codex**、**OpenCode** 和 **Cursor Agent**。

## 在聊天中使用一个技能

1. 打开聊天并选择您想要使用的模型。
2. 在消息框中输入 **$** 再加上技能名称的一部分。
3. 从选择器中选择一项技能并添加您的任务说明。
4. 发送这条消息。

例如，选择 `release-checklist` 技能，并要求它在发布前审查当前更改。Dream 将所选技能显示为行内提及，并在已发送的消息上显示技能徽章。切换聊天的提供商或项目时，可用技能可能会变化。

技能调用由所选提供商处理。提及一个技能会提供指令；它不会改变聊天的[权限设置](/docs/zh-Hans/agent-modes)。

## 浏览和预览技能

1. 打开 **设置 → 技能**。
2. 选择提供商选项卡和要检查的项目。
3. 选择一个技能以查看其描述、来源、路径以及 `SKILL.md` 预览。
4. 使用 **打开文件夹** 在您首选的编辑器中编辑其文件。

技能按范围分组，例如 **项目**、**个人**、**插件**、**托管** 和 **内置**，当这些来源可用时。如果技能尚未出现，请在安装或编辑后使用 **刷新**。

## 启用或禁用一个技能

Claude Code 和 Codex 提供按技能切换的功能。这些设置会更新提供商自身的配置，因此也会影响 Dream 之外的技能可用性。Claude Code 将覆盖设置存储在 `~/.claude/settings.json` 中；Codex 通过其应用服务器将其存储在 `~/.codex/config.toml` 中。

OpenCode 和 Cursor 在 Dream 中不提供按技能切换的功能。要停止加载某个技能，请在提供商的技能位置中管理其文件夹。

## 创建一个技能

1. 在 **设置 → 技能** 中，如果技能应属于某个项目，则选择该项目。
2. 点击 **新建技能**。
3. 输入一个**名称**，一个**说明**，说明在什么情况下使用它，以及**说明 (SKILL.md)**。
4. 选择一个或多个 **位置** 选项。
5. 可选地选择 **仅在被提及时运行**，然后点击 **创建**。

名称使用小写字母、数字和连字符，最多 64 个字符。Dream 会在每个选定位置创建一个该名称的文件夹，并在其中创建一个 `SKILL.md` 文件。

| 位置 | 预期用途 |
| --- | --- |
| 项目 · `.agents/skills` | Codex、OpenCode 和 Cursor 的共享项目技能 |
| 项目 · `.claude/skills` | Claude Code 的项目技能 |
| 个人 · `~/.agents/skills` | Codex、OpenCode 和 Cursor 共享的个人技能 |
| 个人 · `~/.claude/skills` | Claude Code 的个人技能 |

项目位置需要一个打开的项目。**仅在被提及时运行**才会写入技能的 `disable-model-invocation` 设置；该设置如何被强制执行取决于提供商。

你也可以从 **保存为技能** 开始，在 [设置 → 提示词](/docs/zh-Hans/saved-prompts) 中。

## 如果某个技能缺失

检查所选提供商和项目，刷新列表，并查看设置中显示的任何发现错误。确认该技能位于提供商可读的位置，并且未被禁用。一个提供商可用的技能并不一定在另一个提供商中可用。
