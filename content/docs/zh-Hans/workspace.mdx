每个 Dream 项目都有自己的工作区。项目标签页让你在不同仓库之间切换，同时保持每个项目打开的聊天记录和工具在一起。

项目也可以位于 [SSH 主机](/docs/zh-Hans/remote-hosts)上。运行命令前请检查主机标签；远程项目的工具在该机器上工作。

## 添加和切换项目

1. 点击项目选项卡旁边的 **+**，或在入门屏幕使用 **打开文件夹**。
2. 选择你想要工作的文件夹。
3. 选择其选项卡以使其成为当前项目。

当前项目决定了你可见的聊天记录、文件、终端、浏览器标签页和存档项。在发送任务或运行命令前，请检查所选标签页。当你希望相关项目放在一起时，可以拖动项目标签页进行排序。

## 在外部重命名或打开项目

打开项目的 **…** 菜单，选择 **编辑** 来更改其显示名称或图标。点击图标上传最多 5 MB 的图像，然后点击 **保存**。重置自定义图标以恢复项目自动检测功能。在 Dream 中重命名项目不会更改其磁盘上的文件夹名称。

使用菜单中的 **打开于** 选项，在可用的外部编辑器中打开项目。

## 后退到之前的聊天

在项目标签旁边使用 **返回** 和 **前进** 可以返回之前打开的项目和聊天记录。在 Windows 和 Linux 上，使用 **Alt+Left** 和 **Alt+Right**；在 macOS 上，使用 **Command+[** 和 **Command+]**。鼠标上的后退和前进按钮也有效。

该项目和聊天选择的历史记录会随之更新。切换工具面板不会添加条目，嵌入式浏览器有其独立的导航历史。终端或代码编辑器内的键盘快捷键由相应工具本身提供。

## 关闭并重新打开项目

1. 打开项目中的 **…** 菜单并选择 **关闭**。
2. 当你想要返回时，通过项目 **+** 按钮打开入门屏幕。
3. 在 **最近关闭** 中查找项目，如有需要可使用搜索字段。
4. 选择项目以重新打开它。

关闭一个项目会移除其打开的标签页；它不会删除其文件夹。Dream 在可能的情况下会恢复已保存的项目上下文，例如聊天记录和已打开的工具。不要将关闭的项目用作保持终端进程运行的方法。

## 查找工作区控件

左侧工具栏包含 **聊天记录**、**新聊天** 和 **启用多聊天**。将鼠标悬停在图标上可查看其标签。聊天输入框中包含所选模型、在支持情况下包含努力程度和速度，以及权限。

右侧工具栏打开项目工具：

| 工具 | 你可以做什么 |
| --- | --- |
| [更改](/docs/zh-Hans/git-workflows) | 审查 Git 差分并还原文件更改 |
| [文件](/docs/zh-Hans/files) | 浏览文件、搜索路径和编辑文件内容 |
| [浏览器](/docs/zh-Hans/browser) | 预览 URL 并检查网页 |
| [终端](/docs/zh-Hans/terminals) | 在单独会话中运行项目命令 |
| [Git 操作](/docs/zh-Hans/git-workflows) | 提交、推送并创建拉取请求 |
| [拉取请求](/docs/zh-Hans/pull-requests) | 阅读当前分支的拉取请求，发布评论，并合并 |
| [暂存](/docs/zh-Hans/stash) | 保存提示词并稍后运行它们 |

**Git 操作**位于右侧工具栏的顶部。仓库项目会显示 Git 控制选项。聊天区域下方的分支控制项显示当前活动分支；可使用该功能切换分支或[创建一个工作树](/docs/zh-Hans/worktrees)。在工作树项目中，相同位置会显示一个**工作树**按钮，用于打开[完整工作树](/docs/zh-Hans/worktrees#完成一个工作树)对话框。

## 整理聊天记录和面板

点击工具以打开其面板。当需要更多聊天空间时，使用面板的关闭或折叠控件，并拖动面板分隔条来调整布局。关闭工具面板与关闭其单独的终端会话或浏览器标签页是不同的。

启用 [多聊天](/docs/zh-Hans/multiple-chats) 功能，以可调整大小的列形式组织对话。每个聊天都有自己的对话历史，而项目中的所有聊天共享相同的文件。使用工作树进行独立检出。

## 捕获 Dream 窗口

在 Windows/Linux 上按 **Ctrl+Shift+S**，或在 macOS 上按 **Command+Shift+S** 可以捕获 Dream 窗口。Dream 将截图复制到剪贴板，然后打开对话框将其保存为 PNG 文件。取消保存对话框会保留剪贴板中的截图。会有一个通知报告截图是否被复制、保存，或无法捕获。

对于网页的截图，使用 [浏览器的截图操作](/docs/zh-Hans/browser)。

对于应用程序的整体外观、语言和模型偏好，打开 [设置](/docs/zh-Hans/settings)。要查找旧的对话，请使用 [聊天记录](/docs/zh-Hans/chats) 或 [已归档聊天](/docs/zh-Hans/archived-chats)。
