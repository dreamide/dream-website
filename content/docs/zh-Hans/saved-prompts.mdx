---
title: "可复用的提示词"
description: "保存指令一次，然后在任何项目的聊天中运行。"
---

使用 **设置 → 提示词** 来设置您在多个项目中重复使用的指令，例如审查更改或处理评论反馈。已保存的提示具有名称和文本；它会在您选择的对话中运行，使用该聊天的模型和设置。

## 创建一个提示

1. 打开 **设置 → 提示词**，点击 **新建提示词**。
2. 输入一个简短的**名称**，以便在聊天菜单中识别。
3. 以 **提示词** 的形式编写指令，然后点击 **创建**。

例如，将一个提示名称设为“审查更改”并保存：

> 检查当前更改中的错误、遗漏的边界情况和意外行为。报告发现的问题，并附上文件引用。暂时不要编辑文件。

提示在各个项目中都可用。请确保可重用的指令独立于特定文件夹，或确保文本中的任何路径都适用于运行该提示的项目。

## 在聊天中运行一个提示

1. 打开您想要使用的项目和对话。
2. 审查该聊天的模型和[权限](/docs/zh-Hans/agent-modes)。
3. 点击消息框旁边的 **+** 菜单。
4. 选择 **运行提示词**，然后选择已保存的提示。

选择一个提示会立即将其文本发送到该聊天中。它不会先插入一个可编辑的草稿。你已经在编辑器中输入的文本会被保留，已保存的提示文本仍可重复使用。如果你希望在发送前调整文本，可以将其从设置中复制，并自行粘贴到编辑器中。

**运行提示词** 在聊天繁忙时不可用。在运行另一个提示之前，请等待当前响应完成。如果提交失败，请检查提示文本的编辑器。

在 **设置 → 提示词** 中选择一个提示词以预览和复制其文本。使用 **编辑** 或双击其名称来修改它。**上移** 和 **下移** 可以改变其在列表和聊天菜单中的位置。要删除一个提示词，请点击其删除控件，然后点击 **确认删除**。

在聊天的“运行提示”菜单中选择“管理提示…”可打开此设置页面。

## 将一个提示词转化为一个技能

在已保存的提示语旁边点击 **保存为技能** 可以打开技能创建对话框，其名称和说明内容将被自动填充。添加描述，选择保存位置，然后点击 **创建**。有关提供商支持和存储位置，请参见 [智能体技能](/docs/zh-Hans/skills)。

| 你想要…… | 使用 |
| --- | --- |
| 在不同的聊天中重复发送相同的指令 | 可复用的提示词 |
| 为后续任务准备一个具有独立模型设置的任务 | [暂存](/docs/zh-Hans/stash) |
| 为代理提供可重用的指令，以便在执行任务时加载 | [技能](/docs/zh-Hans/skills) |
