---
title: "远程主机"
description: "通过 SSH 或 HTTPS 连接另一台机器，并使用其项目、代理、文件、Git 和终端。"
---

Dream 可以打开远程机器上的项目，与本地项目并排使用。文件、Git 命令、代理进程和终端均在项目所属的主机上运行。项目的主机标签会显示当前的工作位置。

通过 SSH 连接主机；或者，当另一台机器已开启[远程访问](/docs/zh-Hans/remote-access)时，通过 HTTPS 与该 Dream 主机配对。一个主机可以有多条路由，Dream 会使用第一条连接成功的路由。

Dream 通过 SSH 为 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）安装托管主机运行时。这些是远程主机平台；Dream 桌面应用可以在 Windows、macOS 或 Linux 上运行。Linux 主机运行时支持 glibc 2.31 或更高版本的系统。

## 添加 SSH 主机

1. 在系统终端中确认 `ssh devbox` 可以正常运行，将 `devbox` 替换为 SSH 配置别名或 `user@host`。Dream 使用系统的 SSH 客户端、配置和密钥。
2. 打开 **设置 → 连接**，然后选择 **添加主机 → SSH 主机**。
3. 输入 **SSH 目标**（或从 `~/.ssh/config` 建议的别名中选择一个），以及可选的 **名称**。
4. 将 **主机命令** 留空以自动安装运行时，然后点击 **保存**。Dream 会连接到新主机。
5. 在 Dream 中回答主机密钥、密码、密钥口令或双重验证提示。拒绝或取消提示会停止本次连接尝试。

你也可以选择 **添加 SSH 主机…**，该选项位于 **打开文件夹** 对话框中。

托管运行时按版本安装在 `~/.dream/host/versions/` 下。如果主机无法下载运行时，Dream 可以先在本地下载，再通过 SSH 上传。也请在远程机器上安装代理 CLI 并登录；它们在该机器的环境中运行。

如果手动安装了运行时，请将**主机命令**设为在远程机器上运行 `dream-host` 的命令。

## 通过 HTTPS 配对主机

配对可让此桌面应用无需 SSH，即可通过该主机[远程访问](/docs/zh-Hans/remote-access)设置所使用的地址连接到 Dream 主机。

1. 在主机上打开 **设置 → 连接**，然后选择 **配对设备**（位于 **远程访问** 下）。
2. 在此桌面应用上打开 **设置 → 连接**，然后选择 **添加主机 → 配对链接**。
3. 在 **链接** 选项卡上粘贴 **配对链接**。或者，在 **代码** 选项卡上输入主机上显示的 **主机地址** 和 **配对码**。
4. 输入可选的名称，然后选择 **配对**。
5. 如果使用的是配对码，请在主机远程访问设置的 **等待配对** 下确认此桌面应用。

配对链接只能使用一次，并会在 10 分钟后过期。这台电脑必须信任该主机的 HTTPS 证书。

## 打开远程项目

1. 在入门屏幕上选择 **打开文件夹**。使用项目 **+** 按钮可返回该屏幕。
2. 在 **打开位置** 中选择主机。如果 Dream 提示，请连接该主机。
3. 输入 **文件夹路径**；Dream 会在你输入时建议文件夹。你也可以浏览路径下方的列表，并使用 **上一级文件夹**。
4. 点击**打开**。远程文件夹将作为项目标签页打开，拥有自己的聊天和工具。

已关闭的远程项目会显示在**最近关闭**中，并附有主机和路径。重新打开项目时会连接该主机。远程路径属于远程机器；在 Dream 外打开文件时，请使用已连接到该机器的编辑器。

## 管理路由

路由是访问主机的一种方式：一个 SSH 连接或一个已配对的 HTTPS 地址。为同一主机添加多条路由，可在其中一条不可用时继续工作，例如在办公室网络中使用 SSH，在其他地方使用 HTTPS。

1. 打开 **设置 → 连接**，然后点击主机上的 **编辑**。
2. 查看路由。Dream 会按顺序尝试各条路由，直到有一条连接成功；**当前路由** 标记正在使用的那一条。
3. 使用 **上移** 和 **下移** 更改顺序。
4. 选择 **添加 SSH 路由** 或 **添加 HTTPS 路由**，为同一主机添加另一种访问方式；或选择 **移除路由** 删除一条路由。至少必须保留一条路由。

当首选路由不可用时，Dream 会切换到下一条路由，并保持转发端口不变。更改 HTTPS 路由需要新的配对链接。

## 重新连接或移除主机

**设置 → 连接** 中的每个主机都会显示其状态，例如 **已连接**、**正在重新连接…** 或 **连接失败**。Dream 会重试中断的连接。主机不可用时，项目标签页仍然可见，但在重新连接之前无法发送消息。如果重连停止，请阅读显示的错误，然后使用 **连接**。

使用 **编辑** 更改主机的名称、目标或命令。更改目标或命令会重新建立当前连接。**断开连接** 会保留其项目标签页。

**移除** 会先请求确认，然后从此 Dream 工作区中移除该主机及其项目，并停止其终端。主机上的文件和聊天不会被删除。

## 连接问题

先在系统终端中检查相同的 SSH 目标。解决身份验证或主机密钥问题后再重新连接。如果主机运行时无法启动，请阅读 **设置 → 连接** 中的错误，并检查配置的 **主机命令** 或该平台是否有可用的运行时。

对于 HTTPS 路由，请检查主机是否正在运行，且远程访问显示 **就绪**。如果该路由显示 **需要处理**（见主机的 **编辑** 对话框），则设备可能已被撤销；请使用主机远程访问设置中的新链接重新配对。请参阅[远程访问问题](/docs/zh-Hans/remote-access#远程访问问题)。

开发版本没有已发布的运行时可供下载。请在 Dream 应用仓库中运行 `pnpm host:install-dev devbox`，然后将**主机命令**留空并重新连接。远程构建需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3 以及 C++ 工具链（g++ 10 或更新版本）。安装程序会先停止现有的开发主机守护进程，再替换运行时。
