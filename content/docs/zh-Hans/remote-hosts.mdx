---
title: "SSH 远程工作区"
description: "连接 SSH 主机，使用远程项目、代理、文件、Git 和终端进行开发。"
---

Dream 可以通过 SSH 打开远程机器上的项目，与本地项目并排使用。文件、Git 命令、代理进程和终端均在项目所属的主机上运行。项目的主机标签会显示当前的工作位置。

SSH 工作区从 Dream v0.25.0 开始提供。此版本包含适用于 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）的托管主机运行时。这些是远程主机平台；Dream 桌面应用可以在 Windows、macOS 或 Linux 上运行。

1. 在系统终端中确认 `ssh devbox` 可以正常运行，将 `devbox` 替换为 SSH 配置别名或 `user@host`。Dream 使用系统的 SSH 客户端、配置和密钥。
2. 打开**设置 → SSH 主机**，然后选择**添加 SSH 主机**。输入 **SSH 目标**和可选的**名称**。
3. 将**主机命令**留空以自动安装运行时。点击**保存**，然后点击**连接**。
4. 在 Dream 中回答主机密钥、密码、密钥口令或双重验证提示。拒绝或取消提示会停止本次连接尝试。

托管运行时按版本安装在 `~/.dream/host/versions/` 下。如果主机无法下载运行时，Dream 可以先在本地下载，再通过 SSH 上传。也请在远程机器上安装代理 CLI 并登录；它们在该机器的环境中运行。

如果手动安装了运行时，请将**主机命令**设为在远程机器上运行 `dream-host` 的命令。

## 打开远程项目

如果尚未添加主机，**在 SSH 主机上打开**会直接进入**设置 → SSH 主机**。在那里添加主机后，返回入门屏幕以打开其文件夹。

1. 在入门屏幕上选择**在 SSH 主机上打开**。使用项目 **+** 按钮可返回该屏幕。
2. 选择**主机**，如有需要请先连接。使用**主文件夹**、**上一级文件夹**或**显示隐藏文件夹**浏览文件夹，也可以直接输入**文件夹路径**。
3. 点击**打开**。远程文件夹将作为项目标签页打开，拥有自己的聊天和工具。

已关闭的远程项目会显示在**最近关闭**中，并附有主机和路径。重新打开项目时会连接该主机。远程路径属于远程机器；在 Dream 外打开文件时，请使用已连接到该机器的编辑器。

## 重新连接或移除主机

Dream 会重试中断的连接。主机不可用时，项目标签页仍然可见，但发送消息会被禁用，直到重新连接。如果重连停止，请阅读显示的错误，然后使用**重新连接**，或使用**连接**（位于**设置 → SSH 主机**）。

使用**编辑**更改主机名称、目标或命令。更改目标或命令会重新建立当前连接。**断开连接**会保留项目标签页。**移除**会从当前 Dream 工作区中移除主机及其项目，但不会删除远程文件或主机目录数据。

## 连接问题

先在系统终端中检查相同的 SSH 目标。解决身份验证或主机密钥问题后再重新连接。如果主机运行时无法启动，请阅读**设置 → SSH 主机**中的错误，并检查配置的**主机命令**或该平台是否有可用的运行时。

开发版本没有已发布的运行时可供下载。请在 Dream 应用仓库中运行 `pnpm host:install-dev devbox`，然后将**主机命令**留空并重新连接。远程构建需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3 以及 C++ 工具链（g++ 10 或更新版本）。安装程序会先停止现有的开发主机守护进程，再替换运行时。
