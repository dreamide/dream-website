title: "远端主机"

---

Dream 可以开启其他机器上的项目，与本机项目并排使用。文件、Git 指令、代理程序和终端均在项目所属的主机上执行。项目标签页和聊天下方的底部列会显示你目前在哪台主机上工作。

Dream 透过以下两种方式之一连上主机：

| 路由 | 适用时机 | 所需条件 |
| --- | --- | --- |
| SSH | 你已经可以用 `ssh` 连上该机器 | SSH 目标。Dream 会在该机器上安装并执行其主机 |
| HTTPS | 该机器正在执行 Dream 或 `dream-host`，且已开启[远端存取](/docs/zh-Hans/remote-access) | 主机的地址和配对码 |

一台主机可以同时拥有这两种路由。请参阅[路由](/docs/zh-Hans/remote-hosts#路由)。

## 新增 SSH 主机

1. 在系统终端中确认 `ssh devbox` 可以正常运行，将 `devbox` 替换为 SSH 配置别名或 `user@host`。Dream 使用系统的 SSH 客户端、配置和密钥。
2. 开启**设置 → 连接**。在**远程主机**下选择**添加主机**，再选择 **SSH 主机**。
3. 输入 **SSH 目标**。Dream 会从你的 SSH 设置中建议别名。名称为选填，默认与目标相同。
4. 按一下**保存**。Dream 会立即连接至该主机。
5. 在 Dream 中回答主机密钥、密码、密钥口令或双重验证提示。拒绝或取消提示会停止本次连接尝试。

连接时，Dream 会在该机器的 `~/.dream/host/versions/` 下安装与你的应用程序版本相符的主机并将其启动。该机器上不需要预先安装任何东西。如果该机器无法下载主机，Dream 会先在本机下载，再透过 SSH 上传。也请在远端机器上安装代理 CLI 并登入；它们在该机器的环境中执行。

透过 SSH 连接时，Dream 支援 Linux x64、Linux ARM64 和 macOS Apple silicon（ARM64）机器。Linux 机器需要 glibc 2.31 或更新版本。你用来连接的桌面应用程序可以在 Windows、macOS 或 Linux 上执行。

## 透过 HTTPS 与主机配对

无法使用 SSH 或使用 SSH 不方便时，请使用配对码，例如从笔记型电脑透过 Tailscale 或 Cloudflare 通道连上办公室的电脑。

1. 在另一台电脑上开启[远端存取](/docs/zh-Hans/remote-access)，并使用**配对设备**建立配对码，或执行 `dream-host pair`。
2. 在这台电脑上开启**设置 → 连接**，选择**添加主机**，再选择**配对码**。
3. 输入**主机地址**和**配对码**。名称为选填。
4. 按一下**配对主机**。

配对码只能使用一次，并会在建立十分钟后过期。这台电脑必须信任主机的 HTTPS 凭证。过程中不需要 Dream 帐户；这台电脑会维持配对状态，直到在主机上被撤销为止。

## 路由

无论有多少种方式可以连上，每台主机在**远程主机**下都只有一个项目。按一下主机上的**编辑**以开启其路由，然后使用**添加 SSH 路由**或**添加 HTTPS 路由**加入另一种连接方式。你也可以在同一个对话框中重新命名主机。

Dream 会由上而下依序尝试各个路由，直到其中一个连接成功。使用**上移**和**下移**设置顺序，使用**移除路由**删除路由；主机一律至少保留一个路由。偏好的路由无法使用时，Dream 会切换到下一个。

在 Dream 的[浏览器](/docs/zh-Hans/browser)中预览在主机上执行的网站，以及使用**打开于**在外部编辑器中开启项目，都需要 SSH 路由。只能透过 HTTPS 连上的主机仍可提供其项目、聊天、文件、Git 和终端。

## 打开远程项目

1. 按一下项目标签页旁的 **+**，再按一下**打开文件夹**。
2. 在**打开文件夹**对话框中，于**打开位置**下选择主机。如有需要，Dream 会连接至该主机。
3. 输入**文件夹路径**。Dream 会在你输入时列出该主机上相符的文件夹；按 **Tab** 可自动完成反白的文件夹。
4. 点击**打开**。远程文件夹将作为项目标签页打开，拥有自己的聊天和工具。

如果尚未新增主机，请使用对话框底部的**添加 SSH 主机…**。

已关闭的远程项目会显示在**最近关闭**中，并附有主机和路径。重新打开项目时会连接该主机。远程路径属于远程机器；在 Dream 外打开文件时，请使用已连接到该机器的编辑器。

## 重新连接或移除主机

每台主机的连接状态都会显示在**设置 → 连接**中。Dream 会重试中断的连接。主机无法使用时，项目标签页仍然可见，但在重新连接之前无法传送消息。如果重新连接停止，请阅读显示的错误，然后在聊天中使用**重新连接**，或使用**连接**（位于**设置 → 连接**）。

代理回合是在主机上执行，因此这台电脑中断连接时，已在执行的回合会继续进行。重新连接后，Dream 会重新接上该回合。

**断开连接**会保留主机的项目标签页。**移除**会先要求确认，接着从这个 Dream 工作区移除该主机及其项目，并停止它们的终端。主机上的文件和聊天不受影响。

## 连接问题

先在系统终端中检查相同的 SSH 目标。解决验证或主机金钥问题后再重新连接。如果主机无法启动，请阅读**设置 → 连接**中的错误，并确认该机器的平台受到支援。

HTTPS 主机拒绝连接时，错误消息会说明是主机执行的版本不相容，还是这台电脑未获授权。请将两台电脑上的 Dream 更新为相同版本，或在主机上建立新的配对码并重新配对。

开发版本没有已发布的主机可供下载。请在 Dream 应用程序仓库中执行 `pnpm host:install-dev devbox`，然后重新连接。远端建置需要 Node.js 22 或更新版本、pnpm 或 Corepack、make、Python 3，以及 C++ 工具链（g++ 10 或更新版本）。安装程式会先停止现有的开发主机常驻程式，再替换其执行环境。
