---
title: "将任务委派给其他代理"
description: "让代理把任务的一部分交给另一个提供商，稍后再查看结果。"
---

代理可以把一部分工作交给你已设置好的另一个代理提供商。例如，Claude Code 聊天可以在编写测试的同时，让 Codex 审查某项更改。无需开启任何选项，在消息中提出要求即可。

## 让代理委派任务

指明提供商，并描述它应完成的那部分工作：

> 在你编写测试的同时，让 Codex 审查此分支上的更改是否存在错误。它完成后，报告它的发现。

代理启动任务后会继续自己的工作，并在之后的轮次中查看结果。委派的任务在同一项目中运行，并共享项目文件。它不会收到父对话的内容，因此代理会为该任务单独编写指令。

每个任务都是同一项目中的一个新聊天。其标题以 `Task:` 开头，后接这些指令的开头部分。打开该聊天即可跟踪另一个代理的工作。

## 哪些提供商可以委派

Claude Code、Codex、OpenCode 和 Grok Build 聊天可以委派任务，Cursor 和 Antigravity 聊天则不能。六个提供商中的任何一个都可以接收任务，只要其 CLI 已安装并已登录。请参阅 [连接提供商](/docs/zh-Hans/providers)。

## 权限与限制

- 委派的任务以父聊天的 [权限](/docs/zh-Hans/agent-modes) 启动，且权限永远不会超出该范围。
- 停止父聊天的轮次，也会停止它委派的任务。
- 一个聊天最多可同时有 8 个活动的委派任务。委派的任务还可以继续向下委派，最多 4 层。

<Warning>
  委派的任务与父聊天编辑的是同一个项目文件夹。可以让它做审查或调研，或者告诉每个代理应修改哪些文件。如果任务需要独立的检出，请使用 [Git 工作树](/docs/zh-Hans/worktrees)。
</Warning>
