Dream 可作为 macOS、Windows 和 Linux 桌面应用程序使用。

<Card title="下载 Dream" icon="download" href="/zh-Hans/download">
  打开下载页面以选择适用于您平台和架构的包。
</Card>

## 可用的包

| 平台 | 包 |
| --- | --- |
| macOS | 适用于 Apple 芯片（ARM64）或 Intel（x64）的 DMG 文件 |
| Windows | x64 版本的安装程序 |
| Linux | 适用于 x64 的 DEB、RPM 或 AppImage |

## 在打开 Dream 之前

安装并认证至少一个[支持的代理 CLI](/docs/zh-Hans/providers)。Dream 会检测该 CLI 及其提供的模型；API 凭证和订阅仍由该提供商管理。

## 更新

Dream 检查应用程序更新。当有更新可用时，请在应用中使用更新操作，或从 [下载页面](/zh-Hans/download) 下载最新版本。

<Tip>
  如果 Dream 未检测到已安装的 CLI，请确认该命令在您的普通终端中可以正常运行，然后从 Dream 的设置中刷新提供商。
</Tip>

## 下一步

安装后，请[连接一个提供商](/docs/zh-Hans/providers)并启用至少一个模型。然后[打开你的第一个项目](/docs/zh-Hans/first-project)。你可以在[设置 → 通用](/docs/zh-Hans/settings#通用)中选择界面语言、外观和终端 shell。

如果应用程序已打开但无法开始对话，请检查[模型和提供商故障排除](/docs/zh-Hans/troubleshooting#模型缺失或我无法开始聊天)。
