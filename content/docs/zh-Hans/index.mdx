## Dream 包含了什么

- 一个支持多项目的工作区，具有持久化的项目标签页
- [SSH 远程工作区](/docs/zh-Hans/remote-hosts)，支持远程代理、文件、Git 和终端
- 多个并排聊天窗口和聊天分支
- 项目间可复用的提示词及提供商感知的代理技能
- 每条回复的检查点用于审查和恢复代理更改的文件
- 支持 Codex CLI、Claude Code CLI、OpenCode CLI、Cursor Agent CLI 和 Grok Build CLI
- 文件资源管理器、文件搜索与编辑、集成终端和浏览器预览
- Git 状态、分支、差异、提交、推送、拉取请求和工作树工作流程，包括将完成的工作树合并回其基础分支
- 逐行差异反馈和浏览器元素选择，可向聊天发送定向消息
- 一个用于审查代码、发布评论、编辑详情和合并的 GitHub 拉取请求面板
- 可配置的 MCP 服务器和内置的浏览器交互代理工具

<Note>
  Dream 通过其已安装的 CLI 运行代码代理。在开始聊天之前，你需要至少一个支持的 CLI。
</Note>

## 了解工作区

**项目**是本机或 SSH 主机上的文件夹，拥有独立的聊天和工具。**聊天**是拥有独立模型和设置的对话。同一项目中的多个聊天共享文件；**工作树** 为任务提供独立的 Git 工作副本。

使用 [智能体权限](/docs/zh-Hans/agent-modes) 来选择智能体的工作方式，并通过 [上下文与用量](/docs/zh-Hans/context-and-usage) 来了解 composer 以下的信息。[设置参考](/docs/zh-Hans/settings) 列出了全局应用偏好设置。如果某个功能缺失或无法运行，请先查看 [故障排查](/docs/zh-Hans/troubleshooting)。
