在右侧面板中点击 **文件** 以浏览当前项目的文件夹。从树形结构中打开一个文件，以便与聊天内容一起查看该文件。文件标签页让你在多个已打开的文件之间切换。

## 查找文件

1. 打开 **文件**。
2. 在树结构上方的“搜索文件”中输入文件名或路径的一部分。
3. 选择一个结果以打开它。
4. 清除搜索以返回浏览树。

在文件操作中使用 **刷新文件**，当在 Dream 之外做出的更改未反映在文件树中时。通过搜索查找文件的路径；使用编辑器的搜索功能在该文件中查找文本。

## 在文件中搜索和替换

1. 打开文件并在编辑器工具栏中点击 **搜索当前文件**。
2. 在 **查找** 中输入文本。
3. 使用 **下一个匹配项** 或 **上一个匹配项** 来浏览结果。
4. 如果需要，请启用 **区分大小写**、**全字匹配** 或 **使用正则表达式**。

搜索面板还提供了替换控件。使用 **全部替换** 之前，请先检查匹配项，然后保存文件以将更改写入磁盘。替换操作仅影响当前文件。

## 编辑并保存

在代码编辑器中编辑可写文本文件。未保存的更改会在其标签页中标记，面板可以显示有多少文件有未保存的草稿。

在编辑器工具栏点击 **保存**，或在 macOS 上按 **Command+S**，在 Windows/Linux 上按 **Ctrl+S**（编辑器处于焦点状态时）。在请求代理或终端命令使用新内容之前，必须先保存每个已编辑的文件；这些工具会读取磁盘上的文件。

切换文件选项卡可以让你在检查其他文件的同时保留草稿。使用 **丢弃更改** 可以放弃本地草稿。这与通过 Git 撤销更改是分开的。

关闭带有未保存更改的标签页会打开一个 **保存 / 不保存 / 取消** 提示。选择“保存”会写入草稿并关闭标签页，“不保存”会丢弃草稿并关闭标签页，而“取消”则保持标签页打开。如果保存失败或与外部编辑发生冲突，文件会保持打开状态，以便你可以解决该问题。

## 处理编辑器外部更改的文件

当代理、终端命令或外部编辑器在您有草稿时修改了同一个文件，Dream 在保存时会检查磁盘内容，并报告冲突，而不是静默地覆盖该较新版本。

1. 保留你想要保留的任何草稿文本。
2. 阅读冲突信息。
3. 使用 **从磁盘重新加载** 加载当前文件。
4. 重新应用你仍然需要的更改，然后再次保存。

<Warning>
  从磁盘重新加载会替换你的本地草稿。在使用它之前，请复制你需要的未保存工作。
</Warning>

## 调整视图

使用 **启用自动换行** 处理长行。调整文件树和编辑器面板的大小，为内容提供更多的空间。使用可用的 **打开于** 动作继续编辑。

保存后，打开[更改](/docs/zh-Hans/git-workflows)检查 Git 差异。如果要向代理询问某个文件，请在聊天输入框中[使用 @ 引用该文件](/docs/zh-Hans/providing-context)。
