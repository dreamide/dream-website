---
title: "远程访问"
description: "从手机、浏览器或另一个 Dream 桌面应用使用这台电脑上的项目。"
---

远程访问让其他设备可以使用这台电脑上的项目。手机或其他电脑会在浏览器中打开 Dream，另一个 Dream 桌面应用则可以将这台电脑添加为[远程主机](/docs/zh-Hans/remote-hosts#通过-https-配对主机)。每台设备都必须先配对，你也可以随时撤销其访问权限。

代理、终端和 Git 命令仍在这台电脑上运行。只有当 Dream 的主机在这台电脑上运行时，已配对设备才能访问它。如需在关闭 Dream 后保持主机运行，请将其安装为[服务](/docs/zh-Hans/host-service)。

## 开始之前

选择设备访问这台电脑的方式：

| 连接方式 | 所需条件 |
| --- | --- |
| Tailscale | 在这台电脑和每台设备上安装并登录 Tailscale，并为你的 tailnet 开启 MagicDNS 和 HTTPS 证书 |
| Cloudflare Tunnel | 你的 Cloudflare 账户中有一个持久的 Cloudflare Tunnel 和主机名，例如 `dream.example.com` |

对于 Cloudflare Tunnel，请创建一个专用的、远程管理的隧道，并只复制其连接器令牌。将其主机名路由到 Dream 显示的 **本地端口** 上的 `http://127.0.0.1`，并对 `/api/*` 绕过缓存。不支持 Quick Tunnels，且该主机名不能要求交互式的 Cloudflare Access 登录。

## 开启远程访问

1. 打开 **设置 → 连接**，找到 **远程访问**。
2. 选择 **设置**。
3. 在 **通过以下方式访问这台电脑** 下，选择 **Tailscale** 或 **Cloudflare Tunnel**。
4. 对于 Cloudflare Tunnel，输入 **公开地址** 并粘贴 **隧道令牌**。如果连接器显示 **未安装**，请选择 **安装 cloudflared**。
5. 选择 **开启**。

Dream 会先检查连接，然后才显示 **就绪**。如果显示 **未就绪**，请阅读其下方的消息，修正设置后使用 **重新检查**。部分消息会附带 **打开设置页面**。

使用 **更改** 切换连接方式或替换隧道令牌。将令牌留空即可保留已保存的令牌。**允许已配对设备** 开关可关闭或开启远程访问，而不会丢失设置或已配对设备。

### 高级选项

| 选项 | 它能做什么 |
| --- | --- |
| HTTPS 端口 | Tailscale 为 Dream 提供服务的端口。如果 Tailscale 已在该端口上提供其他服务，请更改此端口 |
| 本地端口 | 这台电脑上接收远程连接的端口。留空则自动选择 |
| 我自己运行 cloudflared | 使用你另行安装和运行的 Cloudflare 连接器。Dream 不会启动、停止或删除它 |

## 配对设备

1. 远程访问显示 **就绪** 后，选择 **配对设备**。
2. 为设备选择 **访问权限** 级别。
3. 选择 **创建配对**。
4. 在设备上扫描二维码或打开链接。你也可以使用 **复制链接** 将其发送出去。
5. 选择 **完成**。

| 访问权限 | 设备可执行的操作 |
| --- | --- |
| 仅查看 | 读取项目、聊天和终端 |
| 查看和工作 | 还能以你的身份运行代理、终端和 Git |
| 完全访问 | 还能配对和移除设备 |

链接只能使用一次，并会在 10 分钟后过期。如需不通过链接进行配对，请在设备上打开主机地址，输入二维码旁显示的配对码，并为设备命名。之后设备会一直等待，直到你在这台电脑上选择 **确认**（位于 **等待配对** 下）。对于任何你不认识的设备，请选择 **拒绝**。

如需配对另一个 Dream 桌面应用，请将链接粘贴到其 **添加主机 → 配对链接** 对话框中。请参阅[通过 HTTPS 配对主机](/docs/zh-Hans/remote-hosts#通过-https-配对主机)。

## 在已配对设备上使用 Dream

已配对设备会在浏览器中打开 Dream。在手机上，Dream 使用紧凑布局。设备可以在其访问权限范围内，使用这台电脑上的项目、聊天、文件和终端。

如果无法访问这台电脑，设备上会显示横幅提示，并显示其已保存的内容。主机恢复可用后，Dream 会重新连接。处于睡眠状态的电脑无法访问。

如需在设备本身上移除其访问权限，请选择 **退出登录**（位于 **此设备** 下）。退出登录还会移除该浏览器保存的内容。

## 管理已配对设备

**已配对设备** 列出了每台设备及其上次使用时间。选择 **撤销** 可移除设备的访问权限。该设备上打开的页面会立即停止工作；这台电脑上的工作会继续进行。30 天内未使用的设备必须重新配对。

## 远程访问问题

| 消息或症状 | 该做什么 |
| --- | --- |
| Tailscale 未安装或未运行 | 安装 Tailscale、登录并连接这台电脑，然后选择 **重新检查** |
| 这台电脑正在等待批准 | 在 Tailscale 管理控制台中批准它 |
| 开启 MagicDNS 和 HTTPS 证书 | 在 Tailscale 管理控制台中为你的 tailnet 同时启用这两项 |
| Tailscale 不允许此用户更改其 Serve 设置 | 在 Linux 上，运行一次 `sudo tailscale set --operator=$USER`，然后重新检查 |
| 端口已被其他程序占用 | 选择其他 **HTTPS 端口** 或 **本地端口**（位于 **高级** 下） |
| 无法通过 Tailscale 访问这台电脑 | Tailscale 可能仍在获取证书；请一分钟后重新检查 |
| 无法通过 Cloudflare 访问这台电脑 | 在 Cloudflare 中将该主机名的服务 URL 设置为 `http://127.0.0.1`，并使用 Dream 中显示的 **本地端口** |
| 正在等待 Cloudflare 连接器连接 | 检查隧道令牌，并确认这台电脑允许出站连接 |
| 配对链接已过期或已被使用 | 再次选择 **配对设备** 并使用新链接 |
| 某台设备停止工作 | 检查它是否已被撤销或已 30 天未使用，然后重新配对 |
