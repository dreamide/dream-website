---
title: "远端存取"
description: "透过 Tailscale 或 Cloudflare Tunnel 配对设备，从手机或另一台电脑使用这台电脑上的项目。"
---

远端存取可让其他设备使用这台电脑上的项目。已配对的设备会在其浏览器中开启 Dream，或从另一个 Dream 桌面应用程序连接，而代理、文件、终端和 Git 指令仍在这台电脑上执行。

远端存取在你开启之前会保持关闭，且每台设备都必须先配对才能连接。Dream 不使用帐户或中继服务：网络路由由你提供，谁能连入则由配对控管。

## 选择设备存取这台电脑的方式

| 选项 | 运作方式 | 所需条件 |
| --- | --- | --- |
| Tailscale | 在你的 tailnet 内透过 HTTPS 提供 Dream | 这台电脑和每台设备上都有 Tailscale，且已为 tailnet 开启 MagicDNS 和 HTTPS 凭证 |
| Cloudflare Tunnel | 在你自己域名的公开主机名称上提供 Dream | Cloudflare 帐户中的常设通道，以及由你自行执行的 `cloudflared` 连接器 |

你也可以在主机前方架设自己的反向代理。请参阅[执行主机](/docs/zh-Hans/dream-host#通过命令行使用远程访问)。

## 开启远端存取

1. 开启**设置 → 连接**，找到**远程访问**。
2. 按一下**设置**。
3. 在**通过以下方式访问这台电脑**下，选择 **Tailscale** 或 **Cloudflare Tunnel**。
4. 使用 Tailscale 时，保留或变更 **HTTPS 端口**。使用 Cloudflare Tunnel 时，输入**公开地址**，例如 `https://dream.example.com`。
5. 除非需要特定连接埠，否则请将**本地端口**留空，然后按一下**开启**。

一旦 Dream 能透过该地址连上这台电脑，**允许已配对设备**旁的状态就会显示**就绪**。如果显示**未就绪**，请依照显示的消息修正问题，然后按一下**重新检查**。之后可使用**更改**编辑设置。关闭**允许已配对设备**可停止为设备提供服务，而不必解除配对。

### 设置 Cloudflare 通道

Dream 不会安装或执行 `cloudflared`，也从不需要你的通道权杖。它只需要公开地址，以及该主机名称所路由到的本机连接埠。

1. 在 Cloudflare 仪表板中建立通道，并在这台电脑上执行它显示的安装指令。
2. 为你域名上的某个主机名称新增路由。将其服务设为 `HTTP` 和 `127.0.0.1:5410`，或设为 Dream 中显示的**本地端口**。
3. 请确认该主机名称可接受直接的 API 和 WebSocket 请求。不要在它前面加上 Cloudflare Access 登入或浏览器质询，也不要快取或缓冲 `/api/*`。

不支援 Quick Tunnels。其地址会变动，而且无法传输聊天串流。

## 配对设备

1. 远端存取就绪后，按一下**配对设备**。
2. 为该设备选择**访问权限**等级。
3. 按一下**创建配对**。Dream 会显示**配对码**和**主机地址**。
4. 在另一台设备上，用浏览器开启主机地址，输入配对码和**设备名称**，然后按一下**配对**。

若要改用另一个 Dream 桌面应用程序（而非浏览器）连接，请使用相同的地址和配对码，[在该应用程序中将这台电脑新增为主机](/docs/zh-Hans/remote-hosts#透过-https-与主机配对)。

配对码只能使用一次，并会在 10 分钟后过期。任何输入配对码的人都会取得你所选的存取权限，因此请只将它提供给你要配对的设备。

| 存取权限 | 设备可执行的操作 |
| --- | --- |
| 仅查看 | 读取项目、聊天和终端 |
| 查看与工作 | 还能以你的身分执行代理、终端和 Git |
| 完整存取 | 还能配对和移除设备 |

## 从已配对的设备使用 Dream

已配对的浏览器会显示这台电脑上的项目，以及项目的聊天、文件、终端和 Git 面板。有几项功能仍只在桌面应用程序中提供：内嵌的**浏览器**工具、**设置 → 连接**、在其他主机上开启文件夹，以及用于外部编辑器的**打开于**。

如果设备失去连接，会出现横幅提示正在重新连接，或提示无法连上主机、目前显示的是先前储存的内容。无论哪种情况，主机上的工作都会继续进行。若要从设备端解除配对，请在该设备上开启**设置**并选择**退出登录**。

## 管理已配对的设备

**已配对的设备**会列出每台设备及其存取权限等级和上次使用时间。按一下**撤销**可移除一台设备，按一下**全部撤销**则会移除所有设备。遭撤销的设备会立即失去存取权，其已开启的页面也会停止运作；这台电脑上的工作则会继续。

## 让这台电脑保持可用

只有在 Dream 的主机正在执行且这台电脑处于唤醒状态时，设备才能连接。由桌面应用程序启动的主机会在你结束 Dream 时停止。若要让主机在背景持续执行，或要分享没有桌面工作阶段的机器，请参阅[执行主机](/docs/zh-Hans/dream-host)。

如果「设置」回报这台电脑的主机版本与应用程序不同，请更新较旧的那一个，然后重新启动主机。
