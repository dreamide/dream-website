---
title: "模型与默认设置"
description: "启用模型，为聊天和 Git 撰写设置默认值，并更改对话的模型。"
---

Dream 将可用于使用的模型与特定任务所选择的模型分开。**设置 → 提供商** 控制模型的可用性。**设置 → 通用**，在 **模型** 组中，控制默认设置。每个聊天消息框下方的选择器控制该次对话。

## 启用模型

1. 安装并认证一个 [支持的提供商 CLI](/docs/zh-Hans/providers)。
2. 打开 **设置 → 提供商** 并启用该提供商。
3. 刷新提供商以检测其 CLI 和可用模型。
4. 启用您希望出现在 Dream 选择器中的模型。

你可以启用多个供应商提供的模型。如果某个模型在选择器中缺失，请首先检查此处是否已启用。刷新会检测模型的可用性；它与选择默认模型是分开的。

## 为新聊天设置默认值

1. 打开 **设置 → 通用 → 模型**。
2. 在 **默认聊天模型** 中，选择一个已启用的模型。
3. 如果所选模型提供那些控制选项，请选择 **推理强度** 和 **速度**。
4. 返回项目并开始新的聊天以使用选择。

默认设置适用于项目中新建的聊天。现有对话会保留自己的模型设置。如果“新聊天”恢复了你已打开的空草稿，请检查其编辑器并根据需要更改模型。

## 为提交和拉取请求草稿设置一个模型

在相同的 **模型** 组中，选择 **文本生成模型** 及其性能和速度（如果支持）。Dream 会在撰写提交信息和拉取请求文本时使用这些设置。

例如，你可以为实现聊天使用一个模型，为 Git 摘要使用另一个模型。更改 Git 撰写模型不会影响你的聊天模型。有关在发布前审查和编辑生成文本的详细信息，请参见 [Git 工作流程](/docs/zh-Hans/git-workflows)。

## 更改聊天的模型

1. 打开对话并等待其当前响应完成。
2. 点击消息框下方的模型名称。
3. 选择一个启用的模型，包括需要时从其他提供商选择模型。
4. 在发送下一条消息之前，请检查努力程度和速度控制。

在 Dream 中，对话内容会持续可见。更改模型会重置其努力程度和速度选择，如果需要特定值，请重新选择。模型变更还会为后续工作启动一个新的提供商会话；它不会改变已生成的消息。

## 推理强度和速度

| 控制 | 目的 |
| --- | --- |
| 推理强度 | 选择该模型提供的推理努力级别 |
| 速度 | 选择一个支持的速度层级，例如标准或快速 |

这些控件仅在所选模型支持时出现。可用的努力级别因模型而异。速度等级可能有不同的使用影响；在选择等级时，请参考选项描述以及您提供商的使用信息。

默认的努力程度和速度适用于新聊天。在某个聊天中更改其中一项会影响力该对话。更改速度也会重置其提供者的会话，以供后续工作使用。

## 如果默认选项不可用

禁用选定的默认模型或刷新已更改的模型列表可能会导致 Dream 选择另一个启用的模型。在更改启用模型后，请重新检查两个默认选择器。如果没有任何模型处于启用状态，请在开始新对话前启用一个模型。

对于缺失控件或检测失败，请参见 [故障排查](/docs/zh-Hans/troubleshooting)。
