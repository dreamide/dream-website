---
title: "MCP 服务器"
description: "为支持的编码代理添加或导入外部工具。"
---

MCP 服务器为代理提供了额外的工具。请在 **设置 → MCP 服务器** 中配置它们。Dream 支持为 **Claude Code**、**Codex**、**OpenCode** 和 **Grok Build** 提供这些连接。Cursor 不支持 Dream 管理的 MCP 连接。

## 添加一个服务器

1. 打开 **设置 → MCP 服务器**，并点击 **添加服务器**。
2. 选择一个唯一的**名称**，可使用字母、数字、连字符和下划线，并以字母或数字开头。
3. 选择 **传输方式** 并输入服务器提供的连接详情。
4. 保持 **已启用** 选项以使服务器可用，然后点击 **保存**。

| 传输 | 字段 |
| --- | --- |
| 命令（标准输入输出） | 在**命令**中填写可执行文件，在**参数**中每行填写一个参数，并按需填写**环境变量** |
| HTTP | HTTP 或 HTTPS **URL**，以及可选的**请求头** |
| SSE | HTTP 或 HTTPS **URL**，以及可选的**请求头** |

以每行一个 `KEY=VALUE` 对的形式输入环境变量和头信息。将可执行文件与其参数分开。例如，一个本地服务器可能使用 `node` 作为其命令，绝对路径到其入口文件作为参数。

服务器定义存储在 Dream 的本地数据库中，包括你输入的任何凭据。这些值以未加密的形式存储。

## 导入现有配置

1. 选择您想要包含其配置的项目。
2. 打开 **设置 → MCP 服务器 → 导入…**。
3. 审查检测到的服务器、其源文件以及任何警告。
4. 选择要添加的服务器并点击 **导入**。

Dream 扫描 Claude 用户和项目配置、Codex 的用户配置，以及 Cursor 的用户和项目 MCP 配置。名称已配置的条目被标记为 **已存在**，且不会再次导入。

将副本定义导入 Dream 中。原始文件的后续更改不会自动同步。导入 Cursor 配置会使其服务器可供 Dream 支持的提供商使用；它不会为 Dream 中的 Cursor 聊天添加 MCP 支持。

使用 **编辑** 来修改定义，使用 **保存** 来应用该定义。切换 **已启用** 为关闭以保留其配置，但不使其对后续代理请求可用。要删除该定义，请使用 **删除**，然后点击 **确认删除**。删除定义不会卸载其可执行文件。

在更换服务器后，向支持的聊天中发送新的请求。如果提供商仍使用旧连接，请启动一个新的聊天。检查可执行文件、URL、凭据以及聊天错误，以确保工具可用。

Dream 的[内置浏览器工具](/docs/zh-Hans/browser#要求代理使用浏览器)会为支持的提供商自动连接，无需在此处为它们添加服务器。
