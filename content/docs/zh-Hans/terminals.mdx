集成的终端可以在不离开 Dream 的情况下运行项目命令。点击右侧工具栏的 **终端** 可以打开它。一个普通项目的终端默认启动于项目文件夹中。

## 在聊天的同时运行命令

使用终端检查项目、运行测试或启动其本地应用，使用该项目文档中记录的命令。终端和代理聊天在此工作区中使用相同的文件。

为了进行浏览器预览，启动项目的应用，记下它打印的 URL，并在 Dream 的 [浏览器](/docs/zh-Hans/browser) 中打开该 URL。打开浏览器不会自动启动服务器。

## 管理终端会话

1. 打开 **终端**。
2. 点击 **打开另一个终端**，**+** 控制按钮，创建另一个会话。
3. 选择一个终端标签页以切换会话。
4. 在使用完终端后，请关闭其控制权。

为长时间运行的应用程序和偶尔的命令（如测试）使用独立会话。关闭终端会话将终止其进程。关闭面板会保留您已使用的会话，但 Dream 会自动清理那些未收到用户输入的已打开会话。

使用 **展开终端** 为面板提供更多空间，使用 **折叠终端** 恢复其常规大小。展开或折叠会改变布局但不会关闭会话。

复制文本时，请先选中文本。在 macOS 上使用 **Command+C**，在 Windows/Linux 上使用 **Ctrl+C** 可复制选定的终端文本。如果没有选中内容，终端可能会将 Ctrl+C 传递给前台命令以中断该命令。

## 选择一个 shell

1. 打开 **设置 → 通用**。
2. 查找 **终端**，并从其选择器中选择一个可用的 shell。
3. 打开一个新的终端会话以使用选定的 shell。

现有的会话会保留它们启动时的 shell。如果某个 shell 或命令不可用，请确认它是否已安装，并且在您的系统终端中可以正常运行。

## 在终端中继续一个 Claude 聊天记录

对于一个已建立可恢复会话的 Claude 对话：

1. 等待当前响应完成。
2. 打开聊天头部分的 **…** 菜单。
3. 选择 **在终端中继续**。

Dream 在该会话的当前工作目录中打开一个名为 **Claude** 的终端，并运行 CLI 的 resume 命令。此操作仅适用于 Claude 会话；它不是针对每个提供商的通用导出操作。

如果该选项缺失，请检查聊天是否使用了 Claude 且已启动了提供商会话。更改其模型或速度可能会重置该会话。如果续写失败，请验证原始工作目录仍存在且 Claude CLI 可用。
